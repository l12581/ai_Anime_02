# 剧本写作规则参考文档：小说改编与剧本改写

> 适用场景：AI辅助将小说/故事转化为剧本、剧本迭代优化、结构重组
> 核心目标：掌握从文字媒介到视觉媒介的转化规律，系统化剧本改写方法

---

## 一、媒介差异认知

### 1.1 媒介的本质区别

| 维度        | 小说               | 电影剧本  |
| --------- | ---------------- | ----- |
| **核心**    | 内心生活             | 画面叙事  |
| **空间**    | 心智景象 (Mindscape) | 银幕视觉  |
| **时间**    | 可停留、回溯           | 绝对现在时 |
| **手法**    | 内心独白、意识流         | 动作、画面 |
| **读者/观众** | 独自阅读             | 影院集体  |

**麦基三分法**：
1. **小说**：处理戏剧性动作的"心智景象"——思想、感觉、感情、回忆
2. **电影剧本**：在戏剧结构背景里，用画面讲述的故事——处理人物外在情况

### 1.2 小说→剧本的核心转化

**必须舍弃**：
- 抒情、感性的句子
- 修辞手法（比喻、排比等文学修辞）
- 角色内心世界的直接描述
- 长篇的心理分析和意识流

**必须转化为**：
- 对白和独白
- 表情和肢体动作
- 视觉画面和场景

**创作原则**：
> "当你把一部小说改编成电影剧本时，你是在把一种形式改变成另一种形式，你是在根据别的材料来写电影剧本。从实质上讲，终究你还是在原创一个电影剧本。"

## 二、小说改编流程

### 2.1 改编六步法

| 步骤 | 任务 | 产出 | 关键要点 |
|------|------|------|----------|
| **1. 决定类型和题材** | 定位观众、确定风格 | 类型定义 | 老少咸宜 vs. 特定族群 |
| **2. 选定故事文本** | 选择版本、分析差异 | 故事文本 | 收集多个版本比对 |
| **3. 角色设定** | 确定主配角、关系图 | 角色关系表 | 精简角色数量 |
| **4. 撰写故事大纲** | 梳理主副线、转折点 | 故事大纲（5-6千字） | 简明扼要、中性叙述 |
| **5. 撰写分场大纲** | 细化每场戏的要素 | 分场大纲 | 时空、人物、互动 |
| **6. 撰写分场剧本** | 完成具体场次 | 分场剧本 | 使用旁白/独白过渡 |

### 2.2 角色关系表设计

**设计原则**：
- 单主轴为主
- 副线不宜超过2-3条
- 副线与主线必须有直接因果关系
- 去除对主角成长无决定性作用的支线

**角色精简法则**：
- 原著人物众多时，合并次要角色
- 多个小角色 → 一个形象鲜明的配角
- 限制上场角色数量（电影篇幅有限）

### 2.3 故事大纲结构

**标准流程**：
```
故事缘起 → 转折 → 冲突 → 高潮 → 收尾
```

**篇幅控制**：
- 两小时电影：故事大纲约 5-6 千字
- 把握主要情节，中性叙述即可
- 无需巨细靡遗的描写

**张力设计**：
- 至少一波以上的冲突推动剧情
- 冲突和高潮产生剧情张力
- 紧紧抓住观众眼球

## 三、核心改编技法

### 3.1 阅读小说与材料整理

**四步整理法**：

**步骤1：关键场景索引卡**
- 概括原作所有关键时刻：人物、场景、事件
- 写在索引卡上，便于重排、添加或移除
- 包含：开头、转折、冲突、高潮、结尾

**步骤2：角色清单**
- 列出主配角和次要人物
- 简要勾勒性情、观念、脾气、特殊习性
- 标记可合并的冗余角色

**步骤3：三到四个预告**
- 想象如何向观众预告这部电影
- 明确：故事主线？什么令人激动？想从观众那里得到什么回馈？

**步骤4：找到亮点（卖点）**
- 识别足以引起观众好奇的剧情亮点
- 满足观众期待的关键情节点

### 3.2 思路阻塞时的解决策略

**策略一：时空转换想象**
- 脱离原本时空看情节，有助于彰显本质
- 例：《教父》如果发生在台北而非纽约，需要做哪些调整？

**策略二：全新角度设想**
- 选择配角而非主角主导故事
- 例：《达·芬奇密码》如果以反派杀手赛拉斯的角度设想剧情

**策略三：去除旁支杂叶**
- 删除与主线关系不紧密的副线
- 去除频繁的"闪回"和主角多次的回忆
- 让事件按线性时间顺序发生

**策略四：选定主角，给具体目标**
- 人物众多时，选择1-2个主角
- 给主角定下具体可行的行动目标
- 情节围绕帮助或阻碍主角完成任务展开

**策略五：精简心理分析**
- 处理"内心独白"、"心理分析"、"自由联想"
- 方法A：精简处理，找出与主要情节有关的节点
- 方法B：转化为可通过对话、表情、小动作呈现的内容

### 3.3 内心独白的转化技法

**意识流小说的挑战**：
- 内心独白、心理分析、自由联想、时空蒙太奇
- 对强调画面的电影构成复杂挑战

**转化方法**：

| 原形式 | 转化方法 | 示例 |
|--------|----------|------|
| **直接内心独白** | 转化为视觉闪回或梦境 | 童年创伤 → 闪回画面 |
| **间接内心独白** | 转化为对白或旁白 | 内心犹豫 → 自言自语 |
| **内心分析** | 转化为动作暗示 | 理性推理 → 调查动作 |
| **自由联想** | 转化为蒙太奇序列 | 跳跃思绪 → 画面剪辑 |

**核心原则**：
- 积极面对、拆解这些元素
- 否则它们会变成"泥淖"困住编剧

## 四、剧本改写方法论


**方法1：结构性调整**
- 列出角色关系表，可视化人物关系
- 增加或删减配角
- 将小角色合并成大角色
- 主角与配角交换身份测试
- 从主轴线拉出副线丰富剧情

**方法2：情节分歧点分析**
- 画树枝状图表
- 在每个分歧节点分析几种可能选项
- 发现意想不到的新方向

**方法3：副线取舍**
- 逐条琢磨副线，决定去留
- 根据分场大纲微调故事大纲

**方法4：调整场次顺序**
- 更动场次顺序
- 增删合并场面

**方法5：局部增删补强**
- 修饰角色动作
- 推敲对白
- 增加或合并角色

**方法6：设计潜台词**
- 使角色思维和性情更鲜明、立体
- 增加潜台词空间

**方法7：边写边修**
- 修改幅度不会太大
- 持续检讨反省，促进成长

## 五、四种改写方式

### 5.1 局部增删（微调）

**删减场面**：
- 识别偏离主线的场面
- 删除对后续主线无推动作用的戏份
- 标准：能否导出后续主线剧情？

**增加场面**：
- 当前后场面因果/逻辑关系接不上时
- 插入过渡场面进行衔接
- 示例：从"买彩票祈祷"到"晕倒路旁"，缺少"对中奖→兴奋→心梗"的环节

### 5.2 调动主配角（中调）

**适用场景**：
- 主角戏份太少，剧情推进缓慢
- 配角戏份占绝对优势（非关键大反派时）

**操作方法**：
- 重新思考角色定位
- 将更能推动主线的角色拉到镜头中间
- 让配角成为新的主角，测试剧情发展性

### 5.3 修改时空背景（大调）

**适用场景**：
- 原有设定对剧情延展形成"天然障碍"
- 自我设限过多，场景必须过滤掉太多

### 5.4 推倒重来（重构）

**适用条件**：
- 没有吸引人的亮点（转折、悬念、冲突）
- 主角是"听话的悬丝傀儡"
- 智慧无成长、性格无转变
- 没有从挫折中学会生存技能

**重生方法**：

**选项A：主线大翻修**
- 加入戏剧张力桥段（巧合、阴谋、悬疑、矛盾、危机、反转、冲突）

**选项B：恶整主角**
- 让其貌不扬、缺乏自信的男女主角吃尽苦头
- 饱尝现实冷暖，激发斗志和求生本能

**选项C：加入强力反派**
- 心思邪恶但能力高强的大反派
- 逼使主角面对各种危机和挑战

**选项D：换一张蓝本**
- 重新构思故事大纲
- 将失败故事作为"反面教材"
- 罗列"负面清单"，避免重蹈覆辙

## 六、从小说到剧本的具体转化

### 6.1 常见元素转化对照

| 小说元素 | 剧本转化 | 注意事项 |
|----------|----------|----------|
| **外貌描写** | 演员选择+简要描写 | 为演员预留创作空间 |
| **心理活动** | 表情、动作、对白 | 不可直接描述内心 |
| **回忆闪回** | 闪回场景或道具触发 | 避免频繁使用 |
| **环境渲染** | 场景标题+视觉描写 | 精简，4行以内 |
| **叙述旁白** | 旁白(▲)或删除 | 尽可能视觉化 |
| **对话** | 精简对白+潜文本 | 去除日常寒暄 |
| **章节过渡** | 场景切换、淡入淡出 | 遵循"开始越晚越好" |

### 6.2 旁白使用规范

**使用原则**：
- 尽可能用画面代替旁白
- 旁白仅用于时空间过渡
- 内心独白仅用于关键心理转折

## 七、AI参考注意事项

### Context管理

**小说→剧本转化时**：
1. 首先识别小说的"心智景象"元素（内心独白、心理分析）
2. 逐一转化为可拍摄的视觉/听觉元素
3. 应用"展示，不要告诉"原则重构场景

**剧本改写时**：
1. 明确改写类型（局部/角色/时空/重构）
2. 应用对应的改写策略
3. 保持原剧本的核心卖点和主控思想

### 常见AI错误预警

- ⚠️ **直接照搬**：将小说段落直接放入剧本格式
- ⚠️ **内心描述**：保留"他想"、"她感到"等无法拍摄的内容
- ⚠️ **过度压缩**：将整部小说压缩进90分钟，丢失关键转折
- ⚠️ **角色过多**：保留原著所有角色，导致叙事分散
- ⚠️ **忽视视觉**：仍用对白解释背景和人物关系
- ⚠️ **闪回滥用**：频繁使用闪回代替戏剧动作
- ⚠️ **线性照搬**：没有根据电影节奏重组时间线

### 质量检验清单

- [ ] 是否识别并转化了所有"心智景象"元素？
- [ ] 角色数量是否精简到电影可容纳范围？
- [ ] 主副线关系是否清晰且因果关联？
- [ ] 是否用视觉替代了说明性对白？
- [ ] 故事大纲是否控制在5-6千字？
- [ ] 分场大纲是否简明（3-5句话/场）？
- [ ] 是否有明确的亮点（卖点）？
- [ ] 是否避免了"闪回依赖症"？
- [ ] 是否遵循了"展示，不要告诉"？
- [ ] 改写后是否保持了核心卖点？
