# 剧本写作规则参考文档：人物塑造

> 适用场景：AI辅助生成角色设定、人物弧光设计、角色关系构建
> 核心目标：创造真实、多维、具备成长空间的角色
> ⚠️ 下游工作流说明：本文档输出的角色设定将被分镜/Storyboard工作流调用。**视觉档案**部分是向下游传递的视觉合约，必须完整填写。

---

## 零、视觉档案规范（Visual Profile）

> **用途**：此段由剧本层生成，作为视觉圣经的核心输入，供分镜工作流保持角色视觉一致性。
> **规则**：视觉档案描述"是什么"，不规定画面风格、美术方向或镜头处理。
> **格式要求**：必须使用代码块格式输出，不得以纯文本形式书写。

### 主要角色数量核对（提醒）

> 核对执行流程见 SKILL.md Phase 3 Step 0。此处仅提醒：视觉档案数量必须 ≥ 原著主要角色数，允许合并但需注明。

### 每个主要角色必须输出以下视觉档案

```
【角色视觉档案】
角色名：
性别/大致年龄：
身形体态：（高矮/体型，一句话）
面部特征：（最多3个可识别特征，如：方下巴、单眼皮、浓眉）
发型发色：（颜色+长度+风格，简短）
标志性服装/装扮：（贯穿全剧的固定形象，或各主要时段的服装）
标志性动作/习惯：（1-2个，用于角色辨识，如：习惯摘眼镜、总是抱臂）
标志性随身物件：（如有，如：总带一根香烟、左手腕的旧表）
```

**填写原则**：
- 描述必须具体可画：用可量化的形容词（"寸头"而非"短发"，"1.8米"而非"高挑"）
- 只描述视觉上稳定不变的特征，不描述情绪状态
- 禁止风格词汇（"冷酷的外表"、"俊朗的气质"等无法转化为画面的描述）

**示例**：
```
【角色视觉档案】
角色名：陈逸
性别/大致年龄：男，40岁左右
身形体态：中等偏高，略显消瘦，走路有轻微驼背
面部特征：眼角有细纹，颧骨偏高，嘴唇薄
发型发色：黑色、微卷，略显凌乱，耳上留长
标志性服装/装扮：长款风衣（棕色），白衬衫，皮鞋永远亮
标志性动作/习惯：说话时会无意识地摸左手手背
标志性随身物件：旧款翻盖手机，从不换新
```

## 一、角色塑造十诫（The Ten Commandments of Characterization）

### 诫命一：明确的目标和对手
**核心公式**：具体目标 + 强大对手 = 叙事驱动力

**目标设定规范**：
- 必须是**具体且可衡量**的（如"打满15个回合"而非"获得幸福"）
- 必须涉及**风险**：如果失败，将失去极其宝贵的东西
- 自觉欲望（想要什么）与不自觉欲望（真正需要什么）形成张力

**对手设计规范**：
- 对抗力量不仅是反派，而是**阻止人物意志的各种力量总和**
- 三层对抗力量设计：
  - **内心冲突**：生理、心理、情绪层面
  - **个人冲突**：家人、朋友、恋人
  - **个人外冲突**：社会机构、自然环境
- 对手越强大，人物被迫展现的意志力越强

**最佳实践**：
- 将对抗力量"人格化"——即使对抗力量是组织，也应有具体代表
- 让主人公处于劣势 (Underdog)，只有一次机会赢得目标
- 形成"对立统一体"：双方动机不可调和，都没有妥协余地

**禁止约束**：
- 禁止模糊的目标（如"寻找自我"、"获得幸福"）
- 禁止过于弱小的对手（无法考验人物极限）
- 禁止让对手无理由作恶（必须有与主人公同样强烈的动机）

### 诫命二：强烈的动机
**核心公式**：目标（终点）+ 动机（能量源）= 完整欲望

**动机构建层次**：
1. **表层动机**：角色清楚知道的理由
2. **深层动机**：源于过往创伤的情感需求
3. **私人化转化**：将普遍性目标转化为极端私人化的动机

**最佳实践**：
- 动机与背景故事绑定：深刻的动机往往源于"情感伤口"
- 动机在中点处变得最为清晰或发生质变
- 用"风险测试"评估动机强度：失败将失去什么？

**经典案例**：
- 《洛奇》：目标=打满15回合；动机=证明自己不是"瘪三"
- 《大白鲨》：目标=消灭鲨鱼；动机转变=从职责到自我救赎

**禁止约束**：
- 禁止缺乏私人色彩的抽象动机
- 禁止动机在故事中保持不变（应随冲突升级而深化）

### 诫命三：内在需求与性格缺陷
**核心公式**：过往创伤 → 伤口 → 性格缺陷 → 内在需求

**概念定义**：
- **伤口 (The Wound)**：背景故事中的情感/身体创伤
- **性格缺陷 (Character Flaw)**：为保护伤口发展出的负面特质（自私、傲慢、不信任）
- **内在需求 (Inner Need)**：为获得幸福真正需要的东西（宽恕、家庭、自尊）

**人物弧光机制**：
- 角色必须在**放弃性格缺陷**（或外部目标）时，才能满足内在需求
- 危机时刻将不自觉需求推向意识表层
- 高潮后的领悟标志着伤口的愈合或缺陷的克服

**最佳实践**：
- 设置"内外对立"的脊椎：外部目标与内在需求有时背道而驰
- 利用"救赎情节"：追求错误价值→意识到是缺陷→牺牲外部目标换取内在救赎
- 负面人物弧光：缺陷最终战胜需求（如《教父》迈克尔）

**禁止约束**：
- 禁止完美无缺的角色（无法引起移情）
- 禁止缺陷与需求无关
- 禁止角色在结尾时仍是开始时的那个人（无弧光）

### 诫命四：行动意志
**核心原则**：动作即是人物 (Action is Character)

**关键概念**：
- 一个人的本质不是由其言谈决定，而是由其**在压力下的选择**决定
- 角色通常先采取"最小的保守行动"，失败后才投入更强意志力
- 在高潮时刻，主人公必须采取最后一个行动，决定人生意义

**最佳实践**：
- 确立自觉与不自觉的欲望作为行动驱动力
- 即使外表软弱的角色，深层也必须有驱动潜意识欲望的坚强意志
- 让主人公成为解决故事冲突的核心动力

**禁止约束**：
- 禁止绝对被动的角色（只是抱怨而无行动）
- 禁止让次要角色解决核心冲突
- 禁止让高潮动作由外力完成

### 诫命五：独特的视角与态度
**核心概念**：视角是角色看待世界的"认知滤镜"

**构建方法**：
1. **事实分配法**：赋予每个角色独立的"事实集"，确保看法不一致
2. **社会背景锚定**：通过职业、阶层、政治立场确立视角坐标
3. **哲学对抗设计**：让持有截然相反哲学观的角色对抗

**最佳实践**：
- 角色弧光本质是视角的不可逆转变化
- 通过视角转换完成精神层面的升华
- 让观众共享角色的主观视角以建立强烈移情

**禁止约束**：
- 禁止所有角色共享同一视角
- 禁止角色视角在故事中保持不变（除非是无弧光英雄如邦德）

### 诫命六：成长空间（人物弧光）
**定义**：角色在故事结束时与开始时相比，在感知、态度或道德本质上发生的**不可逆转的变化**

**弧光类型**：
| 类型 | 方向 | 案例 |
|------|------|------|
| 正向成长 | 负面→正面 | 《绿野仙踪》多萝西 |
| 负面坠落 | 正面→负面 | 《教父》迈克尔 |
| 静止弧光 | 无实质变化 | 《007》邦德 |

**最佳实践**：
- 逆境熔炉：真正的成长只能通过冲突、决定和行动产生
- 欲望与需求的对立统一驱动弧光
- 预示与见证：早期展示局限性，结局展示变化深度

**禁止约束**：
- 禁止角色在结尾时仍是开始的同一个人（静止角色需有明确设计意图）
- 禁止轻易可逆的变化
- 禁止没有压力和选择的弧光完成

### 诫命七：真实感（人类情感与维度）
**核心概念**：人物塑造（可观察素质）vs. 人物真相（压力下的选择）

**维度构建**：
- 维度=矛盾：在深层性格之内存在连贯一致的矛盾
- 善之中心：即使反面人物也必须有正面素质或被置于更邪恶环境
- 生活的三大组成部分 (3Ps)：职业、个人、私生活

**最佳实践**：
- 压力下的选择揭示人物真相
- 克制情感而非宣泄：拼命抑制情感比嚎啕大哭更具移情效果
- 剥洋葱式揭示：通过场景层层剥开假面
- 利用假面 (Façade)：设计虚假人格抵御世界，学会处理恐惧后真实本性显现

**禁止约束**：
- 禁止标签化和刻板印象
- 禁止完美无缺的"纸片人"
- 禁止在无关痛痒时展示美德（必须在生命危险时坚持真理）

### 诫命八：具体的性格化工具
**人物塑造工具箱**：

| 工具类型 | 功能 | 案例 |
|----------|------|------|
| **怪癖与习惯** | 独特行为模式，强化个性 | 《尽善尽美》强迫症 |
| **个人表达方式** | 独特口头禅，增加辨识度 | "Wizard" "Well, there it is" |
| **专业知识/技能** | 特定专长，提供权威感 | 电脑黑客、拆弹技术 |
| **道具** | 身份象征/救命稻草/情感纽带 | 印第安纳·琼斯的皮鞭 |
| **身体缺陷** | 视觉隐喻精神特质 | 《国王的演讲》口吃 |

**最佳实践**：
- 道具使用遵循"伏笔与发笑"原则，关键时刻产生情感冲击
- 身体缺陷从视觉上衬托精神层面的特质
- 性格化工具应随人物成长而改变强度

**禁止约束**：
- 禁止随意点缀而无叙事功能的细节
- 禁止道具仅在开场出现而无后续呼应

## 二、人物关系设计

### 2.1 对立统一体 (The Unity of Opposites)
**定义**：两个角色为了实现各自动机处于不可调和的对立状态，且双方都没有妥协余地

**设计要点**：
- 双方拥有同样强烈的动机
- 妥协对任何一方都意味着丧失核心价值
- 冲突必须持续到故事结束

### 2.2 移情建立 (Empathy)
**移情 vs. 同情**：
- 同情=对人物有好感
- 移情="像我"的感觉，内在相似性

**建立方法**：
- 赋予角色普遍性的人类需求（被理解、被接受、被爱）
- 展示角色的脆弱性和不完美
- 让观众理解角色的"为什么"

### 2.3 次要角色功能
| 功能类型 | 作用 | 设计要点 |
|----------|------|----------|
| **盟友** | 帮助主人公，提供情感支持 | 可有自己的小弧光，但最终服务于主线 |
| **催化剂** | 触发主要行动，但随后退出 | 通常在第一幕发挥作用 |
| **导师** | 传授关键知识或技能 | 往往有自身缺陷或局限性 |
| **对手** | 直接对抗主人公 | 应是主人公的"镜像"或"黑暗版本" |
| **喜剧调剂** | 在紧张中提供喘息 | 不可脱离整体基调 |

### 3.2 弧光追踪
| 阶段 | 对缺陷的态度 | 对需求的态度 | 关键场景 |
|------|--------------|--------------|----------|
| 开场 | 依赖缺陷保护自己 | 否认或忽视需求 | 建立基线 |
| 中点 | 开始质疑缺陷 | 需求逐渐清晰 | 觉醒开始 |
| 危机 | 缺陷与需求正面冲突 | 必须选择 | 两难之境 |
| 高潮 | 做出选择 | 需求优先于缺陷 | 行动证明 |
| 结局 | 缺陷被克服/转化 | 需求得到满足 | 领悟完成 |
