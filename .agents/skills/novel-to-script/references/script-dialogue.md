# 剧本写作规则参考文档：对白创作

> 适用场景：AI辅助生成对白、优化台词、设计潜文本、避免AI味对白
> 核心目标：创造具有戏剧性、潜文本丰富、符合人物个性的对白

---

## 〇、创作方向（优先于所有规则）

> 以下三个原则是驱动对白写作的发动机。规则防止写坏；这些原则驱动写好。

### 0.1 每个场景有一个隐藏的问题

写对白之前，先确定这个场景里有一个**不能被直接说出的核心问题**。

所有台词，都是围绕这个问题兜圈子——接近它，回避它，假装它不存在，或用另一个话题掩盖它。这个兜圈子的过程就是潜文本的来源。

如果一个场景里所有话语都能直接说、都能直接回答，这场戏在戏剧性上往往失败。

**操作方法**：
1. 写对白前先写一行隐藏问题（不出现在剧本里）：「这场戏真正的问题是：___」
2. 检查每一句台词：它是在接近这个问题，还是在回避它？
3. 没有与隐藏问题发生任何关系的台词，通常可以删掉。

**示例**（余准/艾伯特场景）：
```
表面话题：关于彭㝡的迷宫
隐藏问题：你是谁，你真正来这里干什么
```
这个隐藏问题一旦确立，台词的写法会完全不同——每句话都带上了另一层含义。

### 0.2 欲望的不对称是张力的来源

台词之所以有力量，不是因为简短，也不是因为有个性，而是因为两个角色**想要的东西不能同时被满足**。

这个不对称性越大，台词的张力越强：
- A 想要被信任，B 的职责是保持怀疑
- A 想要消失，B 的存在让他必须现身
- A 想要亲近，B 的角色是无法真正被亲近的人

**写对白之前，先确认**：
- 角色A在这场戏里想要什么？
- 角色B在这场戏里想要什么？
- 两者的欲望方向是否有结构性冲突？

如果两人想要的东西可以互相兼容，台词就是平的。

### 0.3 规则的层级：什么时候限制，什么时候放手

**硬规则（任何情况不可违反）**：
- 禁止"写在鼻子上"（角色直接说出内心的真实意图或感受）
- 禁止"掸桌子式解说"（两人向对方复述彼此都知道的信息）
- 禁止向观众而非向对方说话

**软规则（默认执行，可有意打破）**：
- 台词简短（某些人物的冗长本身就是性格——喋喋不休是一种权力姿态）
- 避免完整句式（某些角色的正式感是人物标签）
- 单一话题（某些场景中角色故意岔开话题是潜文本策略）

**创作方向（不是规则，是追求）**：
- 每句台词都在做事（争夺、试探、防御、掩盖）
- 场景结束时，某样东西发生了变化
- 观众在角色说完话之后，感受到了比台词更多的东西

## 一、对白本质认知

### 1.1 对白不是对话 (Dialogue is not Conversation)

| 维度 | 现实对话 | 剧本对白 |
|------|----------|----------|
| **性质** | 随意、无方向 | 经过编辑、有目的 |
| **内容** | 充满赘言（"嗯"、"啊"） | 精简、聚焦 |
| **功能** | 社交交流 | 推动戏剧、揭示人物 |
| **追求** | 现实 | 可信（戏剧化真实） |

**核心原则**：剧本对白是"经过剪辑的言语"，必须有方向、有目的，并服从于戏剧结构。

### 1.2 视觉媒介中的"二等公民"

**黄金比例**：电影是 80% 视觉，20% 听觉

**创作优先级**：
1. **第一选择**：视觉形象（动作、表情、画面）
2. **第二选择**：对白（不得已时才使用）

**禁止约束**：
- 禁止用对白解释本应通过视觉展示的内容
- 禁止大段独白替代画面叙事
- 禁止"谈话脑袋"（无动作背景的纯对话）

## 二、对白创作核心技法

### 2.1 精简与节奏 (Lean and Rhythm)

**基本原则**：每个对白块表达一个思想，台词要有方向，不要废话。

**长台词处理**：长台词必须通过动作、神态或对方的反应岔开，不允许连续大段独白不间断。每次岔开是一个自然的分镜切换机会：

```
✓ 正确——用动作岔开：
艾伯特
彭㝡最后一封信里说，有一天会有人来。

他走到书架边，抽出一本线装书。

艾伯特
他说那个人会认识迷宫的入口。
（停顿，把书递过去）
您认识吗？

❌ 错误——不间断独白：
艾伯特
彭㝡最后一封信里说，有一天会有人来。他说那个人会认识迷宫的入口。您认识吗？这是他留下的书，里面有答案。您可以看一看。
```

**掉尾句/悬念句**：将核心意义延缓到最后一个字，迫使观众必须听完：
```
错误：我觉得我们应该离开这里，因为情况很危险。
正确：如果我们再待下去——（停顿）——恐怕就走不了了。
```

### 2.2 信息型场景对白的转化

> 这是AI对白最常见的失败点。当场景功能是"解释背景"时，最危险的写法是让角色直接传递信息。

**"掸桌子"式解说的根本问题**：角色在向观众说话，而不是在向对方做什么事情。

**转化三步法**：
1. **给角色一个此刻使用这些信息的动机**：他为什么要在这个时刻说这件事？他想用它达到什么目的？
2. **让对方制造阻力**：对方不是被动的接收者，他有自己的反应、怀疑、或对抗
3. **让信息在压力下披露**：信息不是完整传递的，而是被打断、被质疑、被利用

```
❌ 掸桌子式（错误）：
艾伯特
彭㝡毕生有两件未竟的心愿。一是写一部比《红楼梦》更宏大的小说。
二是建造一座没有人能走得出来的迷宫。他临终时说，这两件事他都完成了。

余准
那意味着什么？

✓ 信息作为武器（正确方向）：
艾伯特看着余准，停顿了很长时间。

艾伯特
您来这里，是为了参观花园，还是为了别的事？

余准没有回答。

艾伯特
（继续，语气平静）
彭㝡最后一封信里说，有一天会有人来。他说那个人会认识迷宫的入口。
```

### 2.3 将解说转化为"弹药" (Dialogue as Ammunition)

信息是武器，不是说明书。让角色利用已知事实去争夺他想要的东西：

```
错误：
MARY
我们结婚十年了，记得吗？我们在橡树下举行的婚礼。

正确：
MARY
十年了。那棵橡树——（冷笑）——你说过它会见证我们的未来。
```

### 2.4 解说释放的"需求原则"

- 除非缺失该信息会导致观众困惑，否则绝不提前交代
- 将最重要的信息（秘密）留到最后
- 在压力最大的时刻披露，创造爆炸性转折点

## 三、潜文本创作 (Subtext)

### 3.1 冰山理论 (Iceberg Theory)

```
          [文本 - 露出水面的10%]
                  角色说的话
                      ↑
    [潜文本 - 水下的90%]
    真实思想、情感、欲望、动机
```

伟大的对白往往"另有所指"。文本是表面，潜文本是真实战场。

### 3.2 压力场景中的潜文本

当场景中存在某种"角色隐瞒的秘密"时，对白完全不同：

**隐瞒秘密 × 表面礼貌 = 最强的潜文本**

- 角色说的话与他想做的事之间必须有可见的张力
- 通过**话题的选择**暗示秘密：他为什么聊这个，而不是那个？
- 通过**回避**制造潜文本：他没有回应对方提出的问题
- 沉默有时比任何台词更有力量

潜文本的强度与风险成正比：如果角色在场景中的代价很低，潜文本就是弱的。

### 3.3 潜文本创作五技法

**技法一：禁止"写在鼻子上"**
```
❌ 错误：
JOHN
我爱你，玛丽。我无法想象没有你的生活。

✓ 正确：
JOHN
（拿起工具）
这个扳手——（递给她）——你比我用得顺手。
```

**技法二：将信息转化为弹药**
真实的战场在潜文本，文字只是博弈手段。

**技法三：借物喻情（置换法）**
让角色讨论看似无关的琐事，实则通过话题表达爱意、威胁或权力博弈。
案例：《双重赔偿》中通过"车速限制"进行危险的性挑逗试探。

**技法四：言语作为面具**
角色可以说谎、掩饰、夸张或自欺。当文本是谎言时，真实在矛盾中凸显。

**技法五：反衬法（Counterpoint）**
角色谈论与情感状态"反衬"的话题。在谈无关痛痒的小事时，通过动作展现波涛汹涌的情感。

### 3.4 潜文本强度检验

**检查机制**：
1. 确定角色的「场景目标」（自觉欲望）
2. 挖掘其「真实目标」（不自觉欲望）
3. 如果两者完全重合，重写对话以留出潜文本空间

## 四、角色声音塑造

### 4.1 声音的八个维度

| 维度 | 说明 |
|------|------|
| **文本** | 字面意思 |
| **潜台词** | 真实含义 |
| **语法和句法** | 断句 vs. 完整长句 |
| **词汇量** | 专业术语 vs. 通俗词汇 |
| **口音/方言** | 地域俚语、发音习惯 |
| **俚语** | 特定群体用语 |
| **专业术语** | 职业词汇 |
| **说话风格** | 节奏、句长，简练如断奏 vs. 优雅抒情 |

### 4.2 标签法 (Tagging)

给角色贴上心理或社会标签，确保每一行台词都反映出这一特质：

```
标签：控制欲强的CEO

❌ 错误：
BOSS
我觉得这个方案可能需要再考虑一下。

✓ 正确：
BOSS
（看着手表）
我给你三十秒。说服我，或者走人。
```

### 4.3 交换测试

将A角色的台词给B角色读。如果台词依然成立且没有违和感，声音缺乏独特性。每个角色的台词应该"只有TA能说出"。

### 4.4 警惕"作者的话"

**警告信号**：
- 角色说话过于正式，全用完整句式
- 所有角色听起来都像同一个人
- 使用作者喜欢的词汇而非角色会用的词

## 五、对白"七宗罪" (必须规避)

| 死罪 | 定义 | 修正方法 |
|------|------|----------|
| **明显的解说** | 角色向观众而非彼此传递信息 | 转化为"弹药"在冲突中使用 |
| **过度写作** | 使用超过角色需要的词汇 | 删减50%，保留核心 |
| **情绪夸张** | 频繁感叹号、动辄大哭 | 让角色克制情感而非宣泄 |
| **日常寒暄** | "你好"、"再见"等废话 | 直接进入冲突 |
| **不必要的重复** | 重复观众已知信息 | 信任观众的记忆 |
| **无潜文本空间** | 直白说出内心想法 | 使用反衬、置换技法 |
| **陈词滥调** | 使用其他电影中的台词 | 原创表达 |
| **完全句式** | 说话过于正式、无口语感 | 使用断句、省略、口语化 |

## 六、经典案例参考

### 6.1 高效精简案例

**《亡命天涯》**：
```
金布尔：我是无辜的！
杰拉德：我不在乎。
```
简洁有力，直接体现角色的职业冷酷感。

**《逃离亚卡拉》**：
```
典狱长：你童年怎么样？
查理：短。
```
极端简练刻画冷峻人物形象。

### 6.2 潜文本运用案例

**《唐人街》**：
```
伊芙琳：她是我妹妹，也是我女儿。
```
文本：揭露丑闻。潜文本：绝望的呼救——"请救救我们"。

**《双重赔偿》**：
文本：讨论州内"车速限制"。潜文本：进行危险的性挑逗和犯罪合作试探。

**《公主新娘》**：
文本："如你所愿"（As you wish）。潜文本："我爱你"。

## 七、AI参考注意事项

### 生成前必须回答的问题

在开始写对白之前，先确认：
- [ ] **这场戏隐藏的问题是什么？**（不能被直接说出的核心张力）
- [ ] **角色A想要什么？角色B想要什么？两者是否有结构性冲突？**
- [ ] **这场戏里有没有信息要传递？** 如果有，谁用这些信息做武器，对抗什么？
- [ ] **这场戏结束时，什么发生了变化？**
