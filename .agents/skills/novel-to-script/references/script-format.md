# 剧本写作规则参考文档：剧本结构与格式规范

> **用途**：辅助 AI 生成符合电影剧本标准的文本结构，确保内容可被下游分镜工作流（Storyboard AI）稳定解析。
> **原则**：只描述"内容应该是什么"，不规定字体、排版、页边距等印刷格式。

---

## 一、剧本的三大构成元素

每个场景由三类内容组成，缺一不可：

| 元素 | 功能 | 内容原则 |
|------|------|----------|
| **场景标题** | 界定时空，作为解析锚点 | 编号 + 室内外 + 具体地点 + 时间 |
| **叙述性描写** | 视觉叙事，描述动作与环境 | 只写可见可听的内容，禁止内心描述 |
| **对白块** | 角色言语，推动戏剧 | 简洁、有潜文本、有角色个性 |

---

## 二、场景标题规范

### 2.1 标准格式

```
SC_编号 INT./EXT. 地点名称 - 时间
```

**示例**：
```
SC_001 INT. 茶馆 - 日
SC_002 EXT. 码头 - 夜
SC_003 INT./EXT. 行驶中的汽车 - 日
```

### 2.2 各字段规则

**场景编号（SC_XXX）**
- 格式：`SC_` + 3位数字，全局递增
- 必须存在，这是分镜工作流切分场景块的唯一锚点
- 禁止重复

**室内外标识**
- `INT.` = 室内
- `EXT.` = 室外
- `INT./EXT.` = 两者之间快速切换（如车内、门口）

**地点名称**
- 必须具体（"茶馆"而非"某处"，"李宅书房"而非"房间"）
- 同一地点跨场次保持命名一致（分镜工作流依赖此识别同一空间）

**时间标注**
- 常规：`日` 或 `夜`
- 特殊（必要时才用）：`黄昏`、`黎明`、`CONTINUOUS`（紧接上场）、`LATER`（同地稍后）
- 闪回：加 `- 闪回` 后缀

### 2.3 禁止内容

- 禁止在场景标题中加氛围描写（"阴暗的茶馆"）
- 禁止摄影机指令（CLOSE UP, PAN, ZOOM IN 等）
- 禁止剪辑指令（CUT TO, DISSOLVE TO 等）

---

## 三、叙述性描写规范

### 3.1 基本原则

**可拍摄性**（最高优先级）：
- 只描写观众能**看见**或**听见**的内容
- 禁止描写人物内心想法、感受、回忆、意识流
- 禁止抽象比喻和文学性修辞

**时态**：必须使用**现在时态**（正在发生，不是曾经发生）

**语态**：使用主动语态，避免被动句

### 3.2 精简原则

- 每段最多 4 行，建议 1-2 行
- 每段只描述一个动作节拍或视觉形象
- 禁止大段环境介绍，用细节暗示整体

**对比示例**：
```
❌ 错误：
约翰走进了房间，这是一个很大的空间，他感到非常不安，
不知道接下来会发生什么，但他下定了决心要查清真相。

✓ 正确：
约翰推开门。

房间空旷。一把椅子，一张桌子。阳光从百叶窗缝隙射入。

他深吸一口气，走向桌子。
```

### 3.3 动词与名词选择

**动词**：用具象动词代替模糊动词
- ❌ 避免：walk slowly, move, look at
- ✓ 使用：stagger（踉跄）、glide（滑行）、dart（飞速瞥向）

**名词**：用具象名词代替泛指名词
- ❌ 避免：大钉子、工具、一样东西
- ✓ 使用：铁钉、钳子、折叠刀

### 3.4 暗示镜头（隐形视觉引导）

通过描写内容自然引导视觉焦点，不写摄影机指令：

```
❌ CLOSE UP on the letter.（直接指令）

✓ 一封信躺在桌上，邮戳模糊不清。（内容暗示特写）
```

```
❌ PAN across the room.

✓ 房间里一片狼藉——翻倒的椅子，破碎的玻璃，散落的文件。（内容暗示全景）
```

具体可参考script-narrative文档

## 四、对白块规范

### 4.1 结构

对白块必须使用**代码块**格式（用三个反引号包裹），并在代码块内保持4空格缩进，使视觉上与叙述段落有明确区隔：

````
```
    角色名（全大写）
    （插入语，可选）
    对白内容
```
````

**示例**：
```
    陈逸
    （低声）
    就是这里。
```

### 4.2 角色名规则

- 全大写（如 `JOHN`、`陈逸`）
- 全剧保持同一拼写，不可变化
- 角色**首次出场**时，名字后加简要说明，写在对白块内：`陈逸（四十岁，风衣）`

**特殊标识**：
| 标识 | 含义 |
|------|------|
| `(O.S.)` | 角色在现场但不在画面内 |
| `(V.O.)` | 旁白、电话、画外音 |
| `(CONT'D)` | 同一角色对白被动作中断后继续 |

### 4.3 插入语规则

- 仅在对白含义可能产生歧义时使用
- 简短：1-2 行，描述说话时的动作或语气
- 禁止：重复对白已表达的情绪，禁止描述另一角色的动作

```
    玛丽
    （轻声）
    我从来没有怪过你。
```

❌ 滥用示例：
```
    玛丽
    （非常悲伤，眼含泪水，几乎说不出话来）
    我从来没有怪过你。
```

### 4.4 对白内容规则

- 不使用引号
- 精简：理想 1-2 句，避免长篇独白
- 使用"掉尾句"：将核心意义放在最后一个字
- 破折号（--）用于中断或急转，省略号（…）用于停顿或拖尾

具体可参考script-dialogue文档

## 五、视觉档案与场景基准（下游接口）

> 这两个结构是剧本层向分镜工作流传递的**视觉合约**。
> 规则：只描述"是什么"，不规定画面风格、美术方向、镜头处理方式。
> **格式要求**：【角色视觉档案】、【场景视觉基准】、【场景元数据】均必须使用代码块格式输出，不得以纯文本形式书写。

### 5.1 角色视觉档案

**触发条件**：每个主要角色**首次出场**时，在叙述性描写段落中插入以下代码块。

```
【角色视觉档案】
角色名：
性别/大致年龄：
身形体态：（高矮/体型，一句话）
面部特征：（最多3个可识别特征）
发型发色：（颜色+长度+风格）
标志性服装/装扮：（贯穿全剧的固定形象）
标志性动作/习惯：（1-2个，用于角色辨识）
标志性随身物件：（如有）
```

**填写原则**：
- 具体可画：用可量化词（"寸头"而非"短发"，"颧骨偏高"而非"有特点的脸"）
- 只描述视觉上稳定不变的特征，不描述情绪状态
- 禁止风格词汇（"冷酷的外表"、"俊朗的气质"）

### 5.2 场景视觉基准

**触发条件**：每个主要地点**首次出现**时，在场景标题下方插入以下代码块。

```
【场景视觉基准】
地点代码：（与场景标题一致）
空间性质：（室内/室外，开放/封闭，大/中/小）
基本布局：（1-2句，空间形状和功能区）
光线默认状态：（白天/夜晚，自然光/人工光）
固定视觉标志物：（至少3个具体物件，是识别该空间的锚点）
可变元素：（随时间/情节变化的部分）
```

**填写原则**：
- 固定视觉标志物必须具体（"角落里挂着的破日历"而非"有些装饰品"）
- 至少 3 个标志物，供分镜 AI 在任意镜头中保持空间连贯
- 不描述风格、色调、氛围

### 5.3、场景元数据（必填，每场景）

**触发条件**：每个场景标题下方，紧接【场景视觉基准】（如有）之后，叙述正文之前。必须使用代码块格式。

```
【场景元数据】
出场人物：（按戏份排序，全大写，英文逗号分隔）
叙事功能：（一句话说明本场景在全剧中的结构作用）
主要动作：（本场景中角色的核心物理动作，2-3个）
情绪基调：（表层情绪 + 内在张力，格式：「表面X，内在Y」）
隐藏问题：（本场景中不能被直接说出的核心张力，一句话；纯动作场景可省略）
叙述节奏：（快/中/慢，与前一场景的节奏对比）
```

**填写原则**：
- **出场人物** 决定分镜 AI 跟踪的镜头主体，必须包含所有有台词或显著动作的角色
- **叙事功能** 帮助分镜 AI 做镜头优先级判断（哪个动作最重要）
- **主要动作** 控制分镜的动态密度和节奏
- **情绪基调** 控制画面风格生成方向
- **隐藏问题** 为AI生成对白提供潜文本锚点；对话场景必须填写
- **叙述节奏** 控制AI生成叙述描写时的段落密度和句长策略

**示例**：
```
【场景元数据】
出场人物：陈逸, 老板娘
叙事功能：建立主角与线索人之间的初始张力，暗示过去关联
主要动作：陈逸进门点餐，老板娘辨认面孔，两人有意回避对视
情绪基调：表面平静日常，内在高度戒备
隐藏问题：两人曾有过什么关联，谁也不愿先开口
叙述节奏：中，比前一场景（逃跑）明显放慢
```

## 六、特殊场景元素

### 蒙太奇

```
SC_012 EXT. 城市街道 - 日

蒙太奇开始：

-- 约翰在地铁里被人群挤着走

-- 约翰盯着办公室电脑屏幕发呆

-- 约翰独自坐在公园长椅上

蒙太奇结束。
```

### 插入镜头

```
INSERT - 信封上的邮戳

模糊的日期：1945年8月6日

回到场景：
```

### 字幕

```
SUPER: 上海，1937年冬
```

或

```
TITLE CARD: 三天后
```

## 七、AI生成规范

### 必须包含

- [ ] 每个场景标题以 `SC_XXX` 开头（数字递增，不跳号）
- [ ] 主要角色首次出场时附【角色视觉档案】**代码块**
- [ ] 主要地点首次出现时附【场景视觉基准】**代码块**
- [ ] 每场景叙述正文前附【场景元数据】**代码块**
- [ ] 所有对白块使用**代码块**格式，内容4空格缩进
- [ ] 叙述性描写使用现在时态
- [ ] 动作描写具体可拍摄

---

## 八、完整格式示例

````
SC_001 EXT. 街道 - 日

繁忙的街道。行人匆匆。

一辆黑色轿车急停在路边。

```
    司机 (O.S.)
    到了。
```

车门打开。陈逸（四十岁，棕色长风衣）走下车。

```
【角色视觉档案】
角色名：陈逸
性别/大致年龄：男，40岁左右
身形体态：中等偏高，略显消瘦，走路有轻微驼背
面部特征：眼角有细纹，颧骨偏高，嘴唇薄
发型发色：黑色，微卷，略显凌乱，耳上留长
标志性服装/装扮：棕色长款风衣，白衬衫，皮鞋永远亮
标志性动作/习惯：说话时无意识地摸左手手背
标志性随身物件：旧款翻盖手机，从不换新
```

他环顾四周。目光落在对面大楼上。

```
    陈逸
    （低声）
    就是这里。
```

他穿过街道。

SC_002 INT. 大厅 - 日（CONTINUOUS）

```
【场景视觉基准】
地点代码：INT. 大厅
空间性质：室内，开放，大型
基本布局：开阔前台区，左侧电梯间，右侧休息区
光线默认状态：冷色调人工光源
固定视觉标志物：
  - 前台后墙的银色金属抽象雕塑
  - 休息区三组对称摆放的黑色真皮沙发
  - 能倒影人脸的白色大理石地面
可变元素：工作时段有大量白领进出
```

```
【场景元数据】
出场人物：陈逸, 前台
叙事功能：建立主角与线索人之间的初始张力，暗示过去关联
主要动作：陈逸进门扫视、前台辨认盘问、陈逸抛出暗语
情绪基调：表面日常礼貌，内在高度戒备
```

陈逸走进大厅。前台职员抬头看他。

```
    前台
    您好，请问有什么可以帮您？

    陈逸
    我找王先生。

    前台
    （看登记本）
    请问有预约吗？

    陈逸
    没有。但他会见我的。
```

他停顿了一下。

```
    陈逸 (CONT'D)
    就说——关于那批货的事。
```

前台犹豫了一下，拿起电话。
````
