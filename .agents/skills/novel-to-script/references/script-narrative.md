# 剧本写作规则参考文档：叙述性描写（Narrative Description）

> 适用场景：AI生成剧本叙述性描写（Action）段落
> 核心目标：描述摄影机能看见的和话筒能听见的，同时为下游 AI 分镜生成提供足够丰富的画面信息
> **下游用途**：本剧本直接供 AI 分镜（storyboard）生成使用，而非人类拍摄现场。这意味着：神态、姿态、空间关系、光线氛围等细节是有价值的，应充分写出；过度的简洁反而会让分镜 AI 缺少依据。

---

## 〇、创作方向（优先于所有规则）

### 0.1 描写什么，等于确立什么

摄影机面前永远有无数可以描写的东西。编剧的工作是**选择**。

- **描写什么细节** → 确立这个细节在这个场景里的重要性
- **描写的顺序** → 确立视觉的优先级和情绪走向
- **停留多长时间** → 确立这件事对人物的冲击程度

测试一个细节是否值得写：它服务于**人物**、**情节**或**主题**中的哪一个？三者皆无则删。

### 0.2 节奏是情感的唯一合法载体

禁止写情绪，但情绪必须到达读者。它的通道是节奏：

- **句子的长短**：短句制造紧张；长句制造流动
- **段落的间距**：空行是呼吸、停顿、情绪余震
- **动作的密度**：连续动作制造推进感；单个动作加空行制造重量

### 0.3 形象系统是主题的地基

在全剧叙述中植入一类重复出现的视觉或听觉意象，让读者**感受**而非**察觉**主题。

---

## 一、硬规则（任何情况下不可违反）

这些是媒介属性的约束，违反则根本性破坏剧本的可拍摄性：

| 禁止 | 原因 | 正确做法 |
|------|------|----------|
| 描写人物内心想法、感受、回忆 | 摄影机无法拍摄 | 转化为外部动作或物件 |
| "他感到绝望"、"她意识到这是陷阱" | 情绪/认知告知 | "他的手停在枪上，没有拔"；"她的目光移向出口" |
| "我们看见/我们听见" | 作者介入 | 直接描写：一个陌生人走进来 |
| "写在鼻子上"（解释动作含义） | 破坏潜文本 | 让动作本身说话 |
| 摄影机指令（CLOSE UP, PAN等） | spec剧本禁用 | 通过描写细节引导视觉焦点 |
| 非现在时态 | 电影是绝对现在时 | 全程现在时 |

**注意**：外显的情绪状态描写是允许的。
- ❌ "他感到恐惧"（内心告知）
- ✓ "他的手指停在桌沿，微微发抖"（外显状态）
- ✓ "她的嘴角绷紧了一下，随即放开"（神态，可拍摄）

## 二、分段原则

**按情节节拍（beat）分段**，一段描写一个连续动作序列或一个主要视觉焦点。不规定行数上限。

段落之间用空行分隔，空行本身是节奏工具——不要省略，也不要滥用。

```
达尔曼推开门，跨过门槛。

门外：星空。平原。黑暗一直延伸到看不见的地方。

酒馆的灯光从他背后漏出来，照亮他脚下几步，他继续往前走，走进那片光照不到的地方。
```

## 三、动词与名词精准化

### 3.1 具象动词

用本身携带情感色彩或状态信息的动词，避免模糊动词：

| 场景 | 模糊动词 | 具象替换 |
|------|----------|----------|
| 疲惫、受伤 | 走 | 踉跄、拖行、一瘸一拐 |
| 谨慎、侦查 | 移动 | 贴墙挪动、蹑手蹑脚、摸索 |
| 傲慢、强势 | 进来 | 大步迈入、径直走向 |
| 犹豫、恐惧 | 停 | 退缩、冻住、迟疑 |
| 急迫、逃跑 | 跑 | 冲出、飞奔、夺门而出 |

### 3.2 具象名词

避免泛指名词：不写"一件东西"，写"一把折叠刀"；不写"喝的"，写"一杯冷掉的茶"。

### 3.3 副词处理

副词通常是动词选择不精准的结果。优先替换为更精确的动词：
- ❌ 他慢慢地走
- ✓ 他拖着步子走

但当副词本身携带特定语气或节奏时（如"轻轻"、"猛地"），允许保留。

## 四、分镜友好的描写（本剧本特有要求）

以下内容服务于下游 AI 分镜生成，**应充分写出，不要过度省略**：

- **人物表情与神态**：眼神方向、嘴角状态、眉头动作
- **说话时的姿态**：身体朝向、手的位置、与对方的距离
- **人物之间的空间关系**：谁站着谁坐着、靠近还是保持距离
- **场景的光线质感**：从哪里来、是什么颜色、照在谁身上
- **情绪氛围**：通过环境细节和人物状态描写，而非直接命名情绪

```
✓ 分镜友好的写法：
店主抬起头，看了达尔曼一眼——不是打量，是确认。
他把抹布搭在肩上，两手撑着柜台。

✓ 也是分镜友好的：
达尔曼坐下，背对着那桌年轻人。
他倒红酒，手稳，没有抖。
```

## 五、节奏类型

不同场景使用不同节奏模式，全剧节奏不得均速。

**动作堆叠**（快节奏）：
```
他转身。
拔枪。
对准门口。
什么都没有。
枪慢慢放下。
```

**感知积累**（中节奏）：
连续的感知细节（声、光、温度、触感），不加说明，让读者神经系统自己生成情绪：
```
泥土路往下坡延伸。
梣树在两侧高耸，树枝在头顶交叉，封住大半夜空。
月亮挂在树干后，时隐时现。
远处，胡琴的声音。
```

**流动叙述**（慢节奏）：
允许连贯的复合句，适用于开场建立或情绪沉淀时刻：
```
城市在窗外展开。高楼，灯光，烟雾——一切距离余准都非常遥远。
```

## 六、暗示镜头

不写摄影机指令。通过描写细节本身引导视觉焦点：

- 描写什么，读者/分镜AI就聚焦在那里
- 新段落 = 新的镜头节拍
- 全景与细节分段书写，引导"剪辑"感

```
街道空旷。正午的阳光压在石板路上。

远处，一扇门开了。

一只皮鞋踏出门槛。鞋底发亮。
```

## 七、生成前必须确认

- [ ] 这个场景里最重要的物件/动作是什么？（服务人物/情节/主题中的哪个？）
- [ ] 这个场景的节奏：快（堆叠）/ 中（积累）/ 慢（流动）？
- [ ] 与前后场景的节奏对比是什么？
- [ ] 有哪些神态/姿态/空间关系需要写清楚，以便分镜生成？
