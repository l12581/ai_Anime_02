# 剧本写作规则参考文档：剧情设计与节奏

> 适用场景：AI辅助生成故事大纲、剧情转折点设计、节奏把控
> 核心目标：确保剧情结构完整、节奏合理、转折有力
> ⚠️ 核心原则：本文档为指导 AI 生成符合优秀电影剧本标准的故事结构而设，内容剥离了人类编剧的物理页数概念，所有结构比例均以**场景总数或剧情推进的百分比**为衡量尺度。

---

## 一、三幕式结构（The Three-Act Structure）

### 1.1 结构比例
| 幕次 | 名称 | 场景/篇幅占比 | 核心功能 |
|------|------|---------------|----------|
| 第一幕 | 建置 (Setup) | 约 25% | 建立人物、戏剧前提、戏剧情境 |
| 第二幕 | 对抗 (Confrontation)| 约 50% | 进展纠葛，逐步升级的冲突 |
| 第三幕 | 结局 (Resolution) | 约 25% | 危机决策、高潮摊牌、情感回报 |

### 1.2 第一幕：建置
**核心任务**：在开场 10% 的篇幅内完成三件事——介绍主要人物、确立戏剧前提、交代戏剧情境。

**关键要素**：
- **激励事件 (Inciting Incident)**：打破主人公生活平衡的第一个重大事件，通常出现在前 10%-15%。
- **情节点 I (Plot Point I)**：发生在约 25% 处，将主人公钩入第二幕的"不归点"。

**最佳实践**：
- 激励事件必须提出一个"戏剧大问题"，激发观众好奇心。
- 通过具体的视觉场景和人物动作建立调性、地点和类型，而非依赖画外音解说。
- 迅速建立观众与主人公的"移情纽带"（让观众看到人物的动机和脆弱）。

**禁止约束**：
- 禁止开场进行大量背景信息倾倒（Exposition Dump）。
- 禁止让角色通过对白解释彼此已知的事实（"掸桌子"式解说）。
- 禁止延迟主情节的引入。

### 1.3 第二幕：对抗
**核心任务**：主人公在追求目标过程中面对越来越强大的对抗力量。

**关键要素**：
- **中点 (Midpoint)**：位于剧情 50% 处，重大剧情逆转，人物从被动应对转为主动出击。
- **情节点 II (Plot Point II)**：发生在约 75%-85% 处，将故事推入第三幕的低谷或转折。
- **鸿沟技法 (The Gap)**：主观期望与客观结果之间的断层，推动故事能量。

**最佳实践**：
- 通过"鸿沟"不断制造意外，迫使人物采取更具风险的行动。
- 利用转折点控制紧张度的起伏（张弛有度），避免单调的线性上升。
- 设置"不归点"确保故事绝不退回轻量级行动。

**禁止约束**：
- 禁止让主人公轻易解决问题，障碍和赌注必须逐步升级。
- 禁止在第二幕出现"水剧"（缺乏价值转折的凑数场景）。
- 禁止解决冲突的外力介入（机器神仙）。

### 1.4 第三幕：结局
**核心任务**：完成绝对且不可逆转的变化，交付情感的最终回报。

**关键要素**：
- **危机 (Crisis)**：故事最紧张的点，主人公面临"两难之境"（通常在第二幕结尾或第三幕开头）。
- **高潮 (Climax)**：由危机直接产生的最后动作，导致不可逆转的价值转换。
- **领悟 (Realization)**：主人公意识到自己的成长或变化。

**最佳实践**：
- 高潮必须"不可避免而又出乎意料"——逻辑上是激励事件的必然结果，但表现方式令人惊喜。
- 创造总结所有意义的"基调视觉形象" (Key Image)，为下游分镜提供极具冲击力的核心画面。
- 结尾与开端在视觉或情境上形成呼应，确证变化。

**禁止约束**：
- 严格禁止"机械降神" (Deus ex machina) ——利用纯粹的巧合、自然灾害等外力强行解决危机。
- 禁止高潮依赖解释性对白来阐明意义，必须通过可视化的动作来完成。
- 禁止将核心危机放在画外轻描淡写地处理。

## 二、七大关键转折点（The Magnificent 7）

| 转折点 | 位置 | 功能 | 检验标准 |
|--------|------|------|----------|
| **1. 背景故事 (Backstory)** | 故事开始前 | 解释人物当前态度和行为的心理根源 | 是否与当下目标有直接阻碍关系？ |
| **2. 诱发因素 (Catalyst)** | 前 10-15% | 打破生活平衡，提出戏剧大问题 | 是否激发恢复平衡的强烈欲望？ |
| **3. 重大事件 (Big Event)** | 约 25% | 不归点，将主人公钩入第二幕 | 是否改变人生方向且无法回头？ |
| **4. 中点 (Midpoint)** | 约 50% | 重大逆转，赌注加码 | 人物是否从此主动投入？ |
| **5. 危机 (Crisis)** | 约 85% | 终极两难选择 | 是否是真正的、且必须由主角做出的两难之境？ |
| **6. 摊牌/高潮 (Showdown)** | 第三幕 | 最后对峙，解决核心冲突 | 是否产生了绝对不可逆转的视觉化变化？ |
| **7. 领悟 (Realization)** | 高潮后 | 成长的证明，情感补偿 | 是否回应了开篇设定的内在缺陷/需求？ |

### 2.1 背景故事处理规范
**核心概念**：过往创伤 → 性格缺陷 → 内心需求

**最佳实践**：
- 将背景故事转化为推进当前戏剧动作的"弹药"（筹码）。
- 通过"揭示" (Revelation) 在压力最大的时刻酌量释放背景信息。
- 延迟满足：只有当观众产生"为什么"的好奇心时，才释放相关的背景事实。

**禁止约束**：
- 禁止在故事开头一次性提供过多背景信息。
- 禁止背景故事与当下任务无关（无效的设定）。
- 禁止滥用闪回，尤其是没有信息增量、纯为煽情的闪回。

### 2.2 诱发因素设计规范
**核心机制**：偶然（天降横祸/天赐洪福）或 决定（重大抉择），必须通过**动作或事件**呈现。

**最佳实践**：
- 必须是动态的、视觉化的事件
- 引发的风险必须涉及失去极其宝贵的事物
- 激活的对抗力量应随进展不断积聚

**禁止约束**：
- 禁止静态的信息倾倒
- 禁止与高潮无因果关联的随机事件

### 2.3 两难之境设计规范
**类型一：不可调和的两善取其一**
- 主人公想要两样东西，环境迫使只能选择其一

**类型二：两恶取其轻**
- 主人公面对两个都不想要的结果，必须选择其一

**最佳实践**：
- 危机决定必须是有意而为的"静态时刻"
- 让观众直面人物做决定的痛苦
- 真正的危机揭示人物最深层的人格真相

**禁止约束**：
- 禁止虚假两难（存在明显更好的第三种选择）
- 禁止让危机在画外或轻描淡写地处理

## 三、节奏控制原则

### 3.1 进展纠葛 (Progressive Complications)
**定义**：当人物面对越来越强大的对抗力量时，产生越来越多的冲突

**最佳实践**：
- 对抗力量分三个层面设计：**内心冲突**、**个人冲突**、**个人外冲突**
- 每个冲突层面都应同时发生，形成复杂型故事
- 每一次行动都引发意想不到的反应

### 3.2 节奏调控技法
| 技法 | 说明 | 应用场景 |
|------|------|----------|
| 转折点锚定 | 用情节点I、中点、情节点II分割长幕 | 防止第二幕"软大肚子" |
| 次情节穿插 | 在主情节中插入次要情节线 | 调节紧张度，提供喘息 |
| 悬念类型切换 | 神秘→悬念→戏剧反讽的交替使用 | 维持观众注意力 |
| 价值负荷摆动 | 正负价值的交替转折 | 避免单向度的情感疲劳 |

### 3.3 悬念营造类型
| 类型 | 信息分配 | 效果 |
|------|----------|------|
| **神秘 (Mystery)** | 观众知道的比人物少 | 智力上的好奇 |
| **悬念 (Suspense)** | 观众与人物知道同样多 | 焦虑和关心 |
| **戏剧反讽 (Dramatic Irony)** | 观众知道的比人物多 | 对人物命运的担忧 |
