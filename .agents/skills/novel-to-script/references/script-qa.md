# 剧本写作规则参考文档：剧本质量检查

> 适用场景：AI生成剧本后的自检、质量评估
> 核心目标：系统性检验剧本的完整性、戏剧性和可拍摄性
> **说明**：所有结构比例检验以全剧场景总数为基准，不以页数计。

---

## 一、结构完整性检查

### 1.1 三幕结构检验

| 检查项 | 标准 | 通过标记 |
|--------|------|----------|
| **第一幕长度** | 约占全剧25%的场景 | ☐ |
| **第二幕长度** | 约占全剧50%的场景 | ☐ |
| **第三幕长度** | 约占全剧25%的场景 | ☐ |
| **激励事件位置** | 全剧前10-15%内出现 | ☐ |
| **情节点 I 位置** | 约在全剧25%处 | ☐ |
| **中点位置** | 约在全剧50%处 | ☐ |
| **情节点 II 位置** | 约在全剧85-90%处 | ☐ |
| **危机位置** | 第二幕结尾/第三幕开头 | ☐ |

### 1.2 七大转折点检验

| 转折点 | 检查问题 | 通过 |
|--------|----------|------|
| **背景故事** | 是否与当下目标有直接阻碍？ | ☐ |
| **诱发因素** | 是否打破平衡并提出戏剧大问题？ | ☐ |
| **重大事件** | 是否是不可回头的"不归点"？ | ☐ |
| **中点** | 是否标志从被动到主动的转变？ | ☐ |
| **危机** | 是否是真正的两难之境？ | ☐ |
| **摊牌/高潮** | 是否产生绝对不可逆转的变化？ | ☐ |
| **领悟** | 是否回应了内心需求？ | ☐ |

### 1.3 因果锁定检验
**核心原则**：激励事件与高潮之间必须有必然逻辑联系

**检查方法**：
1. 提取激励事件：_________________________
2. 提取高潮事件：_________________________
3. 验证逻辑：因为发生了A，所以必须发生B

**检验问题**：
- [ ] 如果删除激励事件，高潮是否还会发生？（应否）
- [ ] 高潮是否是激励事件的必然结果？（应是）
- [ ] 中间的所有转折点是否都推动故事向高潮发展？（应是）

## 二、角色塑造检验

### 2.1 主人公检验

**目标与动机**：
- [ ] 目标是否具体且可衡量？
- [ ] 动机是否具有强烈的私人色彩？
- [ ] 是否涉及真实的风险（失去宝贵事物）？

**缺陷与需求**：
- [ ] 是否有明确的性格缺陷？
- [ ] 是否有与缺陷对应的内在需求？
- [ ] 缺陷是否源于背景创伤？

**弧光检验**：
- [ ] 开场状态：_________________________
- [ ] 结局状态：_________________________
- [ ] 变化是否不可逆转？（应是）
- [ ] 变化是否通过压力和选择实现？（应是）

### 2.2 对手检验

- [ ] 对手是否有与主人公同样强烈的动机？
- [ ] 对抗力量是否分三个层面设计（内心/个人/个人外）？
- [ ] 对手是否足够强大，能将主人公推向能力极限？
- [ ] 对手是否有"善之中心"（可被理解的正面特质）？

### 2.3 角色关系检验

**对立统一体验证**：
- 主人公核心需求：_________________________
- 对手核心需求：_________________________
- 两者是否不可调和？（应是）
- 妥协是否对双方都是失败？（应是）

**移情检验**：
- [ ] 主人公是否有"善之中心"？
- [ ] 观众能否在主人公身上看到"像我"的特质？
- [ ] 主人公是否有脆弱性和不完美？

---

## 三、场景质量检验

### 3.1 场景必要性检验

对每个场景回答以下问题：

| 问题 | 是 | 否 |
|------|----|----|
| 该场景是否由人物的明确需求驱动？ | ☐ | ☐ |
| 该场景是否产生价值转折？ | ☐ | ☐ |
| 删除该场景是否会影响故事理解？ | ☐ | ☐ |
| 该场景是否推动故事越过"不归点"？ | ☐ | ☐ |

**淘汰标准**：如果所有答案都是"否"，该场景应删除或重写

### 3.2 场景结构检验

**鸿沟检验**：
- 人物采取的行动：_________________________
- 预期的客观结果：_________________________
- 实际的客观结果：_________________________
- 是否形成"鸿沟"？（预期与实际是否不同）

**冲突检验**：
- [ ] 场景是否包含对抗力量？
- [ ] 冲突是否在三个层面至少一个发生？
- [ ] 冲突是否推动人物采取下一步行动？

### 3.3 场景节奏检验

- [ ] 场景是否"开始得越晚越好"？
- [ ] 场景是否"结束得越早越好"？
- [ ] 场景内部是否有节奏变化（紧张-松弛）？
- [ ] 场景之间是否有适当的过渡？

## 四、对白质量检验

### 4.0 场景级对白前置检验

> 在逐行检查台词之前，先在场景级别确认以下问题。如果场景级别失败，台词层面的修改无济于事。

| 检验项 | 问题 | 通过标准 |
|--------|------|----------|
| **隐藏问题** | 这场戏中有没有一个不能被直接说出的核心张力？ | 必须存在 |
| **欲望不对称** | 两个角色想要的东西是否有结构性冲突？ | 必须存在 |
| **信息型场景** | 如果场景功能是"交代背景"，信息是否转化为角色的武器/筹码？ | 不是直接传递 |
| **场景变化** | 场景结束时，某样东西（权力/关系/处境）是否发生了变化？ | 必须有变化 |

**注意**：隐藏问题和欲望不对称是对白张力的结构性来源。如果这两项不存在，修改再多的台词措辞也无法解决根本问题——应重新设计场景。

### 4.1 对白七宗罪检查

| 死罪 | 定义 | 是否存在 | 修正 |
|------|------|----------|------|
| **明显解说** | 角色互相讲述已知事实 | ☐ | |
| **过度写作** | 词汇超过角色实际需要 | ☐ | |
| **情绪夸张** | 频繁感叹号、动辄大哭 | ☐ | |
| **日常寒暄** | "你好"、"再见"等废话 | ☐ | |
| **不必要重复** | 重复观众已知信息 | ☐ | |
| **无潜文本** | 直白说出内心想法 | ☐ | |
| **陈词滥调** | 使用老套表达 | ☐ | |

### 4.2 潜文本检验

**冰山理论应用**：
- 文本（所说）：_________________________
- 潜文本（所想/所感）：_________________________
- 两者是否一致？（应否，应有张力）

**检验方法**：
- [ ] 角色是否很少直白表达真实感受？（禁止"写在鼻子上"）
- [ ] 对白是否可作为争夺利益的"弹药"？
- [ ] 表面话题是否与真实话题形成反衬？
- [ ] 是否存在"掸桌子"式无效解说？（两人谈论彼此都已知的事实）
- [ ] 重要信息是否留到高压时刻才披露，而非提前交代？
- [ ] **信息型场景**：背景信息是否被转化为角色在压力下使用的武器，而非平静传递？
- [ ] **压力场景**：场景中存在的风险和秘密是否渗入了台词的选词和回避方式？

### 4.3 角色声音独特性检验

- [ ] **交换测试**：将A角色的台词给B角色读，是否依然成立？（若成立，声音无独特性）
- [ ] 遮住角色名，能否通过语言风格辨认角色？
- [ ] 每个角色是否有独特的词汇库和表达方式？
- [ ] 对白是否反映角色的教育背景和社会阶层？
- [ ] 是否存在所有角色都说"作者的话"的问题？

### 4.4 对白精简检验

- [ ] 对白是否尽可能简短（1-2句为理想）？
- [ ] 长对白是否分解为动作/反应交替？
- [ ] 是否可用视觉替代对白的段落？
- [ ] **朗读测试**：大声朗读是否流畅自然，无拗口感？

## 五、视觉叙事检验

### 5.1 "展示，不要告诉"检验

| 类型 | 存在问题 | 修正建议 |
|------|----------|----------|
| **情绪告诉** | "他感到很糟糕" | 改为面部/身体动作描写 |
| **背景告诉** | 对白解释过去 | 改为闪回或揭示 |
| **关系告诉** | 对白声明关系 | 改为互动展示 |
| **思想告诉** | "他认为..." | 改为可拍摄的动作 |

### 5.2 可拍摄性检验

**禁止内容检查**：
- [ ] 是否包含内心想法或意识流？
- [ ] 是否包含无法拍摄的抽象比喻？
- [ ] 是否使用"我们看见/听见"等提醒摄影机的表述？
- [ ] 是否描述角色的 realization 或顿悟过程？

### 5.3 形象系统检验

- [ ] 是否有重复出现的视觉/听觉形象类别？
- [ ] 形象是否与主题形成有意义的关联？
- [ ] 形象是否潜在地强化情感而非刻意说教？

## 六、格式规范检验

### 6.1 结构完整性检查

| 检查项 | 标准 | 通过 |
|--------|------|------|
| 场景编号 | 每场以 SC_XXX 开头，递增不跳号 | ☐ |
| 场景标题 | INT./EXT. + 具体地点 + 时间 | ☐ |
| 角色名 | 全大写，全剧命名一致 | ☐ |
| 叙述段落 | 每段不超过4行 | ☐ |
| 时态 | 现在时态 | ☐ |

### 6.2 视觉接口检查

- [ ] 主要角色首次出场是否附【角色视觉档案】**代码块**？
- [ ] 主要地点首次出现是否附【场景视觉基准】**代码块**？
- [ ] 每个场景叙述正文前是否附【场景元数据】**代码块**？
- [ ] 所有对白块是否使用**代码块**格式，内容是否有4空格缩进？
- [ ] 视觉档案是否只描述"是什么"，无风格词汇？

### 6.3 禁忌检查

- [ ] 是否包含摄影机角度（CLOSE UP, PAN等）？（应无）
- [ ] 是否包含剪辑指令（CUT TO, DISSOLVE等）？（应无）
- [ ] 是否包含内心描述（"他想"、"她感到"）？（应无）
- [ ] 是否使用了文学性/无法拍摄的描写？（应无）

### 6.4 叙述描写质检（新增）

**可拍摄性**：
- [ ] 是否包含"他想/她感到/他记得/她知道/他意识到"？（应无，全删）
- [ ] 是否包含"我们看见/我们听见"？（应无，全删）
- [ ] 是否有解释动作含义的句子？（应无，让动作自己说话）
- [ ] 是否有文学性修辞无法转化为画面？（应无）
- [ ] 是否存在纯装饰性的环境描写（与人物/情节/主题无关）？（应无）

**动词与名词精准度**：
- [ ] 是否有模糊动词未替换为具象动词（walk/move/look等）？（应替换）
- [ ] 是否有泛指名词未具象化（"东西"、"工具"等）？（应替换）

**节奏与选择**：
- [ ] **全剧节奏是否均速？** 快/中/慢场景是否有意区分？（均速是叙述的失败）
- [ ] **每个描写细节是否有选择意图？** 服务于人物、情节或主题中的至少一个？
- [ ] 快节奏序列是否使用了动作堆叠（每行一个动作）？

**分镜友好性**：
- [ ] 有对话的场景，说话时的姿态/神态/空间关系是否写清楚？
- [ ] 长台词是否用动作/神态/反应岔开？（不允许不间断大段独白）

**格式**：
- [ ] 是否全程使用现在时态？（应是）

### 6.5 插入语使用检查

- [ ] 插入语是否仅在必要时使用？
- [ ] 插入语是否过长（>2行）？
- [ ] 插入语是否重复对白已表达的信息？

## 六B、视觉档案与场景数量核对（改编剧本必须执行）

> 此检验防止角色视觉档案或场景视觉基准遗漏，确保与原著人物、场景覆盖一致。

### 角色数量核对

| 检验项 | 操作 | 通过标准 |
|--------|------|----------|
| 原著主要角色数量 | 从原著列出所有有名字/台词/显著动作的角色，记录总数 N_char | — |
| 剧本视觉档案数量 | 统计剧本中【角色视觉档案】总数，记录为 M_char | M_char ≥ N_char |
| 逐一核对 | 对照列表，检查是否有角色在剧本中出现但无视觉档案 | 无遗漏 |
| 合并说明 | 若有合并，档案中是否有注明 | 已注明 |

**检验问题**：
- [ ] 原著每个主要角色是否都有对应的【角色视觉档案】代码块？
- [ ] 是否有角色有台词/动作但未生成视觉档案？
- [ ] 合并处理的角色是否在档案中说明合并原因？

### 场景数量核对

| 检验项 | 操作 | 通过标准 |
|--------|------|----------|
| 原著主要地点数量 | 从原著列出所有有完整场景发生的地点，记录总数 N_loc | — |
| 剧本视觉基准数量 | 统计剧本中【场景视觉基准】总数，记录为 M_loc | M_loc ≥ N_loc |
| 逐一核对 | 对照列表，检查是否有地点在剧本中出现但无视觉基准 | 无遗漏 |
| 命名一致性 | 同一地点在不同场次的标题命名是否相同 | 命名一致 |

**检验问题**：
- [ ] 原著每个主要地点是否都有对应的【场景视觉基准】代码块？
- [ ] 是否有地点有场景发生但未生成视觉基准？
- [ ] 同一地点跨场次命名是否保持一致？（影响分镜工作流识别）

## 六C、原著保留项核对（改编剧本必须执行）

> 此检验对照 beat-sheet 中每个场景的 `原著保留项` 字段，防止原著关键信息在多步工作流中丢失。

### 执行方式

1. 逐场提取 beat-sheet 中 `原著保留项` 字段内容，区分 [情节/道具/动作] 和 [台词/含义] 两类
2. 在 full-script-draft.md 对应场景中逐条检查

### 核对表（按场景填写）

| 场景编号 | 类型 | 保留项内容 | 剧本中是否呈现 | 标记 |
|----------|------|-----------|----------------|------|
| SC_XXX | [情节/道具/动作] | （从 beat-sheet 提取） | ☐ 是 / ☐ 否 | 否→【严重缺失】|
| SC_XXX | [台词/含义] | （从 beat-sheet 提取） | ☐ 已呈现 / ☐ 缺失 | 缺失→【严重缺失】|

**处理规则**：
- [情节/道具/动作] 未呈现 → 【严重缺失】，必须在 final-script.md 中补全
- [情节/道具/动作] 部分呈现但不清晰 → 【呈现不足】，给出修复建议
- [台词/含义] 通过任意方式（对白/动作/场景细节）呈现且含义相符 → ✓ 通过
- [台词/含义] 完全缺失 → 【严重缺失】

## 六D、跨场景逻辑一致性核查（改编剧本必须执行）

> 此检验防止 AI 生成多个场景时出现人物行为、道具状态、空间逻辑的断裂。

### 检验维度

**道具状态连贯**：
- [ ] 关键道具在不同场景间的物理状态是否前后一致？（如：SC_A 中道具被损坏，SC_B 中是否仍反映损坏状态）
- [ ] 武器类道具的持有权转移是否有明确的视觉交接点？

**人物行为连贯**：
- [ ] 同一人物的行为能力是否在全剧保持一致？（前序场景建立的身体限制，在后续场景中是否被遵守）
- [ ] 人物的知情状态是否一致？（A 场景中人物尚未知道的信息，B 场景中不应无故知道）
- [ ] 人物在连续场景间的情绪/行为衔接是否合理？（情绪突变是否有足够的因果铺垫）

**空间逻辑**：
- [ ] 同一地点在不同场景中的物理布局描写是否一致？（如：门的位置、家具陈设）
- [ ] 人物在场景间的移动路径是否物理可行？（时间/距离是否合理）

**时间逻辑**：
- [ ] 场景间的时间跳跃是否有清晰的视觉标记？
- [ ] 压缩处理的时间段是否有明确的交代？

### 核对表（按断裂点填写）

| 断裂位置 | 断裂类型 | 矛盾描述 | 标记 |
|----------|----------|----------|------|
| SC_XXX → SC_XXX | 道具/行为/空间/时间 | （具体矛盾内容） | 【逻辑断裂】|

**处理规则**：
- 发现断裂 → 标记为【逻辑断裂】，说明断裂位置和具体矛盾
- 【逻辑断裂】必须在 final-script.md 中修正后才能交付

## 七、整体质量评估

### 7.1 故事强度评分（1-10分）

| 维度 | 评分 | 说明 |
|------|------|------|
| 概念吸引力 | /10 | 高概念是否清晰有力？ |
| 结构完整性 | /10 | 三幕结构是否稳固？ |
| 人物深度 | /10 | 角色是否多维且有弧光？ |
| 冲突强度 | /10 | 对抗力量是否层层升级？ |
| 情感冲击 | /10 | 高潮是否产生情感回报？ |
| 主题深度 | /10 | 主控思想是否清晰传达？ |
| **总分** | /60 | |

**评级**：
- 54-60分：优秀，可提交
- 45-53分：良好，需小幅修改
- 36-44分：及格，需大幅修改
- 35分以下：需重写

### 7.2 开场检验（前10%场景）

**原则**：开场段落决定整个剧本的可信度。

检查清单：
- [ ] 主要人物是否已建立？
- [ ] 戏剧前提是否清晰？
- [ ] 激励事件是否已发生或即将发生？
- [ ] 是否建立了与主人公的移情纽带？
- [ ] 类型、背景、时代是否清晰？

### 7.3 高潮检验

- [ ] 高潮是否是激励事件的必然结果？
- [ ] 高潮是否产生绝对且不可逆转的变化？
- [ ] 高潮是否需要解释性对白来阐明意义？（应否）
- [ ] 是否有总结所有意义的"基调形象"？
- [ ] 主人公是否是解决冲突的核心动力？

### 7.4 反讽与主题检验

- [ ] 故事是否有清晰的"主控思想"？
- [ ] 高潮是否证明了主控思想？
- [ ] 是否存在反讽升华（所得与所失比肩而立）？
- [ ] 主题是否通过动作而非对白传达？

## 八、AI特有风险检查

### 8.1 常见AI错误清单

| 错误类型 | 检查方法 | 严重程度 |
|----------|----------|----------|
| **过度依赖对白** | 统计对白vs描写比例 | 高 |
| **缺乏价值转折** | 逐场检验负荷变化 | 高 |
| **转折缺乏因果** | 验证事件因果链 | 高 |
| **冲突强度平稳** | 检查对抗力量升级 | 中 |
| **危机虚假两难** | 检验是否存在第三种选择 | 高 |
| **叙述文学化** | 检查内心独白、抽象比喻、情绪告知 | 高 |
| **叙述段落过长** | 检查是否有段落超过4行 | 中 |
| **动词不具象** | 检查是否有模糊动词未替换 | 中 |
| **副词堆叠** | 检查是否有副词修饰动词 | 中 |
| **叙述节奏均速** | 检查全剧快/中/慢分布是否有对比 | 中 |
| **细节无选择意图** | 检查每个描写细节是否服务于人物/情节/主题 | 中 |
| **跨场景逻辑断裂** | 道具/人物状态/空间布局/时间逻辑在场景间矛盾 | 高 |
| **视觉档案遗漏** | 对照原著清单逐一核对角色和地点数量 | 高 |
| **视觉档案/对白格式错误** | 检查是否使用代码块格式 | 中 |
| **角色过于完美** | 检验缺陷和伤口 | 中 |
| **动机过于抽象** | 检验私人化和具体性 | 中 |
| **对白无隐藏问题** | 检查是否确认了场景的核心张力 | 高 |
| **对白欲望对称** | 检查两个角色的欲望是否有结构性冲突 | 高 |
| **信息倾倒** | 检查是否有场景以平静对话传递背景信息 | 高 |
| **格式错误** | 逐页技术检查 | 低 |

### 8.2 AI生成后必做修正

1. **对白压缩**：将所有超过4行的对白压缩到2行以内
2. **段落拆分**：将所有超过4行的描写拆分为多段
3. **删除内心描述**：删除所有"他想"、"她感到"、"他意识到"等无法拍摄的内容
4. **强化动作**：用视觉动作替代解释性对白
5. **检查转折**：确保每个转折点都改变游戏的"规则"或"赌注"
6. **对白去味**：逐行检查，消除完整句式、文学腔、AI式解释性语气
7. **潜文本还原**：找出所有"写在鼻子上"的台词，改用反衬或置换法重写
8. **叙述动词替换**：将所有模糊动词（走/看/移动）替换为具象动词
9. **删除副词**：删除所有副词，换用本身携带情感色彩的动词
10. **数量核对**：对照原著，确认视觉档案和场景基准无遗漏
11. **格式核对**：确认视觉档案、场景基准、元数据、对白块均为代码块格式
12. **节奏检查**：检查全剧叙述节奏是否均速，设计快/中/慢对比分布
13. **场景级对白诊断**：每个对话场景确认隐藏问题存在、欲望不对称存在；信息型场景确认信息已转化为武器

## 八B、改编类剧本专项检验

> 仅适用于由小说、故事或已有文本改编的剧本

### 媒介转化检验

**去文学化**：
- [ ] 是否彻底清除"他想"、"她觉得"、"内心独白"等无法拍摄的内容？
- [ ] 抒情性描写是否转化为具体的视觉动作或场景？
- [ ] 是否存在保留小说叙事腔调的段落？（如"这是一个悲伤的秋天"）

**内心独白转化**：
- [ ] 原著的心理分析，是否转化为可拍摄的对白或动作？
- [ ] 意识流内容，是否通过蒙太奇或道具暗示处理？
- [ ] 闪回是否控制在合理数量以内，不滥用？

**角色与结构精简**：
- [ ] 出场角色数量是否精简到电影可容纳范围？
- [ ] 是否合并了功能重复的次要角色？
- [ ] 原著的多条副线是否筛选保留，只留与主线有直接因果的副线？

**亮点保护**：
- [ ] 原著的核心卖点（亮点）是否保留并强化？
- [ ] 改编后故事主线是否仍具清晰、连贯的因果逻辑？

### 改写完成度检验

- [ ] 改写动机是否明确（自发 vs. 被动应对）？
- [ ] 改写类型是否与实际修改幅度匹配（局部/角色/时空/重构）？
- [ ] 关键转折点（原著有而改编版本删除的）是否有对应替代处理？
- [ ] 改写后是否重新验证了三幕结构和七大转折点的完整性？

## 十、参考标准案例

### 优秀剧本参考
- **《唐人街》**：结构、潜文本、视觉叙事的典范
- **《卡萨布兰卡》**：人物塑造、对白艺术的巅峰
- **《沉默的羔羊》**：反派塑造、悬念营造的标杆
- **《异形》**：类型融合、真实可信性的示范

### 检验技巧
1. **朗读测试**：大声朗读对白，检查是否自然
2. **视觉化测试**：阅读时闭眼想象画面，检查是否清晰
3. **删节测试**：删除每个场景，检查故事是否还成立
4. **时间测试**：按"一页一分钟"估算时长，检查节奏
