# 剧本写作规则参考文档：场景环境设计

> 适用场景：AI辅助生成场景设定、背景构建、地点选择
> 核心目标：创造视觉化、戏剧化、真实可信的场景环境
> ⚠️ 下游工作流说明：**场景视觉基准**部分是向分镜工作流传递的视觉合约，确保同一地点在不同场次中保持空间一致性。

---

## 零、场景视觉基准规范（Location Visual Anchor）

> **用途**：每个固定出现的地点（Location）需要一份视觉基准，作为视觉圣经的核心输入。
> **规则**：描述空间"是什么"，不限定画面风格和美术方向。
> **格式要求**：必须使用代码块格式输出，不得以纯文本形式书写。

### 主要场景数量核对（提醒）

> 核对执行流程见 SKILL.md Phase 4 Step 0。此处仅提醒：视觉基准数量必须 ≥ 原著主要地点数，允许合并但需注明，同一地点跨场次命名必须一致。

### 每个主要地点必须输出以下视觉基准

```
【场景视觉基准】
地点代码：（与场景标题一致，如 INT. 茶馆）
空间性质：（室内/室外，开放/封闭，大/中/小）
基本布局：（1-2句，描述空间大致形状和功能区划分）
光线默认状态：（白天/夜晚/遮蔽，自然光/人工光）
固定视觉标志物：（3个以上具体物件或特征，是识别该空间的锚点）
可变元素：（随时间/情节变化的部分，如人流、天气等）
```

**填写原则**：
- 固定视觉标志物必须是具体、可识别的物件（"角落里挂着的日历"而非"有些装饰品"）
- 至少3个标志物，分镜 AI 每次出现该场景时可从中选取形成空间连贯感
- 不规定摄影机角度和拍摄方式

**示例**：
```
【场景视觉基准】
地点代码：INT. 陈逸的办公室
空间性质：室内，封闭，中型
基本布局：长方形，靠窗有一张大书桌，对面是两张访客椅，后墙是顶天立地的书柜
光线默认状态：白天为窗外自然光，夜晚为台灯单点光源
固定视觉标志物：
  - 书桌上永远堆着两叠文件，左高右低
  - 右侧书柜中间层摆着一个白色陶瓷马克杯（无图案）
  - 窗框左侧贴着一张手写便条纸，字迹模糊看不清
可变元素：白天有窗外街道噪音和光影变化，夜晚空间收缩感明显
```

## 一、场景设计核心原则

### 1.1 场景的本质定义
**场景不仅仅是地点的变换，更是戏剧性动作的最小单位**

每个场景必须：
- 由人物的"需求"或目标驱动
- 遭遇对抗力量（内心、个人或环境）
- 产生冲突并导致价值转折

### 1.2 场景设计三要素
| 要素 | 说明 | 检验标准 |
|------|------|----------|
| **鸿沟 (The Gap)** | 主观期望与客观结果之间的断层 | 人物采取最小保守行动后，是否得到意外反应？ |
| **价值转折** | 负荷价值的情境发生正负转换 | 场景结尾的价值是否与开始时不同？ |
| **不归点** | 推动故事越过不可回归的界限 | 后续是否不能再采取类似力度的轻量级行动？ |

**最佳实践**：
- 通过"鸿沟"设计场景：人物行动 → 意外反应 → 更大风险 → 下一步行动
- 每个理想场景必须使人物生活中的负荷价值发生转折
- 场景应推动故事越过一个个"不归点"

**禁止约束**：
- 禁止无目标驱动的场景（纯"展示"或"解说"场景）
- 禁止价值负荷无变化的场景（应删减或重写）
- 禁止场景可以轻易被其他场景替代

### 1.3 场景精简原则
**"开始得越晚越好，结束得越早越好"**

**进入时机**：
- 在冲突即将爆发或刚刚爆发时进入
- 省略不必要的铺垫和寒暄
- 如果一场戏讲述的就是表面正在发生的事，通常是失败的

**退出时机**：
- 在价值转折完成后立即退出
- 留下未解决的问题推动下一场景
- 避免场景结束后的"余波"解释

## 二、背景设计四维构成

### 2.1 背景的四维界定（麦基理论）

| 维度 | 定义 | 设计要点 |
|------|------|----------|
| **时代 (Period)** | 故事在时间中的位置 | 当代/历史/未来，决定技术和社会规范 |
| **期限 (Duration)** | 故事跨度 | 数十年/数天/数小时，影响节奏和深度 |
| **地点 (Location)** | 物理位置 | 具体地点而非泛化区域 |
| **冲突层面 (Level)** | 社会位置 | 决定政治规律、仪式、价值观、法律 |

### 2.2 创作限制原理 (Creative Limitation)
**规范**：创造一个"小小且可知"的世界

**原则**：
- 背景越大，作者知识越被稀释 → 导致陈词滥调
- 背景越小，作者知识越完善 → 创作选择越多
- 故事必须遵守自创的"或然性法则"

**最佳实践**：
- 通过记忆、想象和事实研究填充背景知识
- 环境一旦确立，其因果规律不可随意更改
- 使用"讲述细节"创造真实感而非面面俱到

**禁止约束**：
- 禁止背景过大导致无法深入（如"整个中世纪欧洲"）
- 禁止违背已确立的或然性法则
- 禁止用抽象描述代替具体细节

## 三、地点设计规范

### 3.1 地点选择原则

**戏剧性反衬 (Dramatic Contrast)**：
- 地点与动作的不协调增强戏剧张力
- 案例：在鲨鱼出没的水族馆里谈情说爱
- 案例：在拥挤嘈杂的弹子间讨论犯罪计划

**视觉化与具体化**：
- 使用具体地点名（"史密斯家的房子"而非"午餐中"）
- 通过视觉形象揭示环境而非抽象描写

### 3.2 场景标题规范 (Scene Headings/Slug Lines)

**标准格式**：
```
INT. 地点 - 时间
或
EXT. 地点 - 时间
```

**组成部分**：
1. **摄影机位置**：INT.（室内）/ EXT.（室外）/ INT./EXT.（快速移动）
2. **场景地点**：简短且具体（如 DINER, STREET）
3. **时间**：绝大多数仅用 DAY 或 NIGHT，极关键时才用 DUSK/DAWN
4. **特殊标注**：DREAM STATE, FLASHBACK, 特定年份

**排版规范**：
- 全大写 (ALL CAPS)
- 不加标点
- 主场景标题前留两行空白
- 禁止在标题中包含氛围描写

**次级标题 (Secondary Headings)**：
当主场景包含多个小地点时使用：
```
INT. RESTAURANT - DAY

在吧台...

在餐桌旁...
```

**禁止约束**：
- 禁止在特约剧本中包含摄影机角度（CLOSE UP, PAN）
- 禁止场景编号（那是分镜脚本规范）
- 禁止过多变焦、摇摄等导演指令

### 3.3 真实可信性构建 (Authenticity)
**核心原则**：真实感不取决于现实性，而取决于内部连贯性和"讲述细节"

**技法**：
- 使用少量精选的细节暗示整个世界深度
- 通过环境物的操作暗示镜头（不写"特写"而写"一滴眼泪滚落"）
- 在背景中植入重复出现的形象系统强化主题

**经典案例**：
- 《异形》：舱壁贴家庭照片、船员讨论加班费 → 真实可信的"太空卡车司机"
- 《洛奇》："拳馆看起来像一个由里向外翻出的垃圾桶" → 极简动词确立质感
- 《唐人街》："盲视"形象系统（眼镜、后视镜、窗户）→ 视觉障碍象征内心腐败

## 四、环境设计的形象系统

### 5.1 形象系统定义
在背景中植入一类特定的视觉或听觉范畴，通过重复出现强化审美情感

### 5.2 形象系统类型
| 类型 | 功能 | 案例 |
|------|------|------|
| **自然元素** | 生命/纯净/危险 | 《唐人街》的水、《大白鲨》的海洋 |
| **视觉障碍** | 无知/腐败/隐藏 | 《唐人街》的眼镜、镜子、窗户 |
| **封闭空间** | 囚禁/压迫 | 《卡萨布兰卡》百叶窗制造的"虚拟监狱" |
| **机械/技术** | 异化/现代性 | 科幻片中的机器形象 |

### 5.3 形象系统使用规范
- 潜在地在声画中反复出现
- 强化主题而不让观众察觉
- 与人物心理状态形成呼应
