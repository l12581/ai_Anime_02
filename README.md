# 《人在大乘期，今年上大一》影视改编项目

本项目将君无涯同名网络小说《人在大乘期，今年上大一》改编为一部约 **120 分钟的都市奇幻动作电影**。

改编以原著第一部（第 1—228 章）的完整故事闭环为主体，第 229 章仅作为片尾彩蛋。影片以“无敌流”爽感为外壳，围绕复仇、创伤、家庭与自我选择展开：被女帝反复炼化五百余世的江凡回到大学校园后，必须在毁灭仇人与守护新家庭之间作出选择。

> 真正的无敌不是没有人能伤害你，而是伤害不再决定你是谁。

## 故事梗概

江凡曾被仙圣宫女帝叶倾仙选中，却被投入炼丹炉，成为炼制鸿蒙圣体的材料。五百余世的死亡与重生后，他终于以大乘期修为杀回天界，却在决战中被时空乱流送回大一宿舍。

回到现代校园的江凡看似天下无敌，但梁雨熙体内苏醒的天道之眼、昆仑深处的大道裂缝，以及凋零世界中叫他“爸爸”的康蕾蕾，逐渐揭开蓝星与叶倾仙之间的因果联系。为阻止世界走向毁灭，江凡主动把自己的百世经历拍成电影，以众生共鸣引叶倾仙跨界归来，也将自己推入一场可能无法重生的终极赌局。

## 创作与制作约定

- `final-script.md` 为当前主版本；`full-script-draft.md` 用于保留修订前的完整初稿。
- `scenes/SC_001.md` 至 `SC_036.md` 与完整剧本的场次编号一致，适合后续分镜、制片拆解和素材生成。
- 人物造型以 `characters.md` 中的“角色视觉档案”为准。
- 场景空间与固定标志物以 `locations.md` 中的“场景视觉基准”为准。
- 后续修改若影响人物、地点或剧情因果，应同步更新完整剧本、对应分场文件和 QA 记录。
- 项目文本统一使用 UTF-8 编码，避免中文内容在 Windows 工具链中出现乱码。
