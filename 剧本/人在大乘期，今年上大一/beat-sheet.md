# 《人在大乘期，今年上大一》厚版 Beat Sheet

## 结构总览

- 形式：约 120 分钟都市奇幻动作电影
- 总场景数：36
- 第一幕：SC_001—SC_009（9 场，25%）
- 第二幕：SC_010—SC_027（18 场，50%）
- 第三幕：SC_028—SC_036（9 场，25%）
- 背景故事：SC_001—SC_003
- 激励事件：SC_004
- 情节点 I：SC_009
- 中点：SC_018
- 情节点 II：SC_027
- 危机：SC_031
- 高潮：SC_033
- 领悟与结局：SC_034—SC_036

## 第一幕：建置

### SC_001 EXT. 平头村 - 白昼

- 幕次：第一幕
- 功能：用荒诞奇观建立穿越修仙世界，并让“被选中”迅速反转为危险。
- 原著对应：第1章；关键句“你，可愿随吾修行。”
- 核心动作序列：茅房巨响；五彩祥云压住村庄；叶倾仙与两童女现身；村民跪拜；叼着稻草的江凡走出茅房；江凡答应修行并被霞光带走。
- 情绪走向：滑稽、惊喜 → 神圣诱惑 → 隐约不安。
- 隐藏问题：叶倾仙看到的是一个人，还是一味药？
- 叙述节奏：快。
- 场景结束状态：江凡离地升空，与人间父母骤然分离。
- 原著保留项：
  - [情节/道具/动作]：茅房巨响、五彩霞光、稻草、异常高大的叶倾仙、江凡抱住她的腿。
  - [台词/含义]：“你，可愿随吾修行。”“我，愿意。”

### SC_002 INT. 仙圣宫·真天宫 - 昼/夜蒙太奇

- 幕次：第一幕
- 功能：揭开仙圣宫的屠宰内核，制造江凡第一次死亡。
- 原著对应：第1章；排浊、剃毛、沐浴、披甲、入炉。
- 核心动作序列：叶倾仙为江凡洗筋伐髓；明月、彩霞替他沐浴；玄鸿战甲自动闭合；九转炼丹炉点燃；战甲挤压血肉；叶倾仙隔火凝视；江凡伸手抓向她后坠入火海。
- 情绪走向：受宠若惊 → 感激 → 察觉异常 → 极端背叛。
- 隐藏问题：恩赐是否只是更精致的控制？
- 叙述节奏：中转快。
- 场景结束状态：江凡在火中留下对叶倾仙的仇恨，画面骤黑。
- 原著保留项：
  - [情节/道具/动作]：玄鸿战甲、九转炼丹炉、身体被碾碎、叶倾仙的平静微笑。
  - [台词/含义]：保留“最毒妇人心”的愤怒含义，不直接写内心旁白。

### SC_003 EXT./INT. 异世界多地 - 百世蒙太奇

- 幕次：第一幕
- 功能：压缩五百余世修炼史，把复仇铸成江凡的唯一方向。
- 原著对应：第2—10章；“第四世……第五百一十九世”。
- 核心动作序列：江凡一次次在田野醒来；成家躲避、拜入不同宗门、偷学功法、救下段腾；每一世仍被仙圣宫抓回；尸骨在炼丹炉下叠高；最后一世牛尾扫过封印，江凡睁眼吸尽漫天灵气；他握住轩辕剑。
- 情绪走向：恐惧 → 反抗 → 麻木 → 冷硬决绝。
- 隐藏问题：当一个人只剩复仇，他与炼他的敌人还有何区别？
- 叙述节奏：快。
- 场景结束状态：大乘期江凡劈开天门，主动杀向仙圣宫。
- 原著保留项：
  - [情节/道具/动作]：反复重生、排浊剃毛沐浴披甲的重复意象、鸿蒙圣体、牛尾破封、轩辕剑。
  - [台词/含义]：“我于此界全无敌，不斩仙圣玩泥吗”的狂烈含义。

### SC_004 EXT. 天门战场 - 血色天幕

- 幕次：第一幕
- 功能：激励事件；兑现开场复仇爽点，却把江凡抛回蓝星。
- 原著对应：第10—11章；天界终战与时空扭曲。
- 核心动作序列：江凡踏过仙圣宫残军；叶倾仙展开太极图；轩辕剑封锁时空；两股力量撕开黑白旋涡；江凡抓向叶倾仙，手指即将碰到她时被旋涡吞没；血雨倒流成宿舍窗外的夜雨。
- 情绪走向：复仇亢奋 → 胜负将定 → 猝然失控。
- 隐藏问题：江凡真正想要叶倾仙死，还是想让她承认自己亏欠了他？
- 叙述节奏：快。
- 场景结束状态：江凡从湘南财经大学302宿舍床上惊醒。
- 原著保留项：
  - [情节/道具/动作]：轩辕剑、太极图、时空扭曲、仙圣宫血雨。
  - [台词/含义]：叶倾仙始终不解释，保留其冷峻压迫感。

### SC_005 INT. 湘南财经大学·302宿舍 - 深夜

- 幕次：第一幕
- 功能：完成“神回到大一”的类型反差，建立江凡对叶倾仙的病态执念。
- 原著对应：第11章。
- 核心动作序列：江凡捏碎手机壳又立即复原；查看日期和未读小说；神识扫过校园却找不到叶倾仙；室友翻身骂他吵；江凡冲出宿舍，在空街仰天喊叫；路灯逐盏熄灭。
- 情绪走向：震惊 → 验证现实 → 空虚失措。
- 隐藏问题：没有仇人之后，他还知道自己是谁吗？
- 叙述节奏：中。
- 场景结束状态：江凡独自站在熄灭的街道中央，第一次显得无处可去。
- 原著保留项：
  - [情节/道具/动作]：铁架床、泡面、手机里的小说、神识确认回到蓝星。
  - [台词/含义]：“婆娘，没有你我怎么活”的执念必须保留。

### SC_006 EXT. 城市公交站/INT. 理发店 - 凌晨至早晨

- 幕次：第一幕
- 功能：让江凡作出“重修七情六欲”的初步选择，并用凡人理发制造喜剧反差。
- 原著对应：第12—13章。
- 核心动作序列：江凡在公交站静坐两小时；晨光照到他握剑留下的茧；他收起外放气息；走进理发店，认真低头配合理发师；换掉蘑菇头和黑框眼镜；镜中人既年轻又陌生。
- 情绪走向：无着落 → 暂时平静 → 对新生活产生试探。
- 隐藏问题：他是在重新生活，还是换一种方式等待叶倾仙？
- 叙述节奏：慢。
- 场景结束状态：江凡双手插兜走回校园。
- 原著保留项：
  - [情节/道具/动作]：公交站悟道、理发、收敛大乘气息、外形蜕变。
  - [台词/含义]：“从今以后，在这个世上，没有人能教我做事。”

### SC_007 EXT./INT. 湘南财经大学·林荫道/食堂 - 上午

- 幕次：第一幕
- 功能：用一次代表性校园冲突建立江凡的凡间处境、梁雨熙与段乘风。
- 原著对应：第13—15章及第47章。
- 核心动作序列：梁雨熙认不出改头换面的江凡；段乘风包场驱赶学生；江凡端着餐盘坐下；保镖伸手时齐齐跪倒；江凡把段乘风撒出的现金还给被赶学生；梁雨熙当众声称江凡是她男朋友，试图重新占有关系。
- 情绪走向：轻松 → 欺压 → 爽感反转 → 关系尴尬。
- 隐藏问题：梁雨熙要的是江凡，还是被所有人羡慕的选择权？
- 叙述节奏：快。
- 场景结束状态：江凡否认关系离开，梁雨熙手机黑屏中短暂映出一只闭合巨眼。
- 原著保留项：
  - [情节/道具/动作]：食堂包场、每人五百、梁雨熙认错又改口、段乘风受辱。
  - [台词/含义]：江凡不再围着梁雨熙转；段乘风第一次意识到钱无效。

### SC_008 INT. 张檬檬家/医院诊室 - 黄昏

- 幕次：第一幕
- 功能：第一次让江凡把力量用于救人，建立张檬檬的情感位置。
- 原著对应：第20章及后续张檬檬线。
- 核心动作序列：张檬檬强忍病痛给江凡倒水；药瓶从手中掉落；江凡两指点住她眉心；灰黑病气被抽出又在掌中烧净；监护数据恢复；张檬檬本能哼出一段前世摇篮曲；江凡的手停在半空。
- 情绪走向：克制疏离 → 紧急 → 温暖 → 诧异。
- 隐藏问题：江凡救她，是因为眼前的她，还是因为她像某个前世故人？
- 叙述节奏：慢。
- 场景结束状态：江凡收下张檬檬递来的红绳，却不解释为何失神。
- 原著保留项：
  - [情节/道具/动作]：眉心渡力、病体恢复、张檬檬对江凡的信任。
  - [台词/含义]：“江凡哥哥，我忽然感觉好舒服”的纯粹依赖。

### SC_009 INT. 湘南财经大学·废教室 - 夜

- 幕次：第一幕
- 功能：情节点 I；把校园生活与大道阴谋锁在一起，迫使江凡进入调查。
- 原著对应：第33章、第116章，并前置梁雨熙体内天道之眼线索。
- 核心动作序列：梁雨熙约江凡见面；她指责他变心并逼近；窗外雷声与她的心跳同步；江凡看见她瞳孔后有巨大眼睑抖动；教室玻璃映出叶倾仙白衣身影；江凡伸手时幻影消失，墙上只剩一道天道纹路。
- 情绪走向：旧情纠缠 → 不耐烦 → 猛然警觉 → 猎手苏醒。
- 隐藏问题：叶倾仙究竟藏在梁雨熙体内，还是江凡从未摆脱她的投影？
- 叙述节奏：中转快。
- 场景结束状态：江凡通知炎黄协会封锁异常，正式放弃“只当大学生”的计划。
- 原著保留项：
  - [情节/道具/动作]：梁雨熙脑海中的巨眼、眼皮抖动、江凡看见大道力量。
  - [台词/含义]：江凡明确告诉梁雨熙“过去那个江凡已经死了”。

## 第二幕：对抗

### SC_010 INT. 炎黄协会基地 - 日

- 幕次：第二幕
- 功能：建立现代国家秩序与超凡世界规则，给江凡设置非武力限制。
- 原著对应：第33章、第82—90章。
- 核心动作序列：萧鸿生播放全球异常影像；协会测试江凡力量，仪器连续爆表；萧鸿生递出供奉协议；江凡只拿走异常档案；双方以扳手腕试探，桌面完整、地下钢筋却弯成弧形。
- 情绪走向：戒备 → 试探 → 有限尊重。
- 隐藏问题：国家如何与一个不受任何规则约束的人合作？
- 叙述节奏：中。
- 场景结束状态：江凡得到“湘江水下异常”和昆仑龙脉资料，答应不在城市公开动用全力。
- 原著保留项：
  - [情节/道具/动作]：炎黄协会天地玄黄体系、萧鸿生、江凡成为特殊供奉。
  - [台词/含义]：面对“你能对抗整个协会吗”，江凡只答“能”。

### SC_011 EXT. 湘江施工水域 - 日

- 幕次：第二幕
- 功能：展示江凡的破局能力，并让白冰雪进入主线。
- 原著对应：第29—33章。
- 核心动作序列：桥墩箱体到七米七便上浮；潜水员找不到障碍；白冰雪以协会观察员身份记录；江凡踏水下沉；水底盘龙柱显形；他拔出柱中一枚黑鳞，河面出现短暂星图；白冰雪看见星图指向昆仑。
- 情绪走向：工程困局 → 神秘 → 奇观 → 更大疑问。
- 隐藏问题：江凡解决异常，是为公共安全，还是在搜寻叶倾仙踪迹？
- 叙述节奏：中转快。
- 场景结束状态：黑鳞在江凡掌中睁开一只微型眼睛后化灰。
- 原著保留项：
  - [情节/道具/动作]：箱体七米七上浮、水下无物、盘龙柱、白冰雪旁观。
  - [台词/含义]：“有东西在下面顶了一下”的工程谜面。

### SC_012 INT. 晨光大酒店 - 夜

- 幕次：第二幕
- 功能：合并地方术法势力与校园反派线，让段乘风升级为现实威胁。
- 原著对应：第53—75章。
- 核心动作序列：段乘风以七星葬魂阵抽取住客生气；酒店墙内爬出黑影；江凡受邀参加所谓医学交流；张檬檬被当作阵眼诱饵；江凡反转阵法让七盏灯照回施术者；段乘风召出金龙虚影仍被江凡一指击散。
- 情绪走向：诡异 → 威胁亲近者 → 怒意 → 碾压。
- 隐藏问题：江凡会不会因为绝对力量而随意决定他人生死？
- 叙述节奏：快。
- 场景结束状态：江凡没有杀段乘风，而是把证据交给萧鸿生；段乘风第一次真正恐惧。
- 原著保留项：
  - [情节/道具/动作]：晨光大酒店、七星葬魂、住客五官扭曲、金龙化形。
  - [台词/含义]：原著“仙凡通吃，无人不灭”的威慑改为江凡克制杀意的反衬。

### SC_013 INT. 游娱协会会议室 - 日

- 幕次：第二幕
- 功能：把江凡个人行动升级为团队行动，并埋下“拍电影引敌”的工具。
- 原著对应：第118章。
- 核心动作序列：谢妃姬、胡彬、曹梓桐、郑星云在会议桌前互相拆台；江凡投影全球异常地图；他将调查、资金、舆情、行动四项任务分别丢给四人；墙上组织名从临时小队改为“游娱协会”。
- 情绪走向：喜剧混乱 → 江凡压场 → 团队成形。
- 隐藏问题：这些人追随的是江凡本人，还是他能带来的利益？
- 叙述节奏：中。
- 场景结束状态：曹梓桐报告，有影视公司反复梦见“白衣女帝”和炼丹炉。
- 原著保留项：
  - [情节/道具/动作]：四名骨干、称呼各异、江凡一句“散会”结束会议。
  - [台词/含义]：游娱协会既经营世俗资源，也调查超凡事件。

### SC_014 EXT. 昆仑龙脉 - 夜

- 幕次：第二幕
- 功能：扩大世界观，推进江凡与白冰雪的战友关系。
- 原著对应：第133—150章。
- 核心动作序列：江凡带白冰雪御空穿越雪线；山体脉络在月下发光；黑鳞开启隐藏洞口；两人穿过迷阵；白冰雪在风中抓住江凡；洞底封印裂开，飘出一片不融的雪花；雪花穿透白冰雪胸口，远方空间随之开裂。
- 情绪走向：自由奇观 → 亲近 → 神秘敬畏 → 危险。
- 隐藏问题：白冰雪想靠近的是江凡，还是他所代表的另一个世界？
- 叙述节奏：慢转快。
- 场景结束状态：裂缝中显出一座凋零城市，江凡与白冰雪被吸入。
- 原著保留项：
  - [情节/道具/动作]：天下龙脉出昆仑、御空、背后相拥、秘密封印、纯白雪花。
  - [台词/含义]：保留江凡在宏大奇观前仍带凡俗幽默的性格。

### SC_015 EXT. 道源村 - 无时之昼

- 幕次：第二幕
- 功能：第一次揭示江凡并非普通穿越者，而是鸿蒙大道变数。
- 原著对应：第150、160、203章。
- 核心动作序列：江凡与白冰雪跌入青山小河；老钓者背对两人垂钓；村中五十座石屋只有第四十九座亮灯；江凡触碰“鸿蒙”石碑，童年般碎片闪回；他想走向山坡后的家却被透明边界弹回；老钓者用鱼线钩开通往凋零世界的门。
- 情绪走向：熟悉 → 渴望归属 → 被拒绝 → 接受任务。
- 隐藏问题：若江凡本就是大道，他拥有的“人”身份是否真实？
- 叙述节奏：慢。
- 场景结束状态：老钓者告诉他，凋零世界里有一个“只剩力量的江凡”。
- 原著保留项：
  - [情节/道具/动作]：青山小河、白胡子钓者、五十大道三千小道、回不去的家。

## Phase 5 强制继承提示

1. 江凡的力量展示必须服务于不同戏剧目的，禁止连续同构打脸。
2. 梁雨熙眼中天道之眼、红绳、雪花、炼丹炉、屏幕五组意象要贯穿前后。
3. SC_018 的中点不是“打赢江屠”，而是“先救人并承认父亲身份”。
4. SC_031 必须保留静态两难，不得让白冰雪提前消除自爆代价。
5. SC_033 的高潮动作是江凡主动放手并切断连接，不是单纯用更大能量击杀叶倾仙。
6. 所有世界观信息必须在压力下成为行动筹码，禁止角色站立讲设定。
