# 《人在大乘期，今年上大一》人物档案

## 0. 原著主要角色数量核对

### 0.1 核对口径

- 改编边界：原著第一部第 1—228 章；第 229 章仅作片尾钩子，不扩展第二部人物。
- 纳入标准：在 36 场电影方案中承担主线、对抗、情感、世界观揭示或组织行动功能，且在原著中有明确姓名、台词或显著动作的人物。
- 不计入：仅作环境反应的村民、学生、住客、观众、潜水员、保镖、普通幸存者；没有独立戏剧选择的宿舍室友、理发师、演员；只在结尾完成交接功能且无姓名的京华老先生；江凡父母作为家庭赌注与婚礼亲属群像处理，不建立独立角色弧光。
- 原著姓名虽属于同一灵魂或不同形态，仍分别计数并分别建立视觉档案，保证闪回、现世和终战造型可追踪。

## 1. 江凡

- **功能定位**：主人公；“大乘期修士”与“大一学生”的矛盾统一体。
- **欲望 / 需求 / 恐惧**：欲望是找到并杀死叶倾仙、阻止蓝星凋零；需求是承认自己仍需要家庭与伙伴，并把力量用于守护而非证明无敌；最深恐惧是叶倾仙消失后自己也失去存在意义，以及再次眼睁睁失去家人。
- **缺陷与伤口**：五百余世被炼化使他以傲慢、冷漠和绝对控制包裹受害者创伤；习惯把所有危险独自解决。
- **人物弧光**：以“复仇是唯一方向”开场；在康蕾蕾叫出“爸爸”后第一次把救人置于赢；危机中用鸿蒙核心赌命；结局主动放手叶倾仙，接受有限人生并建立家庭与宗门，完成正向成长弧。
- **关键行为模式**：双手插兜走入冲突；先无视威胁，再用一次精准动作终结局面；触及叶倾仙时右手会不自觉握紧；对家人则蹲低身体、让视线与对方齐平。
- **表达方式**：短句、反问、冷幽默；从“没有人能教我做事”转为“先救人”。

```text
【角色视觉档案】
角色名：江凡
性别/大致年龄：男，外表19岁；百世经历使真实心理年龄远超常人
身形体态：约1.80米，肩背挺直、体脂偏低，收敛修为时是清瘦大学生体型
面部特征：窄长双眼、鼻梁直、下颌线清晰
发型发色：黑色短碎发；返校初段为盖眉蘑菇头，SC_006后剪成露眉层次短发
标志性服装/装扮：蓝星主线为素色圆领T恤、深色直筒裤、白底运动鞋；异世界与终战为暗青内衫配破损玄鸿战甲；SC_005前短暂佩戴厚黑框眼镜

标志性随身物件：缠红绳的轩辕剑剑柄；后期为红绳戒指
```

## 2. 叶倾仙

- **功能定位**：核心对抗者；仙圣宫女帝、江凡百世创伤的人格化源头。
- **欲望 / 需求 / 恐惧**：欲望是完成鸿蒙圣体炼化并掌握跨界规则；需求是承认江凡是独立的人而非计划中的材料；恐惧是失去秩序控制、被自己的“造物”否定。
- **缺陷与伤口**：把绝对理性当成正当性，拒绝解释、拒绝承担情感后果。
- **人物弧光**：静止—坠落弧；始终以控制回应失控，最终当江凡不再抓住她时失去共生支点，被恒星湮灭。
- **关键行为模式**：总从高处俯视；危险越近，动作越少；用指尖和眼神代替大幅度施法。
- **表达方式**：低声、短句、不回答质问；把人称作“变数”“容器”“材料”。

```text
【角色视觉档案】

标志性服装/装扮：无纹纯白交领长袍，外罩半透明银纱大袖；终战白袍下显出黑白太极纹甲片
标志性动作/习惯：悬停在离地半尺处；抬手时只伸一根食指
标志性随身物件：掌心大小的黑白太极图；九转炼丹炉的银色炉钥
```

## 3. 李清月

- **功能定位**：叶倾仙在蓝星规则中的现世身份与完全体容器。
- **欲望 / 需求 / 恐惧**：表层欲望是接近张檬檬与江凡、完成跨界合一；深层需求被叶倾仙意志覆盖；恐惧是人格边界被彻底抹除。
- **人物弧光**：从看似普通的张檬檬友人变为叶倾仙完全体；终局黑线断裂时短暂恢复独立轮廓，视觉上证明“容器”与女帝并非天然一体。
- **关键行为模式**：社交时主动伸手、站位贴近；被侵入后动作逐渐与银幕中的叶倾仙同步。
- **表达方式**：前期轻快调侃，合一后语速变慢并采用叶倾仙的无主语命令句。

## 4. 白冰雪

- **功能定位**：调查搭档、理性见证者、主动跨界取得九字真言的关键援手。
- **欲望 / 需求 / 恐惧**：欲望是查明大道异常并获得足以守护蓝星的力量；需求是从观察江凡转为相信自己的判断与选择；恐惧是只能作为“被保护的人”，看见灾难却无力介入。
- **缺陷与伤口**：以冷静和职业距离掩盖对未知的渴望，早期倾向把风险交给更强者处理。
- **人物弧光**：从监视危险人物，到与江凡并肩看见真相，再主动离队穿越裂缝；高潮只稳定时空，把最终选择留给江凡。
- **关键行为模式**：先记录再行动；思考时把湿发或散发拢到耳后；面对险境会向前半步而非后退。
- **表达方式**：结论先行，极少感叹；重要承诺不用“相信”，而用“我去”。

```text
标志性随身物件：银灰数据记录器；昆仑后随身保存一片不融雪花
```

## 5. 张檬檬

- **功能定位**：江凡在现实人生中的伴侣与家庭核心。
- **欲望 / 需求 / 恐惧**：欲望是活下来并与江凡建立可兑现的日常关系；需求是不把前世身份当作获得爱的凭证，而以当下选择确认自己；恐惧是病痛复发、江凡再次消失在她无法抵达的世界。
- **缺陷与伤口**：长期患病让她习惯降低需求、用“没关系”回避冲突。
- **人物弧光**：从被救者成长为能接住江凡恐惧、保护康蕾蕾并拒绝躲进安全屋的人；婚礼上成为主动缔结承诺的一方。
- **关键行为模式**：疼痛时把手指藏进袖口；照顾人时先倒温水；紧张时无意识哼摇篮曲。
- **表达方式**：轻声、具体，不空谈宿命；常以一个生活问题拆解宏大焦虑。

```text
【角色视觉档案】

标志性服装/装扮：前期米白针织开衫、浅蓝棉裙、平底鞋；后期增加暖红围巾；婚礼为简洁象牙白长裙
```
