```text
可变元素：炉门开合、火色、玄鸿战甲部件、明月和彩霞的位置、地面血迹与灰烬。
```

```text
【场景元数据】
出场人物：江凡, 叶倾仙, 明月, 彩霞

主要动作：叶倾仙洗筋伐髓，童女为江凡净身披甲，玄鸿战甲挤碎江凡并把他投入丹炉
```

冷白天光垂在净身池上。叶倾仙把一指按在江凡眉心，银光沿他的血管游遍四肢。

江凡咬紧牙。黑色浊气从皮肤渗出，落进池水，水面立刻翻起白泡。

叶倾仙收手。明月双手托来银盘，彩霞把盘沿校正到与白玉缝平行。

```
    叶倾仙
    洗净。

    是，宫主。

    彩霞（外表十六岁，淡红童女裙）

```

昼夜在穹顶的冷光里交替。

-- 明月用银勺冲去江凡肩上的污迹，拇指压住颤动的食指。

-- 明月换上银质刮刀，剃尽江凡手臂与腿上的毛发；细碎黑发落满银盘。

-- 彩霞剪断他的乱发，随后将他按进净身池沐浴，抬眼确认叶倾仙仍在座阶上。

-- 两人替江凡换上暗青内衫。江凡举起手臂，动作毫无戒备。

-- 披甲台升起六瓣莲座。玄鸿战甲分成数十片，悬在江凡周围。

蒙太奇结束。

```
    江凡
    师尊，这甲叫什么？

    叶倾仙
    玄鸿。

    江凡

    叶倾仙
    很快就知道。
```

甲片依次扣紧。胸甲、肩甲、腰封、腿甲。

江凡握拳。玄鸿战甲表面流过金纹，他冲明月和彩霞扬一下眉。

彩霞退到右侧。明月仍托着银盘，没有抬头。

高台后方，九转炼丹炉的炉门向两侧滑开。橙红火焰舔过九圈金色回纹。

玄鸿战甲再次收紧。

江凡的笑停住。

肩甲压进锁骨。腰封勒入腹部。金属摩擦声盖过骨裂声，暗红血线从甲缝一条条挤出，滴在白玉地面。

他抬手去扯胸甲。五指刚插进缝隙，整副战甲便拖着他升向炉口。

```
    江凡
    师尊——
```

叶倾仙悬在炉火上方，背脊笔直。她的薄唇抬起极小的弧度。

```
    江凡 (CONT'D)
    你看着我。
```

叶倾仙垂下眼，却不回答。

江凡从甲缝里伸出染血的手，五指抓向她。两人指尖还隔半尺，玄鸿战甲猛然合拢。

血雾喷在银盘上。明月手腕一沉。彩霞立刻扶住盘沿，把它重新摆平。

```
    江凡
    好一个师尊。好一副心肠。
```

炉火卷起江凡。他的手最后沉入火海，指尖仍朝着叶倾仙。

```
    江凡 (O.S.)
    叶倾仙！
```

炉门关闭。九圈金纹依次亮起，白玉地面只剩一滴未被擦去的血。

SUPER：婚后第三年。

蒙太奇开始：

-- 黑底金字“鸿蒙宗”牌匾升上山门。江凡站在梯下，双手插兜；张檬檬抬手拍掉他肩上的木屑。

-- 白冰雪将副宗主银印放上主殿长案。不融雪花封在印底，六瓣纹路清晰可见。

-- 谢妃姬、胡彬、曹梓桐、郑星云分别站到四根殿柱前。四枚旧通讯徽章嵌入石柱，亮成四种颜色。

-- 年轻弟子列队穿过圆门。门内星空旋转，龙王戒小世界的陆地向远处展开。

-- 修行阵纹沿银色飞船外壳点亮。飞船冲出云层，尾部留下金色长线。

```text
    白冰雪
    第一批，全部就位。

    江凡
    出发！
```

飞船群越过蓝星，驶向深空。

蒙太奇结束。

夜。

家中客厅亮着一盏暖灯。电视旁摆着婚礼三人合照，照片边压着剩余的半截红绳。

张檬檬和康蕾蕾窝在沙发里看短剧。长高一些的康蕾蕾抱着补好前爪的小熊，笑得整个人歪到张檬檬肩上。

玄关亮起一道金光。

江凡从光里走出，外套上沾着星尘。他弯腰换鞋，把一只小型飞船模型放到茶几上。

```text
    康蕾蕾

    江凡
    换一部。
```

电视画面骤然一闪。

短剧人物全部消失。一只冰冷巨眼填满屏幕，瞳孔深处叠着无数陌生星系。

客厅灯泡连续熄灭。婚礼照片玻璃上浮出一道细霜。

江凡站到电视前。他没有拔剑。腰间也没有剑。

他摘下戒指，红绳在指间绷紧，又把戒指重新戴好。

```text
    张檬檬
    回来吃饭。

    江凡
    留碗。
```

康蕾蕾从沙发跳下，把飞船模型塞进他手里。

江凡朝母女二人点一下头。

身体化作一道金色流光，径直遁入巨眼瞳孔。

电视黑屏。

白字在屏幕中央浮现：

一场新的征程，开始了。
