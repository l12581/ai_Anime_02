SC_001 EXT. 平头村 - 白昼

```text
【场景视觉基准】
地点代码：EXT. 平头村
空间性质：室外，开放，中型村落与田地相连
基本布局：黄土村道贯穿低矮土屋，村口晒谷场连接田埂；一座孤零零的茅房位于晒谷场边缘。
光线默认状态：白昼自然光，日照偏硬；五彩祥云出现后地面被彩色漫射光覆盖。
固定视觉标志物：
  - 茅草顶歪斜、木门下沿开裂的旧茅房
  - 晒谷场中央嵌着半截青石碾盘
  - 村口两棵以红布条相连的老槐树
  - 土墙上排列的竹筛与玉米串
可变元素：村民数量、晒谷作物、牲畜、风向、祥云高度与彩光强度。
```

```text

主要动作：茅房炸响，叶倾仙乘霞降临，江凡答应修行并升空离村
情绪基调：表面滑稽神圣，内在猎物被挑中的不安
隐藏问题：叶倾仙看到的是一个人，还是一味药？
叙述节奏：快，连续动作建立开篇冲击
```

一声闷响顶开茅房的歪木门。茅草从屋顶落下，鸡群拍翅冲过晒谷场。

江凡提着裤腰跨出来，嘴里叼着一根稻草。他在青石碾盘旁站稳，回头看一眼冒灰的茅房。

身形体态：约1.80米，肩背挺直、体脂偏低，收敛修为时是清瘦大学生体型
面部特征：窄长双眼、鼻梁直、下颌线清晰
发型发色：黑色短碎发；返校初段为盖眉蘑菇头，SC_006后剪成露眉层次短发
标志性服装/装扮：蓝星主线为素色圆领T恤、深色直筒裤、白底运动鞋；异世界与终战为暗青内衫配破损玄鸿战甲；SC_005前短暂佩戴厚黑框眼镜
标志性动作/习惯：双手插兜直行；出手前右手食指轻点目标
标志性随身物件：缠红绳的轩辕剑剑柄；后期为红绳戒指

村口的两棵老槐树停止摇动。牛抬起头，铃铛只响半声。

五彩祥云压过屋脊，晒谷场上的人影被染成红、青、金三色。村民扔下竹筛，接连跪进尘土。

叶倾仙悬在云头，白袍下摆没有沾到一粒尘。明月站在她左后方，彩霞站在右后方，各托一只空盘。

叶倾仙的目光掠过跪伏的人群，停在江凡脸上。她伸出一根食指，江凡胸前的稻草缓缓浮起。

```
    叶倾仙（外表二十八岁，白袍）
    你，可愿随吾修行？
```

江父从土屋门口冲出来。江母抓住他的胳膊，两人的脚却越不过晒谷场边缘那道彩光。

江凡吐掉稻草，踩上青石碾盘。他仰头看了片刻，忽然跑到云下，一把抱住叶倾仙垂落的衣摆和腿。

明月的拇指掐住食指。彩霞把托盘扶回完全水平。

```
    江凡（外表十九岁，粗布衣）
    我，愿意。
```

霞光卷住江凡。他双脚离地，裤脚还沾着茅房旁的湿泥。

江母追到彩光边，伸出的手停在半空。江凡低头，手臂仍环着白袍；叶倾仙没有看他，只转身升向云层。

老槐树间的红布条重新扬起。地上的那根稻草滚过碾盘，停在江父脚边。
