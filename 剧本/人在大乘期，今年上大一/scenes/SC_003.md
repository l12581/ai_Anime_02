SC_003 EXT./INT. 异世界多地 - 百世蒙太奇

```text
【场景视觉基准】
地点代码：EXT./INT. 异世界多地
空间性质：室外与室内交替，开放与封闭并置，蒙太奇复合空间
基本布局：以同一块田野醒来点和同一座炼丹炉为首尾锚点，中间串联农舍、宗门山门、藏经阁与逃亡山道。
光线默认状态：每一世从清晨自然光进入丹炉火光；世代切换时保留由白到红再到黑的循环。
固定视觉标志物：
  - 每次醒来都压弯江凡脸侧的三株狗尾草
  - 不同宗门山门前反复出现的残缺石狮
  - 炼丹炉下逐层增高的焦黑尸骨堆
  - 最后一世掠过封印石的牛尾
可变元素：江凡年龄、服饰、发型与伤痕，不同宗门旗帜、季节、家人面孔和死亡方式。
```

叙事功能：压缩五百余世死亡与修炼，把江凡对叶倾仙的复仇铸成唯一方向，同时留下他曾有家庭与弟子的证据。
主要动作：江凡反复醒来和被炼，收徒成家并持续修行，最后借牛尾破封握住轩辕剑
情绪基调：表面高速轮回，内在关系不断被强制截断
隐藏问题：当复仇吞掉每一段人生，江凡还剩多少属于自己的东西？
叙述节奏：快，比上一场更密集，以动作堆叠推进五百余世

三株狗尾草压在江凡脸侧。他猛地睁眼，双手抓住自己的胸口。

没有玄鸿战甲。只有粗布衣和一颗狂跳的心。

SUPER：第四世

-- 江凡把木门钉死，带着妻子和孩子躲进山中。白衣使者从云层落下，木门连同整座农舍化成白灰。

-- 九转炼丹炉开启。江凡被锁链拖过白玉地面，叶倾仙仍悬在原处。

SUPER：第十七世

-- 残缺石狮前，十四岁的段腾倒在泥水里。江凡挡住落下的木棍，把少年拉到身后。

SUPER：第五百一十九世

田野没有风。一头黄牛甩动尾巴，牛尾扫过封印石。

石面裂开一道缝。

江凡睁眼。

他张口一吸。草叶、云层、山河间的灵气化成无数白线，灌入他的身体。远处宗门旗帜同时折断，天空浮出层层雷纹。

他跨过堆成山的焦黑尸骨。白玉台上，轩辕剑发出低鸣。

江凡握住剑柄。剑身上的尘土炸成一圈白雾。

```
    江凡
    我于此界全无敌。
```

他抬剑。天穹中央裂开一条直线。

```
    江凡 (CONT'D)
    不斩仙圣——留着玩泥吗。
```

剑光劈开天门。江凡踏着碎裂的白玉阶，逆着坠落的仙兵冲上云海。
