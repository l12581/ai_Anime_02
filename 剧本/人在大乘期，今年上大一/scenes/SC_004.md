SC_004 EXT. 天门战场 - 血色天幕

```text
【场景视觉基准】
地点代码：EXT. 天门战场
空间性质：室外，完全开放，超大尺度悬空战场
基本布局：破碎天门立在云海中央，仙圣宫残垣漂浮四周；中央战区由轩辕剑阵与太极图两股空间边界切分。
光线默认状态：血色天幕提供暗红漫射光，剑气为金白闪光，旋涡形成黑白交替逆光。
固定视觉标志物：
  - 断成三截仍悬浮的白玉天门
  - 贯穿云层的轩辕剑金色剑痕
  - 叶倾仙脚下旋转的黑白太极图
  - 逆重力向上飘落的血雨
可变元素：残军数量、漂浮碎石、血雨密度、时空旋涡大小和剑阵完整度。
```

```text
【场景元数据】
出场人物：江凡, 叶倾仙, 仙圣宫残军
叙事功能：兑现百世复仇的力量高潮，却在江凡即将触及叶倾仙时用时空扭曲将他抛回蓝星。
主要动作：江凡踏过残军封锁时空，叶倾仙展开太极图，两人撕开黑白旋涡并被迫分离
情绪基调：表面复仇压倒一切，内在渴求答案却无法抵达
隐藏问题：江凡真正要她死，还是要她承认亏欠？
叙述节奏：快，承接蒙太奇并在触碰前骤停
```

断裂天门悬在云海。血雨不落，沿着残柱向天空倒流。

仙圣宫残军结成最后一道白色人墙。江凡拖着轩辕剑走来，剑尖划过浮石，留下一条金色火痕。

一名仙兵举枪。

江凡抬眼。

剑光横过。

长枪齐断。人墙向两侧炸开，白袍落进血色云层。

叶倾仙独自站在三截天门之间，脚下太极图缓慢转动。她的衣袖和长发都没有沾血。

```
    叶倾仙
    你回来了。

    江凡
    炉子还热吗？
```

叶倾仙抬起食指。太极图的黑白两鱼骤然分开，绕住整片战场。

江凡把轩辕剑插进云海。数百道金色剑痕从四面升起，刺穿漂浮残垣，封死每一道退路。

```
    江凡 (CONT'D)
    这次，别转身。
```

叶倾仙没有回答。她将掌心太极图推向前方。

黑白两色撞上金色剑阵。

云海下陷。

残柱折断。

倒流的血雨悬停成无数红珠。

江凡逆着冲击踏出一步，玄鸿战甲从肩口崩开。他拔起轩辕剑，劈开太极图外围，左手抓向叶倾仙。

叶倾仙第一次后退半步。她的目光落在江凡染血的五指上，仍旧一言不发。

```
    江凡
    看着我。
```

两人之间只剩一指距离。

太极图中央塌陷，黑白旋涡猛然张开。江凡的手臂先被拉成摇晃的残影，随后整个人向后滑去。

他把轩辕剑钉进一截天门。剑锋撕出长痕，白玉碎片接连坠入旋涡。

叶倾仙站在另一侧，白袍被黑白光线切成两半。她抬起手，指尖朝江凡伸来。

江凡松开剑柄，扑向她。

旋涡合拢。

叶倾仙的指尖消失在一线黑暗中。轩辕剑失去支点，剑鸣拖成长音。

血雨倒卷，红色水珠化成玻璃窗上的夜雨。
