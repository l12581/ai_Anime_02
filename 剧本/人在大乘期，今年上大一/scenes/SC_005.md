SC_005 INT. 湘南财经大学·302宿舍 - 深夜

```text
【场景视觉基准】
地点代码：INT. 湘南财经大学·302宿舍
空间性质：室内，封闭，小型四人宿舍
基本布局：两组上下铁架床分列狭长房间两侧，靠窗并排四张书桌，入口旁是拥挤衣柜与洗漱架。
光线默认状态：深夜以窗外路灯冷光和手机屏幕光为主，清晨可由东向窗射入暖光。
固定视觉标志物：
  - 江凡床位上方贴歪的课程表
  - 窗边堆着三个不同口味的泡面桶
  - 掉漆铁架床与床柱上的蓝色号码“302”
  - 书桌边缘夹着的黑框眼镜
可变元素：室友睡姿、电脑屏幕、雨痕、衣物堆积、手机壳破损或复原状态。
```

```text
【场景元数据】
出场人物：江凡, 室友甲, 室友乙
叙事功能：完成大乘期修士回到大一宿舍的类型反差，并暴露叶倾仙消失后江凡的执念空洞。
主要动作：江凡捏碎并复原手机，神识扫过校园，冲到空街呼喊叶倾仙
情绪基调：表面荒诞返校，内在无处安放的执念
隐藏问题：没有叶倾仙之后，江凡还知道自己是谁吗？
叙述节奏：中，比前一场明显放慢并积累失序细节
```

江凡从下铺弹坐起来，额头撞响铁架床。

窗外夜雨敲打玻璃。课程表歪在他头顶，书桌上的泡面汤已经凝出一层油。

室友甲翻身，把被子蒙过头。

```
    室友甲
    江凡，几点了……
```

江凡低头。暗青内衫和玄鸿战甲不见了，身上只剩洗旧的T恤；盖眉蘑菇头贴在额前，厚黑框眼镜夹在书桌边。

一部手机在枕边震动。屏幕日期、寝室群消息、未读小说章节挤在一起。

江凡抓起手机。塑料壳在指间碎成数片，屏幕裂纹像蛛网铺开。

他摊开手。碎片倒飞回去，裂纹逐条闭合，手机恢复完整。

室友乙从上铺探出半张脸。

```
    室友乙
    你修手机呢？

    江凡
    修时间。
```

江凡戴上黑框眼镜，手指划过日期。他点开那本未读小说，页面停在几个小时前更新的章节。

他闭上眼。

桌上的水杯震出一圈涟漪。无形气流穿过门缝，整层楼的门牌轻响，树叶在雨中同时压低，远处教学楼的感应灯逐层亮起。

江凡睁眼。眼镜后的瞳孔缩成一线。

他掀开被子，赤脚踩过冰冷地面，撞开宿舍门。

```
    室友甲 (O.S.)
    鞋！
```

江凡退回一步，套上白底运动鞋，又夺门而出。

宿舍楼外的街道空无一人。雨丝在他身边分开，衣服没有沾湿。

他站在路中央，仰头扫过每一扇亮灯的窗。

```
    江凡
    叶倾仙！
```

声音推开雨幕。窗户震颤，积水向道路两侧翻涌。

没有回应。

```
    江凡 (CONT'D)
    婆娘——
```

第一盏路灯熄灭。

第二盏。第三盏。

黑暗沿着街道一路延伸。江凡扶正黑框眼镜，嘴角抬起，手指却把裤缝攥出褶皱。

```
    江凡 (CONT'D)
    没有你，我怎么活？
```

最后一盏路灯熄灭。雨声填满整条街，江凡独自站在黑暗中央。
