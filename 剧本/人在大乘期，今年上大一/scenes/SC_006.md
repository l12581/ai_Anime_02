SC_006 EXT. 城市公交站/INT. 理发店 - 凌晨至早晨

```text
【场景视觉基准】
地点代码：EXT. 城市公交站/INT. 理发店
空间性质：室外开放小空间连接室内半开放小店
基本布局：玻璃公交亭隔街正对窄门理发店；店内三把理发椅沿镜墙排列，后部以磨砂帘隔出洗发区。
光线默认状态：从凌晨路灯冷光过渡至晨曦；店内白色灯管与镜前暖灯同时开启。
固定视觉标志物：
  - 公交亭玻璃上的褪色线路图
  - 长椅下积水里倒映的橙色路灯
  - 理发店镜墙上红蓝旋转灯的反光
  - 最靠门理发椅扶手上的裂纹胶带
可变元素：候车人流、公交车、晨雾、店内顾客、地面碎发及江凡剪发前后造型。
```

```text
【场景元数据】
出场人物：江凡, 理发师, 清洁工, 早班乘客
叙事功能：让江凡暂时收起复仇者姿态，选择重修七情六欲，并以认真配合理发制造力量与日常的反差。
主要动作：江凡在站台静坐收敛气息，走入理发店剪去蘑菇头，换新外形返回校园
情绪基调：表面安静日常，内在试探重新生活的可能
隐藏问题：江凡是在开始新生活，还是换一种方式等待叶倾仙？
叙述节奏：慢，与前两场高速冲击形成停顿
```

玻璃公交亭还挂着雨珠。褪色线路图后，天边只有一条灰白细线。

江凡坐在长椅中央，背脊挺直。双手摊在膝上，掌心两道握剑磨出的旧茧朝上。

一辆末班车驶过，没有停。

清洁工推着水车经过，扫帚擦过江凡鞋边。他没有动。

街对面的理发店卷帘门升起半人高。红蓝旋转灯亮起，在积水里转出交替光圈。

早班乘客陆续站进公交亭。有人贴着玻璃打盹，有人低头刷手机。江凡身旁始终空着半个座位。

晨光越过楼顶，落在他的掌心。

江凡合起双手。周围漂浮的雨珠坠回地面，远处连续闪动的感应灯全部熄灭。他肩口紧绷的衣料松下来，呼吸与候车人群落到同一节奏。

他起身，穿过街道。

理发师掀开磨砂帘，看见江凡的蘑菇头和厚黑框眼镜，手里的梳子停在半空。

```
    理发师
    怎么剪？

    江凡
    让人看见眼睛。

    理发师
    就这个要求？

    江凡
    先做到这个。
```

江凡坐进最靠门的理发椅，双手规矩地放在膝上。理发师替他披好围布，剪刀从盖眉发梢开始咔嚓作响。

黑发一缕缕落地。

理发师推他的下巴，他便抬头；让他偏左，他便偏左；碎发扫到鼻尖，他忍住喷嚏，眼角挤出一滴水。

```
    理发师
    别绷着。理发，不渡劫。

    江凡
    渡劫没这么麻烦。
```

理发师从镜中看他一眼，继续剪。

围布解开。镜中的蘑菇头变成露眉层次短发，窄长双眼不再藏在镜框和发梢后。

江凡摘下黑框眼镜，折好，放进口袋。他用两根手指拨了拨额前短发，发丝又弹回原位。

```
    理发师
    这回像个人了。

    江凡
    人，先当着。
```

他付钱，推门走进晨光。第一班公交车进站，乘客拥向车门。

江凡侧身让开人群，把双手插进裤袋，沿着校园方向走去。

```
    江凡
    （低声）
    从今以后，在这个世上，没有人能教我做事。
```

红蓝旋转灯的反光从他背后掠过，停在地上的黑色碎发上。
