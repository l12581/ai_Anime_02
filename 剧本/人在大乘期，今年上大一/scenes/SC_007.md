SC_007 EXT./INT. 湘南财经大学·林荫道/食堂 - 上午

```text
【场景视觉基准】
地点代码：EXT./INT. 湘南财经大学·林荫道/食堂
空间性质：室外开放校园道路连接室内开放大型食堂
基本布局：梧桐林荫道通向三层食堂玻璃门；一层中央排布长桌，取餐窗口环绕三面，包场区域位于正中。
光线默认状态：上午自然光穿过梧桐叶形成斑驳光；食堂内为顶棚白光与玻璃门侧光。
固定视觉标志物：
  - 林荫道旁红底白字的校园导视牌
  - 食堂入口两侧成排不锈钢餐盘架
  - 中央立柱上的电子菜单屏
  - 靠窗长桌桌角刻着“2025届”字样
可变元素：学生密度、餐盘与现金散落、保镖站位、窗口菜品和叶影移动。
```

```text
【场景元数据】
出场人物：江凡, 梁雨熙, 段乘风, 保镖, 被驱赶学生
叙事功能：以一次校园冲突证明凡间金钱和身份对江凡失效，同时建立梁雨熙的占有欲与段乘风的敌意。
主要动作：梁雨熙认错江凡，段乘风包场撒钱，江凡令保镖跪倒并把钱还给学生
情绪基调：表面校园喜剧，内在旧关系与权力秩序争夺
隐藏问题：梁雨熙要的是江凡，还是被众人羡慕的选择权？
叙述节奏：快，从上一场静止日常切入连续反转
```

梧桐叶影在林荫道上移动。江凡双手插兜，露眉短发被晨风掀起一角。

梁雨熙抱着一箱快递迎面走来。她盯了江凡两秒，侧身让路。

江凡从她身边经过。

梁雨熙停住，回头看他的背影，又低头刷新手机里那张旧合照。照片上的江凡顶着蘑菇头，黑框眼镜遮住半张脸。

```text
【角色视觉档案】
角色名：梁雨熙
性别/大致年龄：女，19岁左右
身形体态：约1.66米，匀称，习惯收腹挺胸面对镜头
面部特征：杏眼、鼻尖小、唇峰清晰
发型发色：栗黑色胸下大波浪长发，中分
标志性服装/装扮：精致淡妆；校园段为白色修身上衣、浅咖短外套、深色百褶裙；附身段统一为无纹素白长裙
标志性动作/习惯：开口前整理鬓发；不停下拉刷新手机页面
标志性随身物件：银白手机；天道之眼苏醒后手机壳背面出现细小眼纹裂痕
```

```
    梁雨熙（十九岁，浅咖短外套）
    同学。
```

江凡继续往前。

```
    梁雨熙 (CONT'D)
    江凡？
```

江凡回头。梁雨熙把快递箱挪到身前，拢一下鬓发。

```
    江凡
    认得慢了。
```

食堂玻璃门内，一排保镖把学生从中央长桌赶开。段乘风大步走进来，抬下巴，保镖便把一叠叠现金放到被占的餐盘旁。

```text
【角色视觉档案】
角色名：段乘风
性别/大致年龄：男，22岁左右
身形体态：约1.83米，肩宽腰窄，健身型体格
面部特征：剑眉、窄眼、右下颌有一颗黑痣
发型发色：黑色侧分短发，发际与鬓角修剪整齐
标志性服装/装扮：校园段为炭灰定制西装配白色运动鞋；术法段在西装内加暗红七星纹背心
标志性动作/习惯：抬下巴示意他人办事；失控时反复拉平袖口
标志性随身物件：黑色金属卡夹；七枚铜制阵灯
```

```
    保镖
    段学长请大家换层。每人五百。
```

学生拿着餐盘挤向门口。江凡逆着人流走进食堂，从窗口端起一份饭，坐到中央长桌。

段乘风停在桌尾。他抽出黑色卡夹，弹出五张纸币，纸币滑到江凡餐盘旁。

```
    段乘风（二十二岁，炭灰西装）
    位置，我买了。

    江凡
    菜没你的份。
```

两名保镖同时伸手抓江凡肩膀。

江凡夹起一块豆腐。

保镖膝盖砸地。随后第三个、第四个，整排人齐齐跪在长桌两侧，手臂僵在半空。

段乘风的手停在卡夹上。电子菜单屏闪烁一下。

江凡把那五张纸币推回去，又将桌上剩余现金一叠叠抛向被赶走的学生。纸币准确落进每只餐盘。

```
    江凡
    饭冷了。钱留下。
```

梁雨熙把快递箱放下，快步挽住江凡的胳膊，转身面向围观学生。

```
    梁雨熙
    别误会。江凡是我男朋友。
```

周围手机同时抬起。梁雨熙挺直肩背，嘴角保持微笑。

江凡抽出手臂，把她的手机屏幕按灭。

```
    江凡
    你说的是照片里那个。

    梁雨熙
    有区别吗？

    江凡
    他死了。
```

江凡端起餐盘离开。段乘风盯着他背影，反复拉平袖口。

梁雨熙低头，银白手机黑屏映出她的脸。脸后，一只巨大的眼睑闭合一瞬。

她猛然回头。食堂墙面干净，只有电子菜单屏继续滚动菜名。
