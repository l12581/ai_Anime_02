SC_008 INT. 张檬檬家/医院诊室 - 黄昏

```text
【场景视觉基准】
地点代码：INT. 张檬檬家/医院诊室
空间性质：室内，封闭，小型住家与诊室复合叙事空间
基本布局：张家客厅以折叠门连接卧室；医院诊室保留同向诊疗床、监护仪和药柜，转场时由家中茶几匹配切到诊疗台。
光线默认状态：黄昏窗光偏暖，诊室为冷白人工光；治疗时病气和指尖灵光形成局部明暗变化。
固定视觉标志物：
  - 张家茶几上按日期分格的白色药盒
  - 卧室门边挂着的浅红旧围巾
  - 诊室床头绿色波形监护仪
  - 张檬檬腕上磨旧的半截红绳
可变元素：药瓶数量、监护数据、病气浓度、水杯位置、家属与医护人员。
```

```text
【场景元数据】
出场人物：江凡, 张檬檬, 医生
叙事功能：第一次让江凡把力量用于守护具体的人，并以摇篮曲和红绳连接一段尚未说破的前世关系。
主要动作：张檬檬病发跌落药瓶，江凡从眉心抽出病气，监护数据恢复并由摇篮曲触发旧物呼应
情绪基调：表面安静照料，内在旧日关系从身体记忆中浮现
隐藏问题：江凡救她，是为了眼前的张檬檬，还是为了她像一位前世故人？
叙述节奏：慢，比上一场权力冲突显著放缓
```

张家客厅的黄昏光停在折叠门边。白色药盒按日期排在茶几上，空格比满格多。

张檬檬把一杯温水递给江凡。她用两只手捧杯，袖口遮住腕上的半截红绳。

```text
【角色视觉档案】
角色名：张檬檬
性别/大致年龄：女，19岁左右
身形体态：约1.62米，前期偏瘦、肩背略收；康复后体态逐渐舒展
面部特征：圆眼、浅酒窝、唇色偏淡
发型发色：黑色及肩微卷发，薄刘海；居家时用红绳束成低马尾
标志性服装/装扮：前期米白针织开衫、浅蓝棉裙、平底鞋；后期增加暖红围巾；婚礼为简洁象牙白长裙
标志性动作/习惯：双手捧杯；无意识哼同一段摇篮曲
标志性随身物件：成对红绳中的一根；白色药瓶仅在康复前出现
```

```
    张檬檬（十九岁，米白针织开衫）
    医生说，水要慢慢喝。

    江凡
    医生说你还能拖多久？
```

张檬檬把杯子放到他面前，指腹擦掉杯沿一滴水。

```
    张檬檬
    够把这杯喝完。
```

她转身去拿药。白色药瓶从袖口滑出，砸在地板上。

张檬檬扶住茶几，膝盖仍向下折。江凡跨过水杯，一手托住她后背，另一只手的两指点在她眉心。

灰黑细线从她颈侧浮出，在皮肤下朝眉心汇拢。她的肩膀一次次抽紧，手指抓住江凡衣袖。

```
    江凡
    别闭眼。看着杯子。

    张檬檬
    你还没喝。
```

灰黑病气被指尖抽成一团。江凡握拳，掌缝冒出一线白火，病气在无声中烧成灰。

医院诊室。

张檬檬躺在同一方向的诊疗床上。绿色监护波形从杂乱尖峰逐渐变得平稳，医生反复核对检查单，又抬头看她的脸。

```
    医生
    再测一次。

    江凡
    机器累了？

    医生
    我怕是我累了。
```

张檬檬撑着床沿坐起。她深吸一口气，胸口不再发颤。

```
    张檬檬
    江凡哥哥，我忽然感觉……好舒服。
```

她低头整理袖口，轻轻哼起一段摇篮曲。

四个音反复一遍，与旧农舍的摇篮曲一致。

江凡伸向水杯的手停在半空。他把手掌翻过来，掌心一道炼丹炉留下的旧灼痕泛白。

张檬檬解下腕上的半截红绳，放进他的掌心，把他的手指一根根合上。

```
    张檬檬
    这个不治病。留着压压惊。

    江凡
    谁的惊？

    张檬檬
    你刚才比我脸白。
```

江凡把红绳绕上手腕，系了两次都散开。张檬檬伸手，替他打成一个双结。

监护仪规律鸣响。江凡看着双结，没有追问那首歌。
