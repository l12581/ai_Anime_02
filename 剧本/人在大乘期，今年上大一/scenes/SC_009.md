SC_009 INT. 湘南财经大学·废教室 - 夜

```text
【场景视觉基准】
地点代码：INT. 湘南财经大学·废教室
空间性质：室内，封闭，中型废弃阶梯教室
基本布局：积灰课桌由低至高呈扇形排列，讲台正对三扇高窗；侧门通往漆黑走廊，后墙残留旧社团展板。
光线默认状态：夜晚仅有走廊应急灯与雷雨闪电；天道纹路出现时墙面发出黯金光。
固定视觉标志物：
  - 讲台上布满粉尘的木质三角尺
  - 第二扇窗右下角蛛网状裂纹
  - 后墙卷边的“文明课堂”标语
  - 最后一排缺少椅背的课椅
可变元素：雨水、闪电频率、梁雨熙手机屏幕、玻璃中的白衣投影和墙面纹路。
```

```text
【场景元数据】
出场人物：江凡, 梁雨熙, 叶倾仙投影, 炎黄协会接线员
叙事功能：以梁雨熙体内的天道之眼把校园旧情、叶倾仙与蓝星异常锁在一起，迫使江凡进入主动调查。
主要动作：梁雨熙逼近索要旧关系，江凡察觉她瞳孔后的巨眼，白衣投影消失并留下天道纹路
情绪基调：表面旧情谈判，内在跨界猎手互相辨认
隐藏问题：叶倾仙藏在梁雨熙体内，还是江凡从未摆脱她的投影？
叙述节奏：中转快，从关系拉扯骤然切入超凡警报
```

侧门在江凡身后合上。走廊应急灯从门缝压进一条绿光。

梁雨熙站在讲台前，银白手机亮着。她把两张旧合照并排放在屏幕上：一张是蘑菇头、黑框眼镜的江凡；另一张来自今天食堂，江凡的手臂正从她怀中抽走。

```
    梁雨熙
    你换了头发，就打算换个人？

    江凡
    你把我叫来，就看照片？
```

梁雨熙刷新屏幕。食堂视频的转发数字继续上涨。她拢好鬓发，向江凡迈下一阶。

```
    梁雨熙
    所有人都认得我们。

    江凡
    所有人不在这儿。
```

她又下一阶。鞋跟在空教室里敲出回声。

```
    梁雨熙
    那你看着我说。
```

江凡没有后退。梁雨熙停在离他半步的位置，把手机屏幕按灭，黑屏映出两张靠得很近的脸。

```
    梁雨熙 (CONT'D)
    你以前不会让我难堪。

    江凡
    以前那个江凡，死了。
```

雷声撞上窗户。

梁雨熙胸口起伏一次。第二声雷响起，与她下一次心跳落在同一瞬间。

江凡的目光从手机移到她的眼睛。

梁雨熙瞳孔深处，一片巨大的眼睑缓缓抖动。细小黯金纹路从虹膜边缘向外爬行。

江凡手腕上的红绳绷紧。他抬起右手食指，停在梁雨熙眉心前。

```
    梁雨熙
    怎么，不敢碰？

    江凡
    里面那个，敢不敢睁眼？
```

闪电照白三扇高窗。第二扇窗的裂纹里，映出一个及腰长发、无纹白袍的女人。

叶倾仙投影站在江凡背后，眉心银纹竖直。她抬起一根食指，动作与江凡悬停的手指隔着玻璃相对。

江凡猛然转身，五指抓向窗面。

玻璃震碎。白衣投影随闪电一起消失。

碎片没有落地，全悬在半空。后墙“文明课堂”标语下方，一道黯金纹路从粉尘里浮出，形状与巨眼的眼角一致。

梁雨熙后退半步。她低头看手机，黑屏中的眼睑已经闭合。

```
    梁雨熙
    你又在演什么？

    江凡
    这回，观众不是你。
```

江凡摊开手。悬空碎片沿原路嵌回窗框，只有那道黯金纹路留在墙上。

他拨通一个号码，把手机举到纹路前。

```
    炎黄协会接线员 (V.O.)
    身份识别。

    江凡
    江凡。封锁湘南财大旧教楼。

    炎黄协会接线员 (V.O.)
    异常等级？
```

江凡看向梁雨熙。她拢好鬓发，手指却不断下拉刷新一块黑掉的屏幕。

```
    江凡
    能让天道眨眼的等级。
```

墙上纹路猛地亮起。整栋旧教楼的应急灯同时熄灭。
