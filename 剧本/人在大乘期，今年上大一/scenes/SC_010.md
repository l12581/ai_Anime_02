```
【场景元数据】
出场人物：江凡, 萧鸿生, 协会技术员
叙事功能：让现代国家秩序第一次对江凡提出非武力约束，并建立双方有限互信。
主要动作：播放全球异常影像，测试江凡力量，交换供奉协议与异常档案
情绪基调：表面专业克制，内在彼此衡量

```

全息沙盘转动。昆仑雪线、湘江水域、国外神殿依次亮起红点。

萧鸿生站着翻阅档案。他约三十四岁，军人站姿，深绿战术夹克的肩线没有一丝松垮。赤霄剑横在他触手可及的位置。

```
【角色视觉档案】
角色名：萧鸿生
性别/大致年龄：男，34岁左右
身形体态：约1.88米，身材高大、肩背厚实，军人站姿
面部特征：方脸、浓直眉、左颧骨有旧伤
发型发色：黑色平头，鬓角短
标志性服装/装扮：深绿战术夹克、黑色作战裤、军靴；大型行动时外加炎黄协会深红肩章
标志性动作/习惯：站着翻阅资料；下令后最后一个撤离
标志性随身物件：赤霄剑；早期任务背负RPG—9S火箭筒
```

江凡靠在会议桌边，露眉短发，素色T恤。他没有坐，也没有碰桌上的茶。

```
    萧鸿生
    三十七处异常。你出现以后，多了十二处。

    江凡
    所以请我喝茶？

    萧鸿生
    请你上秤。
```

测试室门开启。江凡走到仪表柱前，两指按住感应面。

数字跳过红线。

屏幕爆白。

仪表柱从顶部裂到底部。技术员扑向急停钮，掌心全是汗。

萧鸿生把一份供奉协议推过桌面。江凡翻过封面，只抽走压在下面的湘江和昆仑档案。

```
    萧鸿生
    名称、权限、经费。签了，你做事有人收尾。

    江凡
    不签，也有人收尾。

    萧鸿生
    那我换个问法。你能对抗整个协会吗？

    江凡
    能。
```

萧鸿生卷起袖口，手肘落桌。江凡坐下，与他扣住手掌。

两只手都不动。

桌面平整。桌下传来一串沉闷扭响，地砖缝隙拱起，露出弯成弧形的钢筋。

萧鸿生松手，把供奉协议收回抽屉。他在湘江档案上盖下红章。

```
    萧鸿生
    城市里，不准用全力。

    江凡
    别把人放在我和目标中间。

    萧鸿生
    成交。
```

江凡夹起两份档案离开。沙盘上，湘江红点突然扩散一圈。
