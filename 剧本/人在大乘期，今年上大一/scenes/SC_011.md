SC_011 EXT. 湘江施工水域 - 日

```
【场景视觉基准】
地点代码：EXT. 湘江施工水域
空间性质：室外，开放，大型江面工程区
基本布局：临时栈桥伸向桥墩施工井，起重船与箱体平台分列两侧；盘龙柱位于浑浊水面正下方。
光线默认状态：阴天自然光，江面高反光；水下为蓝绿色散射光，星图出现时转为冷白点光。
固定视觉标志物：
  - 标着“7.7m”红色刻度的桥墩箱体
  - 栈桥尽头黄黑安全护栏
  - 水底缠绕铁链的青铜盘龙柱
  - 起重船悬着的钢索吊钩
可变元素：水位、浪涌、潜水员、工程机械、浮泥、黑鳞与河面星图。
```

```
【场景元数据】
出场人物：江凡, 白冰雪, 工程师, 潜水员
叙事功能：以工程谜面展示江凡的破局能力，并让白冰雪带着怀疑进入主线。
主要动作：箱体反复上浮，江凡踏水下潜，拔出黑鳞并显出星图
情绪基调：表面工程处置，内在超凡试探
隐藏问题：江凡来解决公共危险，还是只把异常当成寻找叶倾仙的路标
叙述节奏：中转快，比上一场更具行动密度
```

箱体沿桥墩下沉。红色刻度掠过七米六、七米七。

砰！

整只箱体向上弹起半米。钢索剧烈抖动，吊钩撞上护栏。

```
    工程师
    又是七米七。下面明明什么都没有。
```

白冰雪按停记录器。她约二十一岁，银灰行动服外罩深蓝防寒外套，乌黑长发束成低马尾。

```
【角色视觉档案】
角色名：白冰雪
性别/大致年龄：女，21岁左右
身形体态：约1.72米，修长结实，肩线平直
面部特征：细长眼、鼻尖窄、左眉尾有一道浅疤
发型发色：乌黑及腰长发，中分；行动时束低马尾
标志性服装/装扮：校园段为白衬衫、深蓝长风衣、黑色长裤；协会行动段为银灰贴身行动服和短款防寒外套
标志性动作/习惯：用拇指按停记录器；将散发拢到左耳后
标志性随身物件：银灰数据记录器；昆仑后随身保存一片不融雪花
```

潜水员摘下面罩，伏在栈桥上喘息。他摇头，掌中只有一把淤泥。

江凡跨过护栏。鞋底落在江面，涟漪只凹下一指。

白冰雪抬起记录器。

```
    白冰雪
    协议第一条，城市范围不用全力。

    江凡
    这里是水。
```

江凡向前一步，身体直沉入江。

浑水裂开一条透明通道。水底泥沙翻卷，青铜盘龙柱露出半身，铁链深嵌龙鳞。柱心卡着一枚黑鳞，鳞面随水流开合。

江凡拔出黑鳞。

盘龙柱骤沉。桥墩箱体稳稳落过七米七。

江凡冲出水面，落在栈桥。掌中黑鳞睁开一只针尖大的眼睛。

白冰雪没有后退。她把记录器贴近黑鳞。

```
    白冰雪
    它在看谁？

    江凡
    看见它的人。
```

黑鳞化成灰。河面浮出冷白星图，一条光线越过群山，钉在昆仑。

白冰雪把散发拢到左耳后，记录器转向江凡。

```
    白冰雪
    你早知道终点？

    江凡
    我只知道，路是她留下的。
```

星图熄灭。江凡掌心只剩一圈黑灰，像一只闭上的眼。
