SC_012 INT. 晨光大酒店 - 夜

```
【场景视觉基准】
地点代码：INT. 晨光大酒店
空间性质：室内，封闭，大型宴会酒店
基本布局：挑高宴会厅以七根立柱围成中心圆区，客房走廊呈放射状连向四周；地下设备层藏有阵眼。
光线默认状态：水晶灯暖光，阵法启动后逐盏熄灭，仅剩七盏青白魂灯。
固定视觉标志物：
  - 枝杈状水晶吊灯
  - 地毯下的七芒阵线
  - 七根立柱底部的铜制兽首
  - 停在十一点四十七分的金色挂钟
可变元素：住客、黑影、魂灯火焰、阵位、墙面裂纹和金龙虚影。
```

```
【场景元数据】
出场人物：江凡, 段乘风, 张檬檬, 萧鸿生, 叶晨（档案影像）, 住客
叙事功能：让段乘风从校园权势升级为术法威胁，并用江凡克制杀意证明力量展示的新用途。
主要动作：七星阵抽取生气，江凡反转魂灯，段乘风召龙后被制伏
情绪基调：表面医学交流，内在猎杀与克制
隐藏问题：江凡会把绝对力量用于裁决，还是愿意把裁决交回人间秩序
叙述节奏：快，比上一场连续加速
```

墙面屏幕停在一段无声档案影像：叶晨背手立在龙王旗下，将一枚黑钢龙戒推向画外。画面右下角标着“龙王殿旧档”。

标志性动作/习惯：双手背后接受跪拜；报姓名前停顿一拍

宴会厅坐满面色灰白的住客。七根立柱下，铜兽首吐出黑气，沿地毯暗纹爬向中央。

张檬檬坐在圆区里。她手腕的暗红绳压在白色药瓶下，手指藏进袖口。

段乘风拉平西装袖口，七枚铜灯在他面前排成弧形。

```
    段乘风
    江同学，医学交流。她的病，你不是治好了吗？

    江凡
    你把她放在阵眼，是怕我不来。

    段乘风
    我只是给你一个证明自己的机会。
```

挂钟秒针卡住。

七盏灯同时亮青。住客的五官向中央扭曲，黑影从墙纸后鼓起，伸向张檬檬。

江凡跨入阵线。

第一盏灯，反转。

第二盏。第三盏。七点青火依次变白。

黑影调头，缠住施术者的手腕。段乘风甩出黑钢龙戒，金龙虚影撞碎水晶吊灯，扑向江凡。

江凡抬起食指。

金龙从眉心裂开，碎成满厅金屑。七盏白灯把段乘风钉在中央，暗红阵衣从西装内烧出焦边。

张檬檬踉跄起身。江凡先扶住她，把红绳和药瓶一同放回她掌中。

```
    张檬檬
    江凡哥哥，灯太亮了。

    江凡
    闭眼。数七下。
```

段乘风跪在灯阵中，额头抵住地毯。

```
    段乘风
    价钱你开。

    江凡
    你只会这一句？
```

江凡的指尖停在段乘风眉心前。地毯下的阵线一寸寸熄灭。

萧鸿生带人撞开大门。江凡收指，把七枚铜灯踢到他脚边。

```
    江凡
    人给你。证据也给你。

    萧鸿生
    你想换什么？

    江凡
    别让他再碰她。
```

萧鸿生给段乘风戴上封灵铐。段乘风抬头看江凡，嘴唇发白，再也拉不平烧焦的袖口。
