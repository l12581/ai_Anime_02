SC_014 EXT. 昆仑龙脉 - 夜

```
【场景视觉基准】
地点代码：EXT. 昆仑龙脉
空间性质：室外，开放，超大尺度高山与隐洞
基本布局：雪线山脊通向龙纹峭壁，黑鳞余灰可开启狭窄洞口；洞底封印台正对跨界裂缝。
光线默认状态：月光与雪地反光为主，龙脉发淡金脉冲，裂缝呈冷蓝黑光。
固定视觉标志物：
  - 发光龙脉
  - 结黑冰的龙角形岩柱
  - 同心圆古字封印台
  - 不融六瓣雪花
可变元素：风雪、云层、龙脉亮度、迷阵路径、裂缝宽度和御空轨迹。
```

```
【场景元数据】
出场人物：江凡, 白冰雪
叙事功能：扩大世界尺度，让白冰雪从观察员转为共同进入危险的战友。
主要动作：御空穿越雪线，以黑鳞开洞，触发雪花与跨界裂缝
情绪基调：表面宏阔自由，内在边界逐步失守
隐藏问题：白冰雪追随的是江凡，还是他能打开的未知世界
叙述节奏：慢转快，与前场会议节奏形成开阔对比
```

月光压在雪线上。山体深处，一道淡金龙脉随呼吸般明灭。

江凡踏空而行。白冰雪落后半步，靴底几次擦过风雪。

一阵横风掀起她的长发。她抓住江凡腰侧衣料，另一只手仍按着记录器。

```
    江凡
    掉下去，我不回头。

    白冰雪
    你已经慢了。
```

江凡没有再加速。两人越过雪线，落在龙角形岩柱之间。

白冰雪摊开取自湘江的灰烬。黑灰逆风贴上峭壁，拼成一枚鳞片。石壁向内退开，露出狭窄洞口。

他们贴墙穿过迷阵。每走错一步，来路便多一块黑冰。

洞底，封印台上的同心古字依次亮起。中央悬着一片六瓣雪花，没有融化，也没有落下。

白冰雪伸手。

```
    江凡
    协会没教你别碰？

    白冰雪
    协会教我先记录。
```

她按停记录器，指尖触上雪花。

雪花穿透她的胸口。白冰雪身体向后一弓，左眉旧疤覆上一层薄霜。

江凡扣住她手腕。洞底古字同时炸亮，远处空间裂开一道竖缝。

缝后是一座浸在黄昏里的废城。发黄酸雨斜落，广播声穿过裂口。

```
    广播 (V.O.)
    开餐。开餐。
```

白冰雪抬手按住江凡手背，向裂缝迈出半步。

```
    白冰雪
    这次，我先。
```

裂缝猛然张开。两人的手还扣在一起，身体同时被吸入黑暗。
