SC_015 EXT. 道源村 - 无时之昼

```
【场景视觉基准】
地点代码：EXT. 道源村
空间性质：室外，开放，中型超现实村落
基本布局：青山环抱缓慢河流，五十座石屋沿弧形山坡排列；第四十九座屋亮灯，坡后“家”的方向被透明边界隔断。
光线默认状态：无明确太阳的恒定白昼，光线柔和无影；石碑与亮灯石屋发灰金和暖黄光。
固定视觉标志物：
  - 刻“鸿蒙”的黑灰石碑
  - 老钓者的无轮竹竿
  - 五十座门楣符号各异的石屋
  - 半途消失的青石小路
可变元素：石屋灯光、河面影像、钓线、雾气、边界波纹与跨界门。
```

```
【场景元数据】
出场人物：江凡, 白冰雪, 老钓者
叙事功能：揭示江凡与鸿蒙大道的关系，并以“回不去的家”把力量问题转为身份问题。
主要动作：触碰鸿蒙石碑，撞上透明边界，老钓者以鱼线开门
情绪基调：表面宁静熟悉，内在归属被拒
隐藏问题：如果江凡本就是大道变数，他作为“人”的家庭是否仍然真实
叙述节奏：慢，比前场突发坠落显著放缓
```

江凡与白冰雪跌进齐膝青草。

没有太阳。青山、石屋、小河都罩在均匀白光里。第五十座石屋没有门，第四十九座屋亮着暖灯。

河边坐着老钓者。他约七十五岁，干瘦微驼，洗旧靛青短褂垂到腰间，赤脚踩在扁青石上。

```
【角色视觉档案】
角色名：老钓者
性别/大致年龄：男，外表75岁左右
身形体态：约1.68米，干瘦、微驼，坐姿稳定
面部特征：白眉下垂、鼻翼宽、下巴有稀疏长须
发型发色：银白长发，在脑后松束成低髻
标志性服装/装扮：洗旧靛青短褂、灰白长裤、赤脚；雨天披棕色蓑衣
标志性动作/习惯：背对来客垂钓；说完规则便拨动一次鱼线
标志性随身物件：无钩竹鱼竿；可割开空间的半透明鱼线
```

江凡走到村口。黑灰石碑上的“鸿蒙”二字亮起。

他的手贴上石面。碎片在碑面闪过：狗尾草、木门、抱向他的幼童双臂。江凡的手指收紧，石碑没有裂。

坡后传来木碗落桌的声音。

江凡沿青石路冲上山坡。最后一步，他撞上一层透明边界。波纹沿空气扩散，把他弹回三丈。

白冰雪向前半步，又停在他身后。

```
    江凡
    里面是谁？

    老钓者
    你连门都认不出，问屋里做什么。
```

老钓者没有回头。他拨动鱼线，河面浮出五十道粗光和三千道细光。

```
    白冰雪
    五十大道？

    老钓者
    数得出来的，不算答案。
```

江凡拔出缠红绳的轩辕剑。剑刃抵住透明边界，没有刺下。

老钓者提起竹竿。半透明鱼线从河里抽出，钩住虚空。

```
    老钓者
    鸿蒙不归位。变数也别想先看答案。

    江凡
    那你让我看什么？

    老钓者
    看你只剩力量以后，住在哪儿。
```

鱼线绷紧。老钓者手腕一拨，虚空裂成门。

门后，发黄酸雨冲刷着废弃白院。一个与江凡骨相相同的男人站在街心，黑刃拖地。

江凡收剑，红绳在剑柄上勒紧。他与白冰雪一前一后迈进门。
