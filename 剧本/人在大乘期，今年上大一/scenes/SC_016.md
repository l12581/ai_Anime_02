SC_016 EXT. 凋零世界·荒城 - 黄昏

```
【场景视觉基准】
地点代码：EXT. 凋零世界·荒城
空间性质：室外，开放，大型末日城市
基本布局：宽阔废街穿过坍塌高楼，废弃白院居于街区中心；广播塔和断桥分隔饥民、怪物与江屠的活动区。
光线默认状态：黄昏永久停滞，发黄天光被酸雨云削弱；废火与怪物眼睛提供零散光点。
固定视觉标志物：
  - 外墙大片剥落的白院
  - 长满黑苔的侧翻校车
  - 播放“开餐”的锈蚀广播塔
  - 两栋楼之间的破损红横幅
可变元素：酸雨、饥民、怪物、黑潮、废火、江屠位置和骑熊女孩路线。
```

```
【场景元数据】
出场人物：江凡, 白冰雪, 江屠, 康蕾蕾, 饥民, 吸血生物
叙事功能：把蓝星失败的未来变成可见末日，并让江凡同时面对负面镜像与失落女儿。
主要动作：穿越荒城，江凡与江屠隔街对视，康蕾蕾骑熊冲出怪物群认父
情绪基调：表面末日追逃，内在身份双重震动
隐藏问题：江屠是否是江凡继续只信力量后的终点，而孩子能否迫使他转身
叙述节奏：中转快，比前场宁静骤然加压
```

发黄酸雨敲打白院残墙。广播塔的喇叭缺了半边，仍反复吐出同一句话。

```
    广播 (V.O.)
    开餐。开餐。
```

饥民从楼洞里冲出，朝断桥挤去。两只吸血生物沿墙倒爬，四肢在水泥上划出白痕。

江凡抬手撑开无形屏障。酸雨在他和白冰雪头顶分成两股。白冰雪的记录器刚亮，屏幕便长出黑斑。

街道尽头，一柄黑刃拖过积水。

江屠踏进黄光。他约二十五岁，与江凡骨架相同，肌肉更厚，左脸横着黑色裂纹，酸雨把齐颈乱发的发梢漂成灰白。

```
【角色视觉档案】
角色名：江屠
性别/大致年龄：男，外表25岁左右
身形体态：约1.82米，与江凡骨架相同但肌肉更厚，肩部常前压
面部特征：与江凡同样的窄眼和直鼻；左脸横贯一道黑裂纹；牙齿边缘有血渍
发型发色：黑色齐颈乱发，发梢被酸雨漂成灰白
标志性服装/装扮：破碎黑色长衣、裸露胸口的暗红鸿蒙裂纹、缠布长靴
标志性动作/习惯：张臂吸收怨气；复制江凡双手插兜的姿势后突然出拳
标志性随身物件：由城市废铁熔成的黑刃；掌心一粒发光鸿蒙记忆
```

江屠把黑刃插进街面，模仿江凡双手插兜。两个人隔着翻倒的校车站成同一姿势。

```
    江屠
    又来一个王。

    江凡
    王住这种地方？
```

江屠咧嘴，牙缝带血。他张开双臂，楼洞里的黑气同时朝他胸口涌去。

怪物群后传来沉重脚步。一头瘦熊撞开吸血生物，背上女孩伏低身体，褪色红连帽衫被雨浸透。

康蕾蕾约七岁，黑色齐肩乱发扎成一高一低两条短辫。她一手勒住熊颈，一手护着缠红绳的布偶小熊。

```
【角色视觉档案】
角色名：康蕾蕾
性别/大致年龄：女，7岁左右
身形体态：约1.20米，瘦小，膝肘有长期奔跑留下的擦痕
面部特征：大圆眼、鼻梁上有浅雀斑、左乳牙缺一颗
发型发色：黑色齐肩乱发，自己扎成一高一低两条短辫
标志性服装/装扮：褪色红色连帽衫、过大的灰色工装裤、磨破的棕色短靴
标志性动作/习惯：一手抓父亲衣角、一手护住小熊；紧张时快速数人头
标志性随身物件：缠红绳的布偶小熊；蜡笔画的三口之家
```

瘦熊在江凡面前急停。康蕾蕾从熊背滚下，膝盖擦过碎石。

她抬头。数江凡，数白冰雪，又数回江凡。

江凡右手已经按上轩辕剑。看见小熊腕上的暗红绳，他的手冻在剑柄。

康蕾蕾扑进他怀里。

```
    康蕾蕾
    爸爸！
```

江凡站着不动。酸雨沿屏障滑落，把他们与江屠隔成两个世界。
