SC_017 INT. 凋零世界·废弃教室 - 夜

```
【场景视觉基准】
地点代码：INT. 凋零世界·废弃教室
空间性质：室内，封闭，中型破败教室
基本布局：断裂课桌围出中央避难区，讲台后黑板作为地图与画纸展示面；一侧窗户钉有木板，后门通往荒城。
光线默认状态：铁桶火和康蕾蕾体内星光为主，窗缝偶尔掠过外界冷光。
固定视觉标志物：
  - 黑板上的三口之家蜡笔画
  - 被红绳包扎前爪的小熊
  - 只剩半截的地球仪
  - 钉窗木板上的五道爪痕
可变元素：幸存者、火焰、星光、红绳、窗外黑影和脚步震落的灰尘。
```

```
【场景元数据】
出场人物：江凡, 康蕾蕾, 白冰雪, 小熊
叙事功能：用红绳、画像和摇篮曲三重可见证据确认康蕾蕾身份，推动江凡承认父亲责任。
主要动作：康蕾蕾包扎小熊，展示三口之家，江凡让她爬上后背
情绪基调：表面临时避难，内在亲缘逼近
隐藏问题：承认女儿，是否也等于承认复仇之外曾有完整人生
叙述节奏：慢，以证据逐层积累压住上一场追逃
```

铁桶里烧着拆碎的课桌。康蕾蕾跪在火边，把布偶小熊的前爪放在膝上。

她从自己的袖口抽出一截暗红绳，绕过破口，打了两个结。

江凡坐在两张断桌之间，身体朝门，目光却停在她指尖。白冰雪靠着黑板，记录器没有开。

康蕾蕾把一张蜡笔画贴上黑板。

画里，一个持剑男人站在左边，青裙女人站在右边，中间的孩子举着红绳。三个人头顶只有一间小屋，没有太阳。

```
    江凡
    她叫什么？

    康蕾蕾
    妈妈就是妈妈。

    白冰雪
    画上的男人呢？

    康蕾蕾
    他总说马上回来。
```

江凡从衣领里拉出张檬檬送的红绳。两段绳线颜色相同，纤维都混着一根极细金丝。

康蕾蕾伸手去碰。她没有拿走，只在江凡腕上重新打成双结。

她低头，哼起一段摇篮曲。

白冰雪抬眼。江凡的手停在半空，指尖离女孩头顶一寸。

窗外，一步。

教室灰尘从梁上落下。

又一步。门框向内鼓起。

```
    康蕾蕾
    你还走吗？

    江凡
    我背你。

    康蕾蕾
    这次不骗？

    江凡
    你抓紧。
```

江凡蹲下，背朝她。康蕾蕾抱起小熊，爬上他的后背，双臂勒住他肩膀。

江凡托住她膝弯，第一次与她的视线保持同一高度。

```
    江凡
    蕾蕾，数人。

    康蕾蕾
    一个，两个，三个。
```

门外，黑刃劈下。

江凡背着康蕾蕾起身。轩辕剑出鞘，剑柄红绳贴着女孩的小臂。
