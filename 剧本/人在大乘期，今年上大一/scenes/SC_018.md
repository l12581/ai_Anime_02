SC_018 EXT. 凋零世界·城市中轴 - 夜

```
【场景视觉基准】
地点代码：EXT. 凋零世界·城市中轴
空间性质：室外，开放，超大型城市主轴战区
基本布局：中轴大道从白院延伸至断裂城门，两侧高楼形成峡谷；中央广场供人群集结，出口门在尽头上空开启。
光线默认状态：无月夜色，以黑潮暗红纹路、星光出口和战斗能量闪光照明。
固定视觉标志物：
  - 折断一半的双环雕塑
  - 横跨大道的高架桥残骸
  - 通向城门的白色疏散箭头
  - 吸附怨气的黑色风柱
可变元素：黑潮、幸存者、楼体崩塌、出口、怨气流向和战斗痕迹。
```

```
【场景元数据】
出场人物：江凡, 江屠, 康蕾蕾, 白冰雪, 幸存者
叙事功能：完成中点价值反转，让江凡停止追求击杀镜像，第一次明确选择先救人。
主要动作：两个江凡对轰，江凡转身护送幸存者，康蕾蕾以星光照亮出口
情绪基调：表面宿命决斗，内在守护取代胜负
隐藏问题：真正的赢，是杀死另一个自己，还是拒绝成为他
叙述节奏：快，以动作堆叠完成全片中点
```

黑潮越过断桥，灌进城市中轴。

江屠张开双臂。暗红怨气钻进胸口裂纹，黑刃膨胀成一堵墙。

江凡把康蕾蕾递给白冰雪。

```
    江凡
    带她去城门。

    白冰雪
    你要赢多久？

    江凡
    一剑。
```

江凡冲出。

轩辕剑斩下。

黑刃迎上。

双环雕塑炸碎。高架桥残骸被气浪掀起，撞进两侧楼群。

江屠的右臂断裂。黑潮扑上断口，骨肉立刻重生。他复制江凡抬指的动作，暗光穿透江凡肩甲。

```
    江屠
    杀不死我。这里每个人，都喂我活着。
```

江凡再刺。

黑潮再补。

一次。两次。整条大道只剩剑火和黑雨。

城门前，幸存者被倒塌墙体堵住。白冰雪托着康蕾蕾，另一只手推不开巨石。

康蕾蕾伸向江凡。

```
    康蕾蕾
    爸爸，少了一个！
```

江凡的剑停在江屠咽喉前。

他转身。

江屠的黑刃劈中他后背。玄鸿战甲裂开，红绳剑柄从掌中滑出半寸。

江凡没有回头。他冲到城门，双手托起整面墙体。

```
    江凡
    先救人！
```

幸存者沿白色箭头涌向出口。白冰雪逐个把人推进门内。

康蕾蕾胸口亮起星光。光从她的指缝射出，铺成一条穿透黑潮的路。

江屠举着黑刃站在路尽头。他看见江凡背对自己，护着最后一名老人跨过门槛。

黑刃垂下。

```
    江屠
    不杀我，你算什么王？

    江凡
    我不当王。
```

江屠第一次没有笑。他张开掌心，一粒鸿蒙记忆发着微光。

江凡走近，伸手接住。江屠的指骨随黑潮散去。

白冰雪抱着康蕾蕾站在门内。江凡握紧记忆，跨过出口。门在他身后闭合。
