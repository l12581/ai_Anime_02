SC_019 EXT. 道源村河边 - 无时之昼

```
【场景视觉基准】
地点代码：EXT. 道源村河边
空间性质：室外，开放，中型河岸
基本布局：缓坡草岸贴着静止河面，老钓者坐在扁青石上；河面可承载记忆投影，钓线可切开远端空间。
光线默认状态：均匀柔光，河面影像出现时从水下发蓝金光。
固定视觉标志物：
  - 没有鱼护的空竹篓
  - 扁青石上的鱼线白痕
  - 对岸孤立的银叶柳树
  - 水中不移动的圆形涟漪
可变元素：河面投影、钓线状态、雾气、跨界门、人物倒影和水色。
```

```
【场景元数据】
出场人物：江凡, 白冰雪, 康蕾蕾, 老钓者, 梁雨熙影像, 叶倾仙影像
叙事功能：把鸿蒙记忆变成危机规则，并让江凡找到以电影建立众生共鸣通道的主动计划。
主要动作：投映大道战争，辨认天道载体，老钓者割断鱼线
情绪基调：表面规则问答，内在伦理逼问
隐藏问题：江凡是否有权让亿万人共同相信一扇可能伤害他们的门
叙述节奏：中，比中点大战收束但持续施压
```

鸿蒙记忆落进河面。

蓝金光铺开。无数戴着光环的人影与背负方形系统的人影在星海厮杀，败者化成光丝，被一只闭合巨眼吸收。

康蕾蕾蹲在岸边，一手抓江凡衣角，一手数河里的影子。

```
    康蕾蕾
    太多了。数不完。

    老钓者
    数不完，才叫众生。
```

老钓者拨动鱼线。河面巨眼睁开，瞳孔里站着梁雨熙。她背后，叶倾仙的白衣轮廓与她同时抬手。

江凡按住剑柄。暗红绳被水光映成黑色。

```
    江凡
    她只是壳。

    老钓者
    壳也得自己开门。

    白冰雪
    门从哪边开？

    老钓者
    两边都有人信，门才认路。
```

白冰雪把记录器投向河面。屏幕上，十七家影视公司的炼丹炉梦境叠成同一轮廓。

```
    白冰雪
    同一幅画。还差让所有人同时看见。

    江凡
    银幕。
```

老钓者从腰后抽出一把旧鱼刀。他把半透明鱼线拉紧，刀刃一压。

鱼线断开。

河面所有影像同时熄灭。无轮竹竿第一次变轻，竿梢弹回老钓者肩头。

```
    老钓者
    线断了，鱼不会替你负责。

    江凡
    我负责开门，也负责关。

    老钓者
    你只说了自己的命。
```

江凡低头。康蕾蕾仍抓着他的衣角，红绳小熊贴在她胸口。

他把轩辕剑推回鞘中。

```
    江凡
    那就先把他们撤出去。
```

断掉的鱼线沉入河中。圆形涟漪第一次向岸边扩散。
