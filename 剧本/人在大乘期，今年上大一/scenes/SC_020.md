SC_020 INT. 春城同福巷·张檬檬家 - 日

```
【场景视觉基准】
地点代码：INT. 春城同福巷·张檬檬家
空间性质：室内，封闭，小型老式住宅
基本布局：窄客厅兼饭厅，入门可见方桌；左侧小厨房，右侧卧室，窗户朝向同福巷石板路。
光线默认状态：临街窗户暖自然光为主，夜晚为饭桌上方单盏乳白吊灯。
固定视觉标志物：
  - 方桌边缘月牙形烫痕
  - 旧搪瓷杯里的绿萝
  - 门框上的身高刻度
  - 墙钉上悬挂的两截红绳
可变元素：饭菜、茶杯、康蕾蕾画作、门外防线、窗上霜花与家具损伤。
```

```
【场景元数据】
出场人物：江凡, 张檬檬, 康蕾蕾
叙事功能：让前世亲缘在当下动作中重新成立，把蓝星危机变成具体家庭赌注。
主要动作：康蕾蕾认母，张檬檬替她梳头，江凡系合两截红绳
情绪基调：表面陌生试探，内在本能相认
隐藏问题：张檬檬接受的是无法验证的前世，还是眼前父女对她的需要
叙述节奏：慢，与前场规则压力形成温暖停顿
```

门开。康蕾蕾躲在江凡身后，只露出一只眼睛和布偶小熊。

张檬檬端来三杯温水。她把第三只杯子推到空位，转身时无意识哼起那段摇篮曲。

康蕾蕾从江凡背后探出头。

杯子从张檬檬手中落下。

水洒过方桌烫痕。康蕾蕾冲过去，抱住她的腰。

```
    康蕾蕾
    妈妈。
```

张檬檬双手停在半空。康蕾蕾把脸埋进她的米白开衫，肩膀一抽一抽，没有哭声。

江凡站在门口，手仍扶着门。他没有往里走。

```
    张檬檬
    你认错人了。

    康蕾蕾
    你唱错了一个音。以前也错。
```

张檬檬低头看女孩一高一低的短辫。她解开自己低马尾上的暗红绳，蹲下，把两条短辫重新梳齐。

同一个双结落在发尾。

康蕾蕾抬头，缺掉的左乳牙露出来。张檬檬右手遮住嘴，左手却把她抱紧。

江凡取出腕上半截红绳，又从布偶小熊前爪解下一截。他把两段绳并在一起，金丝接成一线。

```
    江凡
    上辈子，我们是一家人。

    张檬檬
    这辈子呢？
```

江凡看向门外。石板巷里行人经过，远处传来卖菜声。

他关上门，把红绳系在墙钉上。

```
    江凡
    先吃饭。
```

三个人坐到方桌边。康蕾蕾数了一遍椅子，把空着的第四把推回墙边。

张檬檬给江凡夹菜。江凡第一次没有看向门外。
