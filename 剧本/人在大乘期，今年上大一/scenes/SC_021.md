SC_021 INT. 炎黄协会基地 - 夜

```
【场景元数据】
出场人物：江凡, 萧鸿生, 白冰雪, 谢妃姬, 胡彬, 曹梓桐, 郑星云
叙事功能：把江凡的私人引敌计划升级为受国家防线约束的全球防御行动。
主要动作：展示全球异常，争夺计划控制权，分配疏散与外围防御
情绪基调：表面战术会议，内在伦理对峙
隐藏问题：江凡是否肯让别人约束他的决定，并让所有人共同承担后果
叙述节奏：中，从家庭静止切回高压协商
```

基地顶灯熄暗。全息沙盘密布红点：神殿石像睁眼，古堡窗后掠过獠牙，海面升起陌生城市。

萧鸿生站在沙盘中央。他把赤霄剑刺入会议桌插槽，剑身震出一圈红光。

```
    萧鸿生
    你要让十亿人替你敲门。

    江凡
    门已经在开。

    萧鸿生
    那就封，不是推。
```

曹梓桐调出《我被她炼的那些年》传播模型。曲线越过安全线，城市屏幕图标连成一只巨眼。

白冰雪把凋零世界记录器接入沙盘。白院、黑潮、成群饥民悬在众人之间。

```
    白冰雪
    封住这一扇，下一扇会在没人看见的地方开。

    萧鸿生
    你拿一座死城，换我一座活城？

    白冰雪
    我拿它提醒你，什么都不做也有价钱。
```

江凡没有碰沙盘。他把城市疏散图推向萧鸿生。

谢妃姬展开折叠耳机。胡彬逐个点过四名队员。郑星云用指节敲完四拍，把撤离路线投上墙。曹梓桐咬住笔帽，关闭所有自动发布键。

```
    江凡
    你守人。我开门。

    萧鸿生
    外围归我。几点、哪座城、撤到哪儿，也归我。

    江凡
    可以。
```

萧鸿生拔出赤霄剑，剑尖点中沙盘上的春城。红色防线沿同福巷展开。

```
    萧鸿生
    我会出手，不等你求援。

    江凡
    我也不等。
```

白冰雪把一片不融雪花放在昆仑坐标上。雪花旋转，尖端指向尚未开启的黑色裂缝。

全球红点同时闪烁一次。

沙盘上，蓝星被三层防线包围。江凡、萧鸿生与游娱四人分别站在不同方向，没有人坐在主位。
