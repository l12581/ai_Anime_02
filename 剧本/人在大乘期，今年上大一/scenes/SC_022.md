SC_022 INT./EXT. 片场与城市多地 - 制作蒙太奇

```
【场景视觉基准】
地点代码：INT./EXT. 片场与城市多地
空间性质：室内摄影棚与室外城市点位交替，大型制作蒙太奇空间
基本布局：主棚复刻平头村茅房、真天宫白殿和炼丹炉；剪辑室、送审窗口、影院外墙与城市广告屏组成制作链。
光线默认状态：摄影棚随复刻场景变化，工作区为冷白灯，城市外景随昼夜切换。
固定视觉标志物：
  - 等比例炼丹炉道具
  - 写有《我被她炼的那些年》的场记板
  - 监视器旁“爸爸打坏女帝”蜡笔画
  - 剪辑时间线上的白衣背影
可变元素：布景、演员、工作人员、审批章、预告版本、广告屏和烟雾。
```

```
【场景元数据】
出场人物：江凡, 白冰雪, 张檬檬, 康蕾蕾, 曹梓桐, 谢妃姬, 胡彬, 郑星云, 演员, 工作人员
叙事功能：把江凡的百世创伤转化为主动跨界武器，并让重演暴露尚未愈合的身体记忆。
主要动作：复刻百世炼化，制作和送审电影，发布首支预告
情绪基调：表面高效忙碌，内在创伤被迫重演
隐藏问题：江凡是在掌控过去，还是再次给伤害提供身体
叙述节奏：快，以制作链动作堆叠推进
```

蒙太奇开始：

-- 平头村布景里，茅房木门被工作人员扶正。江凡伸手，把门重新推歪一寸。

-- 白殿布景中央，演员穿上玄鸿战甲。江凡扣住他的手腕，把抓向叶倾仙的位置压低。

```
    江凡
    不是求她。是想把她拖进来。
```

-- 张檬檬蹲在童年江凡演员面前，将暗红绳系在他腕上。康蕾蕾坐在监视器后，布偶小熊挡住一只眼睛。

-- 白冰雪穿着无纹白袍站上高台。她没有模仿叶倾仙的脸，只把颈背挺直，伸出一根食指。

江凡握紧轩辕剑。

剑柄发出脆响。红绳下裂开一道细缝。

白冰雪放下手。

```
    白冰雪
    不像？

    江凡
    太像。
```

-- 曹梓桐在剪辑室拖动时间线。炼丹炉门开、合、再开。她咬住笔帽，把三个版本分别存入红、蓝、黄硬盘。

-- 谢妃姬在送审窗口递上加密文件，银色保温杯压住缺页说明。

-- 胡彬站在库房门口清点封箱，双手第一次没有拢在身前。

-- 郑星云让折叠无人机飞过影院外墙，测出每一面屏幕到疏散口的距离。

-- 城市广告屏亮起白衣背影。场记板在画面前一合：电影《我被她炼的那些年》。

蒙太奇结束。

片场主棚，江凡站在炼丹炉道具前。炉门内没有火，只有自己的倒影。

曹梓桐把平板递来。发布键下方，倒计时归零。

```
    曹梓桐
    一旦出去，撤不回来。

    江凡
    她也一样。
```

江凡按下发布。

无数手机同时响起预告首句。

```
    叶倾仙演员 (V.O.)
    你，可愿随吾修行。
```

热搜榜第一行跳出：叶倾仙。
