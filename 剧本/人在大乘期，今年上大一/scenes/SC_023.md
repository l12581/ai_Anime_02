SC_023 INT. 梁雨熙公寓 - 夜

```
【场景视觉基准】
地点代码：INT. 梁雨熙公寓
空间性质：室内，封闭，中型现代公寓
基本布局：客厅以电视墙为中心，落地窗连接窄阳台；卧室门与玄关分居电视墙两侧，形成狭长空间。
光线默认状态：电视冷白光和城市霓虹为主；附身后墙内泛出暗金眼纹光。
固定视觉标志物：
  - 电视下方三部旧手机
  - 沙发背后无装饰的灰墙
  - 落地窗前白纱帘
  - 比真人慢半拍的玄关镜倒影
可变元素：预告、屏幕、巨眼、段乘风、家具破损和霓虹颜色。
```

```
【场景元数据】
出场人物：梁雨熙, 段乘风, 叶倾仙声音
叙事功能：让梁雨熙主动接纳天道之眼，使江凡的引敌计划被对手反向利用。
主要动作：反复播放预告，巨眼占据墙面，梁雨熙夺取段乘风记忆
情绪基调：表面独处嫉妒，内在控制欲迎接入侵
隐藏问题：梁雨熙是被夺走身体，还是用身体换回支配江凡的机会
叙述节奏：中转快，从公开传播收缩为密室恐怖
```

三部旧手机并排播放同一段预告。电视上的叶倾仙抬起手，手机里的白衣女人同时伸出食指。

梁雨熙坐在沙发中央，不停下拉刷新。银白手机壳背面的眼纹裂痕越伸越长。

```
    叶倾仙声音 (V.O.)
    你，可愿随吾修行。
```

梁雨熙跟着张口。她的声音与电视重合，最后一个字没有起伏。

白纱帘停止摆动。

她身后的灰墙鼓起。墙皮裂成上下眼睑，一只暗金巨眼缓慢睁开。

走廊警报灯从门缝扫过。

门锁炸开。段乘风闯入，腕上仍扣着半截封灵铐，断裂的协会封条挂在烧焦袖口。他把一张协会防线图拍在茶几上。

```
    段乘风
    我能把江凡带来。你给我原来的位置。

    梁雨熙
    原来的你，值多少？

    段乘风
    你也被他扔下了。我们——
```

梁雨熙抬起食指。

段乘风撞上墙，双脚离地。巨眼的瞳孔收成一线，一束暗金光钻进他额头。

他的记忆浮在墙面：基地环形走廊、春城疏散图、萧鸿生的赤霄剑、同福巷门牌。

梁雨熙站起。她的颈背笔直，栗黑长发垂在素白裙上。

```
    梁雨熙
    你能带来的，不是他。

    段乘风
    那你要什么？

    梁雨熙
    让他回来找我。
```

她指尖一收。段乘风跌在地毯上，防线图自行卷起，落入她掌中。

电视、旧手机、街对面广告屏里的白衣女人同时转脸。

所有屏幕眨了一次眼。
