SC_024 EXT. 城市上空/炎黄协会防线 - 夜

```
【场景视觉基准】
地点代码：EXT. 城市上空/炎黄协会防线
空间性质：室外，开放，超大型城市空域与街区防线
基本布局：高楼屏幕围成中心空域，三条封锁街道汇入协会指挥车；最大空间裂缝悬于楼群之间。
光线默认状态：城市夜灯被警戒红灯覆盖，裂缝投下蓝黑冷光，术法形成短促高亮。
固定视觉标志物：
  - 睁出巨眼的三面楼体屏幕
  - 横跨街道的协会隔离带
  - 车顶展开环形天线的指挥车
  - 不断结霜的主裂缝边缘
可变元素：怪物、疏散人流、车辆、裂缝、雪花、火光和建筑损伤。
```

```
【场景元数据】
出场人物：江凡, 白冰雪, 萧鸿生, 谢妃姬, 胡彬, 曹梓桐, 郑星云, 市民, 怪物残影
叙事功能：第一次全面检验团队协作，并让白冰雪选择脱离江凡保护、独自寻找克制天道的力量。
主要动作：防线疏散，江凡封裂缝，白冰雪穿越异界通道
情绪基调：表面全城失控，内在信任被迫放手
隐藏问题：江凡能否承认白冰雪的选择不需要由他批准
叙述节奏：快，比前场密室恐怖扩大到城市行动
```

三面高楼屏幕同时睁眼。

蓝黑裂缝撕开夜空。石像手臂、长翼黑影、沾血獠牙从缝中挤出，落向街区。

萧鸿生把赤霄剑钉进路口。红光沿隔离带窜开。

```
    萧鸿生
    三街清空！两分钟！
```

谢妃姬戴上折叠耳机，转身带走东侧人群。胡彬守住车门，点过最后一名伤员。曹梓桐切断周围屏幕信号。郑星云套上橙色反光背心，无人机把蓝色撤离箭头投到路面。

江凡升到楼群上空。

他双掌一合，白茫世界压住最大裂口。外来怪物碰上边界，皮肉化成灰；一名被巨眼控制的市民冲进去，毫发无损。

```
    江凡
    它只认外来者。

    萧鸿生
    那就把本地人交给我们！
```

白冰雪站在指挥车顶。昆仑雪花从她胸口浮出，六个尖端同时指向裂缝深处。

裂缝边缘结霜，露出一条仅容一人的窄路。

江凡落在她面前，挡住入口。

```
    江凡
    那边没有路标。

    白冰雪
    所以我带着它。

    江凡
    回不来呢？

    白冰雪
    你当初回天门，也有人替你批准？
```

白冰雪把记录器递给江凡。她没有递出雪花。

一只长翼怪物扑下。江凡抬指将它击成灰。白冰雪借那一瞬跨过他，踏上霜路。

江凡伸手，只抓住从她发尾落下的一片普通雪。

白冰雪走入裂缝。六瓣不融雪花贴回她胸口，冷光远去。

裂缝合拢。

江凡摊开掌心。普通雪花在皮肤上融成水。

他收手，转身冲向下一处防线。
