SC_025 INT. 游娱协会片场 - 深夜

```
【场景视觉基准】
地点代码：INT. 游娱协会片场
空间性质：室内，封闭，大型停拍摄影棚
基本布局：炼丹炉布景占据中央，周围是熄灭灯架、绿幕与监视区；侧门通向道具库和紧急出口。
光线默认状态：停电后仅有应急灯、手电和炉膛内残余红光。
固定视觉标志物：
  - 炉门上的康蕾蕾蜡笔画
  - 通往监视器的黄色电缆
  - 道具桌上的裂纹剑柄
  - 倒扣的女帝白色头冠
可变元素：人员、应急电量、红绳、炉膛光、剧本页和外界警报。
```

```
【场景元数据】
出场人物：江凡, 张檬檬, 康蕾蕾
叙事功能：让江凡在引敌前暴露无法直说的恐惧，并由现实家庭支持他继续承担计划。
主要动作：江凡独坐炉前，康蕾蕾贴画，张檬檬以红绳修补剑柄
情绪基调：表面停电静默，内在害怕再次被抛弃
隐藏问题：无敌的江凡是否敢让家人看见，他也可能回不来
叙述节奏：慢，与前场城市大战形成长停顿
```

摄影棚停电。应急灯隔很远才亮一盏。

江凡独坐在炼丹炉道具前。炉膛里的红灯忽明忽暗，把他的影子压在白殿布景上。

康蕾蕾踩着黄色电缆走来。她把一张蜡笔画贴在炉门上：江凡举剑，女帝碎成很多白纸片。

```
    康蕾蕾
    爸爸打坏女帝。

    江凡
    画反了。

    康蕾蕾
    你站着，就是没反。
```

她把布偶小熊放到江凡腿上，跑回张檬檬身边。

张檬檬端来一杯温水。她没有递给江凡，只放在他能碰到的位置。

```
    张檬檬
    回来以后，你最怕什么？

    江凡
    水凉。

    张檬檬
    那就别碰水。
```

江凡从腰后取下轩辕剑。剑柄红绳下的裂纹已经延伸半圈。他把剑平放在张檬檬膝上。

张檬檬看一眼裂口，解下自己的低马尾红绳。她一圈圈缠过旧绳，把裂纹盖住。

康蕾蕾蹲在旁边，数她绕过的圈数。

```
    康蕾蕾
    七。八。九。

    张檬檬
    多一圈，留给回来的人。
```

江凡接过剑。拇指压住新结，没有试着掰断。

```
    江凡
    上映以后，门可能关不上。

    张檬檬
    你负责关门。我们负责不站在门口等死。

    江凡
    谁教你的？

    张檬檬
    没人能教你做事。我们也一样。
```

外面恢复供电。灯架一排排亮起，炼丹炉里的假火熄灭。

江凡起身，把缠紧红绳的轩辕剑重新背好。

他取出手机，按下“维持上映计划”。
