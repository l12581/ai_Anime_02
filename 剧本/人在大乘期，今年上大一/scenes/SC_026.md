SC_026 INT./EXT. 全国影院与街道 - 大年初一

```
【场景视觉基准】
地点代码：INT./EXT. 全国影院与街道
空间性质：室内公共影院与室外开放街道并置，全国性复合空间
基本布局：多个城市的银幕、放映室、售票厅和门外街道屏幕组成并行网络，所有空间由同一电影画面同步。
光线默认状态：影院由银幕白光照明，街道为节日灯与广告屏光；共鸣增强后白色光丝成为主光源。
固定视觉标志物：
  - 相同的白衣女帝银幕画面
  - 印炼丹炉剪影的票根
  - 放映窗口旋转的白色光束
  - 街道屏幕下的大年初一红灯笼
可变元素：观众、弹幕、热搜、光丝、城市天气和梁雨熙所在影院。
```

```
【场景元数据】
出场人物：江凡, 梁雨熙, 曹梓桐, 萧鸿生, 全国观众
叙事功能：让引敌计划成功到越过控制线，把公众想象转化为叶倾仙的新神格与通道。
主要动作：全国同步观影，众生光丝升空，梁雨熙与银幕女帝同步
情绪基调：表面节日观影，内在集体献祭成形
隐藏问题：江凡召来的究竟是仇人，还是被十亿人重新创造的神
叙述节奏：中转快，以跨城同步动作持续加速
```

大年初一。

影院里先响起笑声。银幕上的江凡叼着稻草走出茅房，抱住白衣女帝的腿。

笑声逐渐停下。

九转炼丹炉闭合。五百余世尸骨层叠。观众手中的票根泛出白光，炼丹炉剪影像烙印一样浮起。

一缕光丝从第一排观众额前升起。

第二缕。第三缕。

全国影院外，红灯笼还在风里摇。无数光丝穿过屋顶，沿街道屏幕向城市上空汇聚。

控制室里，曹梓桐双手拖动时间线。跨界读数越过黄线、红线，最后顶住量程。

```
    曹梓桐
    讨论量不是上涨。是同步。

    萧鸿生 (V.O.)
    停映。

    江凡
    现在停，门留一半。
```

江凡站在屏幕墙前。每一块屏都滚动同一个名字：叶倾仙。

一座空影院里，梁雨熙独自坐在正中央。素白长裙铺过座椅，银白手机立在扶手上。

银幕女帝抬头。

梁雨熙抬头。

银幕女帝伸出食指。

梁雨熙伸出食指。

她背后的座椅一排排陷入黑暗，只有颈背被银幕白光照亮。

```
    梁雨熙
    你，可愿随吾修行。
```

城市上空，光丝缠成白衣轮廓。轮廓没有脸，眉心银纹却先亮起。

控制室警报爆响。跨界读数击穿屏幕，玻璃裂纹组成一只眼。

江凡拔出轩辕剑。新缠的红绳结压在他掌心。

天空裂开。

一只苍白的手穿过城市巨幕，指尖向下。
