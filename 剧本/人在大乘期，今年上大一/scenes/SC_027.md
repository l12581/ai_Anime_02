SC_027 EXT. 城市中心/天门 - 夜

```
【场景视觉基准】
地点代码：EXT. 城市中心/天门
空间性质：室外，开放，超大型城市中心与跨界门户
基本布局：十字路口和中央广场被高楼包围，弧形巨幕位于北侧；天门从银幕上方向天空延展，战场沿楼顶拉升。
光线默认状态：广告屏白光与天门金白逆光压过城市照明；时间停止后移动光源冻结。
固定视觉标志物：
  - 广场北侧弧形巨幕
  - 路口中央圆形城市徽记
  - 光丝编织的白玉天门
  - 疏散路线蓝色箭头灯
可变元素：市民、车辆、冻结范围、李清月显形、屏幕裂纹、雷鞭和战斗轨迹。
```

```
【场景元数据】
出场人物：江凡, 李清月, 梁雨熙, 叶倾仙投影, 萧鸿生, 市民
叙事功能：完成情节点II，让叶倾仙获得蓝星规则中的完全形态，并把决战不可逆地拉向银河。
主要动作：梁雨熙与银幕投影合一，李清月冻结半城，江凡以雷鞭转移战场
情绪基调：表面召唤成功，内在复仇被家人安危重新排序
隐藏问题：仇人终于出现时，江凡能否仍把众人安全放在复仇之前
叙述节奏：快，承接前场越线读数直接爆发
```

白玉天门压在城市上空。

银幕中的叶倾仙迈出一只脚。空影院里的梁雨熙同时离座，身体化成一束白光，穿过街区撞进巨幕。

两道白影在广场上方重合。

光芒收缩。李清月赤脚悬停半尺，约二十二岁，深棕锁骨发被银色月牙发夹别在右侧。月白针织衫从下摆开始白化，长出黑白甲纹。

```
【角色视觉档案】
角色名：李清月
性别/大致年龄：女，22岁左右
身形体态：约1.67米，匀称，日常站姿放松；被合一后颈背异常挺直
面部特征：圆杏眼、右侧鼻翼有小痣、下巴偏圆
发型发色：深棕色锁骨直发，右侧用一枚银色月牙发夹固定
标志性服装/装扮：初见为月白针织衫、浅灰长裙、低跟短靴；完全体阶段衣料逐渐白化并长出黑白甲纹
标志性动作/习惯：正常状态先偏头再笑；受控后抬手只伸食指
标志性随身物件：银色月牙发夹，合一时裂成太极形两片
```

她伸出食指。

半座城市停止。

飘落的纸屑悬在路灯旁。救护车蓝光凝成两条静止光带。奔跑的市民停在抬脚的一瞬。

江凡踏上巨幕顶端。轩辕剑出鞘，红绳结紧贴虎口。

```
    江凡
    叶倾仙。

    李清月
    这个名字，还是能让你拔剑。
```

江凡挥剑。金色剑气绕过高楼，把战场向上托起，没有落向广场。

萧鸿生背起一名被冻结的孩子，赤霄剑拖出红色防护线。他带着还能行动的人沿蓝色箭头撤离。

李清月抬手挡住剑锋。她掌心没有伤口。

```
    李清月
    世界之力，净化不了这个世界的人。

    江凡
    那我不用它。
```

李清月身后浮出三幅光影：张檬檬家的方桌，康蕾蕾的红绳小熊，江凡父母紧闭的房门。

江凡的剑尖偏开一寸。

```
    李清月
    你终于有了不能一起烧掉的东西。

    江凡
    所以你不能留在这里。
```

江凡左手一扯。钓之雷鞭从虚空抽出，缠住李清月与整片天门。

雷光绷紧。

城市巨幕、白玉天门、两道人影同时被拉成薄纸。江凡脚下的楼顶寸寸开裂，他仍把雷鞭向银河方向甩出。

萧鸿生回头。高空只剩一条贯穿夜幕的白痕。

红超巨星在白痕尽头燃起。
